Visual Studio

Visual Studio Community là một IDE chỉ dành cho Windows của Microsoft, miễn phí cho cá nhân hoặc sử dụng phi thương mại trong tổ chức. Nó có nhiều tính năng hữu ích như memory view, performance view, quản lý mã nguồn và nhiều hơn nữa.

Ghi chú

Tài liệu này dành cho việc đóng góp vào game engine, không phải để dùng Visual Studio làm trình soạn thảo C#. Để viết mã C# trong trình soạn thảo bên ngoài, xem hướng dẫn C# về cấu hình trình soạn thảo bên ngoài.

Import dự án

Visual Studio cần một tệp solution để làm việc với dự án. Mặc dù Godot không đi kèm tệp solution, bạn có thể tạo nó bằng SCons.

  • Điều hướng đến thư mục gốc của Godot và mở cửa sổ Command Prompt hoặc PowerShell.

  • Chạy scons platform=windows vsproj=yes dev_build=yes để tạo solution có debug symbol.
    Tham số vsproj cho biết bạn muốn tạo solution Visual Studio.
    Tham số dev_build đảm bảo các debug symbol được bao gồm, cho phép bạn chẳng hạn chạy từng bước qua mã bằng breakpoint.

  • Giờ bạn có thể mở dự án bằng cách nhấp đúp vào godot.sln trong thư mục gốc của dự án hoặc dùng tùy chọn Open a project or solution bên trong Visual Studio.

  • Dùng menu Build trên cùng để build dự án.

Gỡ lỗi dự án

Visual Studio có một trình gỡ lỗi mạnh mẽ. Nó cho phép người dùng xem xét mã nguồn của Godot, dừng tại các điểm cụ thể trong mã, kiểm tra ngữ cảnh thực thi hiện tại và thay đổi trực tiếp codebase.

Bạn có thể khởi chạy dự án với trình gỡ lỗi được gắn vào bằng tùy chọn Debug > Start Debugging từ menu trên cùng. Tuy nhiên, trừ khi bạn muốn debug riêng Project Manager, bạn cần cấu hình các tùy chọn debug trước. Lý do là khi Project Manager của Godot mở một dự án, tiến trình ban đầu bị kết thúc và trình gỡ lỗi bị tách ra.

  • Để cấu hình các tùy chọn khởi chạy dùng với trình gỡ lỗi, hãy dùng Project > Properties từ menu trên cùng:

  • Mở mục Debugging và trong Command Arguments thêm hai tham số mới: cờ -e mở trình chỉnh sửa thay vì Project Manager, và tham số --path yêu cầu tệp thực thi mở dự án được chỉ định (phải được cung cấp dưới dạng đường dẫn tuyệt đối đến thư mục gốc của dự án, không phải tệp project.godot; nếu đường dẫn chứa dấu cách, hãy nhớ đặt nó trong dấu ngoặc kép).

Để tìm hiểu thêm về các tham số dòng lệnh, hãy tham khảo bài hướng dẫn dòng lệnh.

Ngay cả khi bạn khởi chạy dự án mà không gắn trình gỡ lỗi, bạn vẫn có thể kết nối nó với tiến trình đang chạy bằng menu Debug > Attach to Process....

Để kiểm tra mọi thứ có hoạt động không, hãy đặt một breakpoint trong main.cpp và nhấn F5 để bắt đầu debug.

Nếu gặp vấn đề, hãy nhờ trợ giúp tại một trong các kênh cộng đồng của Godot.
