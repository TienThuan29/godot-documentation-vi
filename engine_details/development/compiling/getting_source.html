Lấy mã nguồn

Tải mã nguồn Godot

Trước khi tìm hiểu hệ thống build SCons và biên dịch Godot, bạn cần tải mã nguồn Godot về.

Mã nguồn có trên GitHub và dù bạn có thể tải thủ công qua trang web, thông thường bạn nên tải qua hệ thống quản lý phiên bản git.

Nếu bạn biên dịch để đóng góp hoặc tạo pull request, hãy làm theo hướng dẫn trên trang Quy trình pull request.

Nếu bạn chưa biết nhiều về git, có rất nhiều bài hướng dẫn trên nhiều trang web khác nhau.

Nhìn chung, bạn cần cài đặt git và/hoặc một trong các ứng dụng client có giao diện đồ họa.

Sau đó, để lấy phiên bản phát triển mới nhất của mã nguồn Godot (nhánh master chưa ổn định), bạn có thể dùng git clone.

Nếu bạn dùng client dòng lệnh git, hãy nhập lệnh sau trong terminal:

git clone https://github.com/godotengine/godot.git
# You can add the --depth 1 argument to omit the commit history (shallow clone).
# A shallow clone is faster, but not all Git operations (like blame) will work.

Với bất kỳ bản phát hành ổn định nào, hãy truy cập trang phát hành và nhấp vào liên kết của bản phát hành bạn muốn. Sau đó bạn có thể tải và giải nén mã nguồn từ liên kết tải xuống trên trang.

Với git, bạn cũng có thể clone một bản phát hành ổn định bằng cách chỉ định nhánh hoặc tag của nó sau tham số --branch (hoặc -b):

# Clone the continuously maintained stable branch (`4.7` as of writing).
git clone https://github.com/godotengine/godot.git -b 4.7

# Clone the `4.7-stable` tag. This is a fixed revision that will never change.
git clone https://github.com/godotengine/godot.git -b 4.7-stable

# After cloning, optionally go to a specific commit.
# This can be used to access the source code at a specific point in time,
# e.g. for development snapshots, betas and release candidates.
cd godot
git checkout f4af8201bac157b9d47e336203d3e8a8ef729de2

Các nhánh bảo trì được dùng để phát hành thêm các bản vá cho mỗi phiên bản minor.

Bạn có thể lấy mã nguồn của từng bản phát hành và bản tiền phát hành ở định dạng .tar.xz từ godotengine/godot-builds trên GitHub. Cách này không có thông tin quản lý phiên bản nhưng dung lượng tải xuống nhỏ hơn một chút.

Sau khi tải mã nguồn Godot, bạn có thể tiếp tục biên dịch Godot.
