Biên dịch cho iOS

Xem thêm

Trang này mô tả cách biên dịch các binary export template cho iOS từ mã nguồn. Nếu bạn muốn xuất dự án sang iOS, hãy đọc Xuất cho iOS.

Yêu cầu

  • Python 3.9+.

  • Hệ thống build SCons 4.4+.

  • Xcode.

    • Khởi chạy Xcode một lần và cài đặt hỗ trợ iOS. Nếu bạn đã khởi chạy Xcode trước đó và cần cài đặt hỗ trợ iOS, hãy vào Xcode -> Settings... -> Platforms.

    • Vào Xcode -> Settings... -> Locations -> Command Line Tools và chọn một phiên bản đã cài. Ngay cả khi đã có phiên bản được chọn, hãy chọn lại.

  • Tải về và làm theo hướng dẫn trong README để build một .xcframework tĩnh từ MoltenVK SDK.

Ghi chú

Nếu bạn đã cài Homebrew, bạn có thể dễ dàng cài SCons bằng lệnh sau:

brew install scons

Việc cài Homebrew cũng sẽ tự động tải Command Line Tools cho Xcode nếu bạn chưa có.

Tương tự, nếu bạn đã cài MacPorts, bạn có thể dễ dàng cài SCons bằng lệnh sau:

sudo port install scons

Biên dịch

Mở Terminal, đi tới thư mục gốc của mã nguồn engine và gõ lệnh sau để biên dịch bản build debug:

scons platform=ios target=template_debug generate_bundle=yes

Để biên dịch bản build release:

scons platform=ios target=template_release generate_bundle=yes

Để tạo một dự án Xcode giống các bản build chính thức, bạn cần dùng template nằm trong misc/dist/apple_embedded_xcode. Các thư viện release và debug lần lượt được đặt trong libgodot.ios.debug.xcframework và libgodot.ios.release.xcframework. Các thư viện module camera được đặt trong libgodot_camera.ios.debug.xcframework và libgodot_camera.ios.release.xcframework. Quá trình này có thể được tự động hóa bằng tùy chọn generate_bundle=yes ở lệnh SCons cuối cùng dùng để build export template (để mọi binary đều được đưa vào).

Thư mục .xcframework tĩnh của MoltenVK cũng phải được đặt trong thư mục apple_embedded_xcode sau khi được tạo. MoltenVK luôn được liên kết tĩnh trên iOS; không có tùy chọn liên kết động, khác với macOS.

Cảnh báo

Trình giả lập iOS chỉ hỗ trợ renderer Compatibility.

Máy Mac dùng Apple Silicon có thể chạy ứng dụng iOS một cách native, vì vậy bạn có thể chạy trực tiếp các dự án iOS đã xuất trên máy Mac Apple Silicon mà không gặp giới hạn của trình giả lập iOS.

Chạy

Để chạy trên thiết bị, hãy làm theo hướng dẫn sau: Xuất cho iOS.

Bản xuất iOS có thể chạy trực tiếp trên máy Mac Apple Silicon. Để chạy dự án iOS đã xuất trên Mac, hãy mở dự án đã xuất trong Xcode và chọn My Mac trong danh sách thả xuống Run Destinations.

Khắc phục sự cố

Fatal error: 'cstdint' file not found

Nếu bạn gặp lỗi biên dịch dạng này ngay từ đầu, nhiều khả năng là do bản cài đặt Xcode command line tools cần được sửa chữa sau khi cập nhật macOS hoặc Xcode:

./core/typedefs.h:45:10: fatal error: 'cstdint' file not found
45 | #include <cstdint>
   |          ^~~~~~~~~

Chạy hai lệnh sau để cài đặt lại Xcode command line tools (nhập mật khẩu quản trị viên khi được yêu cầu):

sudo rm -rf /Library/Developer/CommandLineTools
sudo xcode-select --install

Nếu vẫn không được, hãy thử cập nhật Xcode từ Mac App Store rồi thử lại.
