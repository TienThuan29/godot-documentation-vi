Perfetto

Xem thêm

Vui lòng xem hướng dẫn về tracing profiler để biết thêm thông tin.

Perfetto là hệ thống tracing mặc định của Android. Thực tế, dịch vụ tracing hệ thống của nó đã được tích hợp sẵn vào nền tảng kể từ Android 9.

Dùng template Perfetto chính thức

Bắt đầu từ Godot 4.7, export template Perfetto được cung cấp cho mọi bản phát hành Godot ổn định và có thể tải về từ trang GitHub Releases.

Dùng Gradle build template

  • Truy cập trang phát hành và tải artifact Godot_v<godot_version>_android_source.perfetto.zip, trong đó godot_version tương ứng với phiên bản engine đang dùng.

  • Trong hộp thoại Project > Export, phải bật Advanced Options và Use Gradle Build.

  • Trỏ Android Source Template đến export template đã tải về.

Làm theo hướng dẫn trong phần Cấu hình để tìm hiểu cách cấu hình và tạo trace.

Dùng build template không phải Gradle

  • Truy cập trang phát hành và tải các artifact sau, trong đó godot_version tương ứng với phiên bản engine đang dùng:

    • Godot_v<godot_version>_android_debug.perfetto.apk (cho bản build debug)

    • Godot_v<godot_version>_android_release.perfetto.apk (cho bản build release)

  • Trong hộp thoại Project > Export:

    • Phải bật Advanced Options

    • Phải tắt Use Gradle Build

  • Trỏ Custom Template đến các export template đã tải về.

Làm theo hướng dẫn trong phần Cấu hình để tìm hiểu cách cấu hình và tạo trace.

Bản build Godot tùy chỉnh có hỗ trợ Perfetto

Từ thư mục gốc godot, chạy script python sau để cài đặt phiên bản mới nhất của Perfetto SDK vào thirdparty/perfetto:

python misc/scripts/install_perfetto.py

Tiếp theo, build template Android debug hoặc release cho kiến trúc của bạn bằng scons (theo Biên dịch cho Android), nhưng thêm tham số profiler=perfetto.

Ghi chú

Nhìn chung, bạn nên profile template release, vì đó là phiên bản người chơi sẽ dùng và nó sẽ có hiệu năng khác với các loại bản build khác. Tuy nhiên, với Android, đôi khi dùng template debug lại hữu ích, vì Godot chỉ có thể debug từ xa các game được xuất từ template debug.

Ví dụ, để build template release cho arm64:

scons platform=android target=template_release arch=arm64 generate_android_binaries=yes profiler=perfetto

Cấu hình

Perfetto cần một tệp cấu hình để biết cần theo dõi những sự kiện nào.

Tạo một tệp tên godot.config với nội dung sau:

# Trace for 10 seconds.
duration_ms: 10000

buffers {
    size_kb: 32768
    fill_policy: RING_BUFFER
}

# Write to file once every second to prevent overflowing the buffer.
write_into_file: true
file_write_period_ms: 1000

# Track events in the "godot" category.
data_sources {
    config {
        name: "track_event"
        track_event_config {
            enabled_categories: "godot"
        }
    }
}

Ghi chú

Godot ghi lại hai nhóm track event:

  • godot: Dùng để ghi lại các sự kiện của Godot engine. Nhóm này được dùng để phân tích hiệu năng. Chi phí tracing sự kiện không nên ảnh hưởng đáng kể đến hiệu năng. Đây nên là chế độ tracing thông thường cho hầu hết nhà phát triển.

  • godot_scripting: Dùng để ghi lại các sự kiện scripting của Godot. Đây là nhóm chậm vì nó profile toàn bộ logic script của game. Nhóm này được dùng để hiểu mã / debug / tìm nguyên nhân gây giật frame. Hiệu năng chậm hơn nhiều, nhưng nó giúp tìm ra lời gọi hàm có vấn đề mà nếu không thì sẽ bị ẩn đi.

Ghi trace

Cuối cùng, khởi chạy game trên thiết bị Android bằng các export template bạn đã build trước đó.

Khi bạn sẵn sàng ghi trace (ví dụ, khi đã đến phần game đang gặp vấn đề hiệu năng), bạn có thể dùng script này từ kho GitHub của Perfetto.

./record_android_trace -c /path/to/godot.config

Script sẽ ghi trong 10 giây (theo cấu hình), hoặc cho đến khi bạn nhấn Ctrl + C.

Xem xét trace

Ngay khi script đó kết thúc, nó sẽ mở giao diện Perfetto UI trong trình duyệt web.

Để xem các sự kiện của Godot, hãy mở rộng hàng của ứng dụng bằng cách nhấp vào Unique Name / Package Name / App ID Android của nó (Perfetto cũng sẽ đưa một số sự kiện từ các dịch vụ hệ thống vào trace).

Sau đó bạn có thể dùng các phím WASD để điều hướng biểu đồ:

  • Nhấn A hoặc D để di chuyển tới hoặc lui dọc theo dòng thời gian

  • Nhấn W hoặc S để phóng to hoặc thu nhỏ

Có thể bạn sẽ cần phóng to một chút trước khi thấy được từng sự kiện riêng lẻ của Godot.

Để tìm hiểu thêm, xem tài liệu Perfetto UI.
