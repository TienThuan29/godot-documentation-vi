Tracy

Xem thêm

Vui lòng xem hướng dẫn về tracing profiler để biết thêm thông tin.

Tracy là một profiler mã nguồn mở chạy trên nhiều nền tảng, bao gồm Windows, Linux và macOS. Dù chủ yếu là tracing profiler, nó cũng có thể lấy mẫu dữ liệu định kỳ như một sampling profiler, mang lại một số lợi ích của cả hai cách tiếp cận.

Build Godot có hỗ trợ Tracy

Trước tiên, clone phiên bản mới nhất của mã nguồn Tracy ("0.13.0" tại thời điểm viết) bằng Git:

git clone -b v0.13.0 --single-branch https://github.com/wolfpld/tracy.git

Thao tác này sẽ tạo thư mục tracy - bạn có thể đặt nó ở bất kỳ đâu.

Tiếp theo, build template release cho nền tảng của bạn bằng scons, nhưng thêm các tham số profiler=tracy profiler_path=path/to/tracy với đường dẫn thật đến thư mục tracy, cùng với debug_symbols=yes để các tính năng lấy mẫu của Tracy hoạt động.

Ghi chú

Bạn không bắt buộc phải build template release, bạn cũng có thể build template debug, hoặc thậm chí trình chỉnh sửa. Tuy nhiên, nhìn chung bạn nên profile template release, vì đó là phiên bản người chơi sẽ dùng và nó sẽ có hiệu năng khác với các loại bản build khác.

Ví dụ, để build template release cho Windows:

scons platform=windows target=template_release debug_symbols=yes profiler=tracy profiler_path=path/to/tracy

Tải "server" của Tracy

Theo thuật ngữ của Tracy, ứng dụng bạn đang profile là "client", và ứng dụng nhận dữ liệu là "server".

Nếu bạn dùng Windows, bạn có thể tải tracy-profiler.exe dựng sẵn từ trang phát hành của Tracy.

Tuy nhiên, nếu bạn dùng Linux hoặc macOS, bạn sẽ cần tìm tệp nhị phân dựng sẵn từ trình quản lý gói (như brew hoặc nix), hoặc tự build từ mã nguồn.

Ghi chú

Nếu bạn dùng bản binary dựng sẵn, hãy nhớ dùng đúng phiên bản bạn đã dùng khi build Godot.

Build Tracy server từ mã nguồn

Để build Tracy, bạn cần cài cmake, có thể tải từ trang web CMake, hoặc cài qua trình quản lý gói (như brew hay nix).

Hướng dẫn đầy đủ để build Tracy từ mã nguồn có trong tài liệu hướng dẫn Tracy, còn đây là bản tóm tắt:

# On Linux, Tracy uses Wayland by default, so if you use X11 add -DLEGACY=1
cmake -B profiler/build -S profiler -DCMAKE_BUILD_TYPE=Release
cmake --build profiler/build --config Release --parallel

Lệnh này sẽ đặt file binary tại tracy/profiler/build/tracy-profiler hoặc tracy/profiler/build/tracy-profiler.exe (trên Windows).

Ghi trace

Khởi chạy Tracy server - bạn sẽ thấy giao diện tương tự như sau:

Nhấn "connect". Việc này đảm bảo Tracy kết nối ngay khi game khởi chạy. Nếu bạn quên nhấn "connect", Tracy sẽ lưu các sự kiện hệ thống vào RAM, có thể khiến mức dùng bộ nhớ tăng vọt nhanh chóng (xem tài liệu về TRACY_ON_DEMAND).

Bây giờ, hãy xuất (export) game bằng các release template bạn đã build ở trên rồi chạy nó. Ngay khi cả hai đang chạy và bạn đã nhấn nút "Connect" trong Tracy, bạn sẽ thấy dữ liệu bắt đầu đổ về:

Khi thấy đã thu thập đủ dữ liệu, hãy nhấn nút "Stop". Nếu bạn lỡ nhấp vào đâu đó và hộp chứa nút "Stop" biến mất, bạn có thể nhấp vào biểu tượng ở góc trên cùng bên trái để hiện lại.

Xem xét trace

Dưới đây là một số thao tác điều khiển cơ bản:

  • Phóng to/thu nhỏ bằng con lăn chuột

  • Nhấp chuột phải và kéo để di chuyển tới/lui trên dòng thời gian

  • Trên thanh trên cùng, nhấp các nút mũi tên trái và phải cạnh "Frames" để di chuyển từng frame trên dòng thời gian

Để tìm hiểu thêm, xem tài liệu hướng dẫn Tracy.
