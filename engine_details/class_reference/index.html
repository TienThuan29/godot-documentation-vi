Nhập môn tài liệu tham chiếu lớp

Trang này giải thích cách viết tài liệu tham khảo lớp (class reference). Bạn sẽ học được nơi viết mô tả mới cho các lớp, phương thức và thuộc tính của các kiểu node dựng sẵn trong Godot.

Xem thêm

Để học cách gửi thay đổi của bạn lên dự án Godot bằng hệ thống quản lý phiên bản Git, xem Tài liệu đóng góp class reference.

Tài liệu tham khảo của mỗi lớp được chứa trong một file XML như bên dưới:

<class name="Node2D" inherits="CanvasItem" version="4.0">
    <brief_description>
        A 2D game object, inherited by all 2D-related nodes. Has a position, rotation, scale, and Z index.
    </brief_description>
    <description>
        A 2D game object, with a transform (position, rotation, and scale). All 2D nodes, including physics objects and sprites, inherit from Node2D. Use Node2D as a parent node to move, scale and rotate children in a 2D project. Also gives control of the node's render order.
    </description>
    <tutorials>
        <link title="Custom drawing in 2D">https://docs.godotengine.org/en/latest/tutorials/2d/custom_drawing_in_2d.html</link>
        <link title="All 2D Demos">https://github.com/godotengine/godot-demo-projects/tree/master/2d</link>
    </tutorials>
    <methods>
        <method name="apply_scale">
            <return type="void">
            </return>
            <argument index="0" name="ratio" type="Vector2">
            </argument>
            <description>
                Multiplies the current scale by the [code]ratio[/code] vector.
            </description>
        </method>
        [...]
        <method name="translate">
            <return type="void">
            </return>
            <argument index="0" name="offset" type="Vector2">
            </argument>
            <description>
                Translates the node by the given [code]offset[/code] in local coordinates.
            </description>
        </method>
    </methods>
    <members>
        <member name="global_position" type="Vector2" setter="set_global_position" getter="get_global_position">
            Global position.
        </member>
        [...]
        <member name="z_index" type="int" setter="set_z_index" getter="get_z_index" default="0">
            Z index. Controls the order in which the nodes render. A node with a higher Z index will display in front of others.
        </member>
    </members>
    <constants>
    </constants>
</class>

Nó bắt đầu bằng mô tả ngắn và mô tả dài. Trong tài liệu được tạo ra, mô tả ngắn luôn nằm ở đầu trang, còn mô tả dài nằm bên dưới danh sách phương thức, biến và hằng số. Bạn có thể tìm thấy phương thức, biến thành viên, hằng số và signal trong các node XML riêng biệt.

Với mỗi mục, bạn cần tìm hiểu cách chúng hoạt động trong mã nguồn của Godot. Sau đó, điền tài liệu cho chúng bằng cách hoàn thiện hoặc cải thiện văn bản trong các thẻ sau:

  • <brief_description>

  • <description>

  • <constant>

  • <method> (trong thẻ <description> của nó; kiểu trả về và đối số không có chuỗi tài liệu riêng)

  • <member>

  • <signal> (trong thẻ <description> của nó; đối số không có chuỗi tài liệu riêng)

  • <constant>

Hãy viết bằng ngôn ngữ rõ ràng và đơn giản. Luôn tuân theo hướng dẫn viết để giữ mô tả ngắn gọn và dễ đọc. Đừng để dòng trống trong mô tả: mỗi dòng trong file XML sẽ tạo thành một đoạn văn mới, ngay cả khi dòng đó trống.

Cách chỉnh sửa XML của lớp

Chỉnh sửa file của lớp bạn chọn trong doc/classes/ để cập nhật class reference. Thư mục này chứa một file XML cho mỗi lớp. File XML liệt kê các hằng số và phương thức bạn sẽ thấy trong class reference. Godot tự động tạo và cập nhật file XML.

Ghi chú

Với một số module trong mã nguồn của engine, bạn sẽ tìm thấy các file XML trong thư mục modules/<module_name>/doc_classes/ thay vào đó.

Hãy chỉnh sửa nó bằng trình soạn thảo văn bản yêu thích của bạn. Nếu bạn dùng trình soạn thảo mã, hãy đảm bảo dùng tab để thụt lề.

Để kiểm tra xem các sửa đổi của bạn có đúng trong tài liệu được tạo ra hay không, hãy chuyển đến thư mục doc/ và chạy lệnh make rst. Lệnh này sẽ chuyển các file XML sang định dạng của tài liệu trực tuyến và in ra lỗi nếu có gì sai.

Ngoài ra, bạn có thể build Godot và mở trang đã sửa đổi trong tài liệu tham khảo mã dựng sẵn. Để học cách biên dịch engine, hãy đọc hướng dẫn biên dịch.

Chúng tôi khuyên bạn nên dùng trình soạn thảo mã hỗ trợ file XML như Vim, Atom, Visual Studio Code, Notepad++ hoặc trình soạn thảo khác để chỉnh sửa file thoải mái. Bạn cũng có thể dùng tính năng tìm kiếm của chúng để tìm lớp và thuộc tính nhanh chóng.

Mẹo

Nếu dùng Visual Studio Code, bạn có thể cài extension vscode-xml để có linting cho các file XML của class reference.

Cải thiện định dạng bằng các thẻ kiểu BBCode

Class reference XML của Godot hỗ trợ các thẻ giống BBCode để tạo liên kết cũng như định dạng văn bản và mã. Trong các bảng bên dưới, bạn có thể tìm thấy các thẻ có sẵn, ví dụ sử dụng và kết quả sau khi chuyển đổi sang reStructuredText.

Liên kết

Bất cứ khi nào liên kết tới một thành viên của lớp khác, bạn cần chỉ định tên lớp. Với liên kết trong cùng một lớp, tên lớp là tùy chọn và có thể bỏ qua.

Định dạng khối mã

Có hai cách để định dạng khối mã:

  1. Dùng [codeblock] nếu bạn muốn thêm ví dụ cho một ngôn ngữ cụ thể.

  2. Dùng [codeblocks], [gdscript] và [csharp] nếu bạn muốn thêm cùng một ví dụ cho cả hai ngôn ngữ, GDScript và C#.

Theo mặc định, [codeblock] tô sáng cú pháp GDScript. Bạn có thể thay đổi bằng thuộc tính lang. Các tùy chọn hiện được hỗ trợ là:

  • [codeblock lang=text] tắt tô sáng cú pháp;

  • [codeblock lang=gdscript] tô sáng cú pháp GDScript;

  • [codeblock lang=csharp] tô sáng cú pháp C# (chỉ trong phiên bản .NET).

Ghi chú

[codeblock] vô hiệu hóa BBCode cho đến khi parser gặp [/codeblock].

Ví dụ:

[codeblock]
func _ready():
    var sprite = get_node("Sprite2D")
    print(sprite.get_pos())
[/codeblock]

Sẽ hiển thị như sau:

func _ready():
    var sprite = get_node("Sprite2D")
    print(sprite.get_pos())

Nếu bạn cần có phiên bản mã khác nhau cho GDScript và C#, hãy dùng [codeblocks] thay thế. Nếu dùng [codeblocks], bạn cũng cần có ít nhất một trong các thẻ dành riêng cho ngôn ngữ, [gdscript] và [csharp].

Luôn viết ví dụ mã GDScript trước! Bạn có thể dùng công cụ dịch mã thử nghiệm này để tăng tốc quy trình làm việc.

[codeblocks]
[gdscript]
func _ready():
    var sprite = get_node("Sprite2D")
    print(sprite.get_pos())
[/gdscript]
[csharp]
public override void _Ready()
{
    var sprite = GetNode("Sprite2D");
    GD.Print(sprite.GetPos());
}
[/csharp]
[/codeblocks]

Đoạn trên sẽ hiển thị như sau:

func _ready():
    var sprite = get_node("Sprite2D")
    print(sprite.get_pos())

public override void _Ready()
{
    var sprite = GetNode("Sprite2D");
    GD.Print(sprite.GetPos());
}

Định dạng ghi chú và cảnh báo

Để đánh dấu thông tin quan trọng, hãy thêm một đoạn văn bắt đầu bằng "[b]Note:[/b]" vào cuối phần mô tả:

[b]Note:[/b] Only available when using the Forward+ renderer.

Để đánh dấu thông tin then chốt có thể gây ra vấn đề bảo mật hoặc mất dữ liệu nếu không được tuân thủ cẩn thận, hãy thêm một đoạn văn bắt đầu bằng "[b]Warning:[/b]" vào cuối phần mô tả:

[b]Warning:[/b] If this property is set to [code]true[/code], it allows clients to execute arbitrary code on the server.

Trong tất cả các đoạn văn được mô tả ở trên, hãy đảm bảo dấu câu nằm bên trong thẻ BBCode để đảm bảo tính nhất quán.

Đánh dấu API là deprecated/experimental

Để đánh dấu một API là deprecated hoặc experimental, bạn cần thêm thuộc tính XML tương ứng. Giá trị của thuộc tính phải là một thông điệp giải thích vì sao API không được khuyến nghị (hỗ trợ markup BBCode) hoặc một chuỗi rỗng (thông điệp mặc định sẽ được dùng). Nếu một phần tử API được đánh dấu là deprecated/experimental, nó được coi là đã có tài liệu ngay cả khi mô tả trống.

<class name="Parallax2D" inherits="Node2D" experimental="This node is meant to replace [ParallaxBackground] and [ParallaxLayer]. The implementation may change in the future." xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xsi:noNamespaceSchemaLocation="../class.xsd">
    [...]
</class>

<constant name="RESPONSE_USE_PROXY" value="305" enum="ResponseCode" deprecated="Many clients ignore this response code for security reasons. It is also deprecated by the HTTP standard.">
    HTTP status code [code]305 Use Proxy[/code].
</constant>

<member name="auto_translate" type="bool" setter="set_auto_translate" getter="is_auto_translating" deprecated="Use [member Node.auto_translate_mode] instead.">
    Toggles if any text should automatically change to its translated version depending on the current locale.
</member>

<method name="get_method_call_mode" qualifiers="const" deprecated="Use [member AnimationMixer.callback_mode_method] instead.">
    <return type="int" enum="AnimationPlayer.AnimationMethodCallMode" />
    <description>
        Returns the call mode used for "Call Method" tracks.
    </description>
</method>
