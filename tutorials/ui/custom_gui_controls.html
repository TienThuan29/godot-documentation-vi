Đang cập nhật

Nội dung trang này chưa được cập nhật cho Godot 4.7 và có thể đã lỗi thời. Nếu bạn biết cách cải thiện trang này hoặc xác nhận được rằng nó vẫn đúng, hãy gửi một pull request (bản tiếng Anh).

Control GUI tùy chỉnh

Thật nhiều control...

Nhưng vẫn không bao giờ là đủ. Tự tạo control tùy chỉnh hoạt động đúng như ý muốn là nỗi ám ảnh của hầu hết lập trình viên GUI. Godot cung cấp rất nhiều control, nhưng chúng có thể không hoạt động chính xác như bạn muốn. Trước khi liên hệ các nhà phát triển với một pull request để hỗ trợ thanh cuộn chéo, ít nhất bạn cũng nên biết cách tạo những control này một cách dễ dàng từ script.

Vẽ

Về việc vẽ, bạn nên xem bài hướng dẫn Vẽ tùy chỉnh trong 2D. Những điều tương tự cũng áp dụng ở đây. Một số hàm đáng được nhắc đến vì tính hữu ích khi vẽ, nên chúng sẽ được trình bày chi tiết sau đây:

Kiểm tra kích thước control

Không giống node 2D, "kích thước" rất quan trọng với control, vì nó giúp sắp xếp chúng trong các bố cục phù hợp. Để làm việc này, thuộc tính Control.size được cung cấp. Kiểm tra nó trong _draw() là điều thiết yếu để đảm bảo mọi thứ nằm trong giới hạn.

Kiểm tra focus

Một số control (như nút bấm hoặc trình soạn thảo văn bản) có thể nhận focus đầu vào cho bàn phím hoặc tay cầm. Ví dụ như nhập văn bản hoặc nhấn nút. Điều này được điều khiển bằng thuộc tính Control.focus_mode. Khi vẽ, nếu control hỗ trợ focus đầu vào, bạn luôn nên hiển thị một dạng chỉ báo nào đó (tô sáng, khung, v.v.) để cho biết đây là control đang được focus. Để kiểm tra trạng thái này, có phương thức Control.has_focus(). Ví dụ

func _draw():
    if has_focus():
         draw_selected()
    else:
         draw_normal()

public override void _Draw()
{
    if (HasFocus())
    {
        DrawSelected()
    }
    else
    {
        DrawNormal();
    }
}

Định kích thước

Như đã đề cập, kích thước rất quan trọng với control. Nó giúp chúng được bố trí đúng khi đặt vào lưới, container hoặc được neo (anchor). Phần lớn thời gian, control cung cấp một kích thước tối thiểu để giúp bố trí chúng đúng cách. Ví dụ, nếu các control được xếp chồng theo chiều dọc bằng VBoxContainer, kích thước tối thiểu sẽ đảm bảo control tùy chỉnh của bạn không bị các control khác trong container chèn ép.

Để cung cấp callback này, chỉ cần ghi đè Control._get_minimum_size(), ví dụ:

func _get_minimum_size():
    return Vector2(30, 30)

public override Vector2 _GetMinimumSize()
{
    return new Vector2(20, 20);
}

Hoặc, đặt nó bằng một hàm:

func _ready():
    set_custom_minimum_size(Vector2(30, 30))

public override void _Ready()
{
    CustomMinimumSize = new Vector2(20, 20);
}

Đầu vào

Control cung cấp một vài công cụ hỗ trợ giúp quản lý sự kiện input dễ dàng hơn nhiều so với node thông thường.

Sự kiện input

Đã có một vài bài hướng dẫn về đầu vào trước bài này, nhưng cần nhắc rằng control có một phương thức input đặc biệt chỉ hoạt động khi:

  • Con trỏ chuột nằm trên control.

  • Nút được nhấn khi đang ở trên control này (control luôn giữ đầu vào cho đến khi nút được nhả)

  • Control cung cấp focus bàn phím/tay cầm thông qua Control.focus_mode.

Hàm này là Control._gui_input(). Để dùng nó, hãy ghi đè nó trong control của bạn. Không cần thiết lập xử lý (processing) nào.

extends Control

func _gui_input(event):
   if event is InputEventMouseButton and event.button_index == MOUSE_BUTTON_LEFT and event.pressed:
       print("Left mouse button was pressed!")

public override void _GuiInput(InputEvent @event)
{
    if (@event is InputEventMouseButton mbe && mbe.ButtonIndex == MouseButton.Left && mbe.Pressed)
    {
        GD.Print("Left mouse button was pressed!");
    }
}

Để biết thêm thông tin về bản thân các sự kiện, hãy xem bài hướng dẫn Sử dụng InputEvent.

Notification

Control cũng có nhiều thông báo (notification) hữu ích mà không có callback riêng, nhưng có thể kiểm tra bằng callback _notification:

func _notification(what):
    match what:
        NOTIFICATION_MOUSE_ENTER:
            pass # Mouse entered the area of this control.
        NOTIFICATION_MOUSE_EXIT:
            pass # Mouse exited the area of this control.
        NOTIFICATION_FOCUS_ENTER:
            pass # Control gained focus.
        NOTIFICATION_FOCUS_EXIT:
            pass # Control lost focus.
        NOTIFICATION_THEME_CHANGED:
            pass # Theme used to draw the control changed;
            # update and redraw is recommended if using a theme.
        NOTIFICATION_VISIBILITY_CHANGED:
            pass # Control became visible/invisible;
            # check new status with is_visible().
        NOTIFICATION_RESIZED:
            pass # Control changed size; check new size
            # with get_size().
        NOTIFICATION_MODAL_CLOSE:
            pass # For modal pop-ups, notification
            # that the pop-up was closed.

public override void _Notification(int what)
{
    switch (what)
    {
        case NotificationMouseEnter:
            // Mouse entered the area of this control.
            break;

        case NotificationMouseExit:
            // Mouse exited the area of this control.
            break;

        case NotificationFocusEnter:
            // Control gained focus.
            break;

        case NotificationFocusExit:
            // Control lost focus.
            break;

        case NotificationThemeChanged:
            // Theme used to draw the control changed;
            // update and redraw is recommended if using a theme.
            break;

        case NotificationVisibilityChanged:
            // Control became visible/invisible;
            // check new status with is_visible().
            break;

        case NotificationResized:
            // Control changed size; check new size with get_size().
            break;

        case NotificationModalClose:
            // For modal pop-ups, notification that the pop-up was closed.
            break;
    }
}
