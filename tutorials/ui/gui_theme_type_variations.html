Biến thể theme type

Khi thiết kế giao diện người dùng, có lúc một node Control cần có giao diện khác với những gì thường được định nghĩa bởi Theme. Mọi control node đều có theme property override, cho phép bạn định nghĩa lại kiểu dáng cho từng phần tử UI riêng lẻ.

Cách làm này nhanh chóng trở nên khó quản lý nếu bạn cần dùng chung một giao diện tùy chỉnh giữa nhiều control. Hãy tưởng tượng bạn dùng các biến thể xám, xanh dương và đỏ của Button khắp dự án. Thiết lập nó mỗi lần thêm một phần tử nút mới vào giao diện là một việc tẻ nhạt.

Để giúp tổ chức và tận dụng tốt hơn sức mạnh của theme, bạn có thể dùng theme type variation. Chúng hoạt động như các theme type thông thường, nhưng thay vì tự đủ và độc lập, chúng mở rộng một type cơ sở khác.

Tiếp theo ví dụ trước, theme của bạn có thể có một số style, màu và font được định nghĩa cho type Button, tùy chỉnh giao diện của mọi phần tử nút trong UI. Để có nút xám, đỏ hoặc xanh dương, bạn sẽ tạo một type mới, ví dụ GrayButton, và đánh dấu nó là variation của type cơ sở Button.

Type variation có thể thay thế một số khía cạnh của type cơ sở, nhưng giữ lại các khía cạnh khác. Chúng cũng có thể định nghĩa các thuộc tính mà style cơ sở chưa định nghĩa. Ví dụ, GrayButton của bạn có thể ghi đè style normal từ Button cơ sở và thêm font_color mà Button chưa từng định nghĩa. Control sẽ dùng kết hợp cả hai type, ưu tiên type variation.

Ghi chú

Cách control xác định theme item nào được dùng từ mỗi type và mỗi theme được mô tả rõ hơn trong mục Tùy chỉnh một dự án của bài viết "Giới thiệu về GUI skinning".

Tạo một biến thể type

Để tạo một type variation, hãy mở theme editor, rồi click vào icon dấu cộng cạnh dropdown Type ở phía bên phải của trình chỉnh sửa. Gõ tên bạn muốn đặt cho theme type variation vào ô văn bản, rồi click Add Type.

Bên dưới dropdown Type là các tab thuộc tính. Chuyển sang tab có icon cờ lê và tua vít.

Click vào icon dấu cộng cạnh trường Base Type. Bạn có thể chọn type cơ sở tại đó, thường là tên của một lớp control node (ví dụ Button, Label, v.v.). Type variation cũng có thể nối chuỗi và mở rộng các type variation khác. Điều này hoạt động giống như cách control node kế thừa kiểu dáng từ lớp cơ sở của chúng. Ví dụ, CheckButton kế thừa style từ Button vì các loại node tương ứng mở rộng lẫn nhau.

Sau khi chọn type cơ sở, giờ bạn sẽ thấy các thuộc tính của nó trên các tab khác trong theme editor. Bạn có thể chỉnh sửa chúng như bình thường.

Sử dụng một biến thể type

Giờ type variation đã được tạo, bạn có thể áp dụng nó cho các node. Trong inspector dock, dưới thuộc tính Theme của một control node, bạn có thể tìm thấy thuộc tính Theme Type Variation. Mặc định nó trống, nghĩa là chỉ type cơ sở có tác dụng lên node này.

Bạn có thể chọn type variation từ danh sách dropdown, hoặc nhập tên của nó thủ công. Variation chỉ xuất hiện trong danh sách nếu type variation thuộc về theme toàn dự án, mà bạn có thể cấu hình trong cài đặt dự án. Với mọi trường hợp khác, bạn phải nhập tên variation thủ công. Click vào icon bút chì ở bên phải. Sau đó gõ tên type variation và click icon dấu tích hoặc nhấn enter. Nếu tồn tại type variation có tên đó, node sẽ sử dụng nó.
