Tích hợp với các API Android

Nền tảng Android có rất nhiều API cùng một hệ sinh thái thư viện bên thứ ba phong phú với các chức năng rộng và đa dạng, như thông báo đẩy, phân tích, xác thực, quảng cáo, v.v...

Những thứ này không phù hợp để đưa vào lõi Godot, nên từ lâu Godot đã cung cấp một hệ thống plugin Android. Hệ thống plugin Android cho phép nhà phát triển tạo plugin Godot Android bằng mã Java hoặc Kotlin, cung cấp giao diện để truy cập và dùng các API Android hoặc thư viện bên thứ ba trong dự án Godot từ GDScript, C# hoặc GDExtension.

class MyAndroidSingleton(godot: Godot?) : GodotPlugin(godot) {
        @UsedByGodot
        fun doSomething(value: String) {
                // ...
        }
}

Tuy nhiên, viết plugin Android đòi hỏi kiến thức về Java hoặc Kotlin, điều mà phần lớn nhà phát triển Godot không có. Vì vậy, có nhiều API Android và thư viện bên thứ ba không có plugin Godot để nhà phát triển giao tiếp. Thực tế, đây là một trong những lý do chính mà nhà phát triển nêu ra khi không thể chuyển sang Godot từ các game engine khác.

Để giải quyết vấn đề này, chúng tôi đã giới thiệu một vài công cụ trong Godot 4.4 nhằm đơn giản hóa quá trình truy cập các API Android và thư viện bên thứ ba cho nhà phát triển.

JavaClassWrapper (singleton của Godot)

JavaClassWrapper là một singleton của Godot cho phép tạo instance của các lớp Java / Kotlin, triển khai các interface Java / Kotlin và gọi phương thức trên chúng chỉ bằng GDScript, C# hoặc GDExtension.

var LocalDateTime = JavaClassWrapper.wrap("java.time.LocalDateTime")
var DateTimeFormatter = JavaClassWrapper.wrap("java.time.format.DateTimeFormatter")

var datetime = LocalDateTime.now()
var formatter = DateTimeFormatter.ofPattern("dd-MM-yyyy HH:mm:ss")

print(datetime.format(formatter))

Trong đoạn mã trên, JavaClassWrapper được dùng từ GDScript để truy cập các lớp Java LocalDateTime và DateTimeFormatter. Thông qua JavaClassWrapper, chúng ta có thể gọi trực tiếp phương thức của các lớp Java từ GDScript như thể chúng là phương thức GDScript.

class PrintProxy:
    func println(content: String) -> void:
        print(content)

var print_proxy = PrintProxy.new()
var printer_object = JavaClassWrapper.create_proxy(print_proxy, ["android.util.Printer"])
printer_object.println("Hello Godot World!")

Trong đoạn mã trên, JavaClassWrapper được dùng để triển khai interface Java android.util.Printer từ GDScript, dùng một Object làm phần triển khai. Proxy được tạo instance sau đó có thể được truyền vào các phương thức Java nhận tham số android.util.Printer.

Hãy xem tài liệu JavaClassWrapper để tìm hiểu thêm về API của nó.

Plugin AndroidRuntime

JavaClassWrapper rất tuyệt, nhưng để làm nhiều việc trên Android, bạn cần truy cập nhiều đối tượng vòng đời / runtime khác nhau của Android. Plugin AndroidRuntime là một plugin Godot Android tích hợp sẵn cho phép bạn làm điều này.

Kết hợp JavaClassWrapper với plugin AndroidRuntime cho phép nhà phát triển truy cập và dùng các API Android mà không cần rời khỏi GDScript hay dùng bất kỳ công cụ nào ngoài chính Godot. Đây là một bước tiến rất lớn cho việc áp dụng Godot vào phát triển Android:

  • Nếu bạn cần làm một việc đơn giản, hoặc chỉ dùng một phần nhỏ của thư viện bên thứ ba, bạn không cần tạo plugin

  • Nó cho phép nhà phát triển nhanh chóng tích hợp chức năng Android

  • Nó cho phép nhà phát triển tạo addon Godot chỉ bằng GDScript và JavaClassWrapper (không cần Java hay Kotlin)

Ghi chú

Với các bản xuất dùng gradle, Godot sẽ tự động đưa vào các tệp .jar hoặc .aar mà nó tìm thấy trong thư mục addons của dự án. Vì vậy, để dùng một thư viện bên thứ ba, bạn chỉ cần thả tệp .jar hoặc .aar của nó vào thư mục addons và gọi phương thức của nó trực tiếp từ GDScript bằng JavaClassWrapper.

Ví dụ: Hiển thị toast Android

# Retrieve the AndroidRuntime singleton.
var android_runtime = Engine.get_singleton("AndroidRuntime")
if android_runtime:
    # Retrieve the Android Activity instance.
    var activity = android_runtime.getActivity()

    # Create a Godot Callable to wrap the toast display logic.
    var toast_callable = func():
        # Use JavaClassWrapper to retrieve the android.widget.Toast class, then make and show a toast using the class APIs.
        var ToastClass = JavaClassWrapper.wrap("android.widget.Toast")
        ToastClass.makeText(activity, "This is a test", ToastClass.LENGTH_LONG).show()

    # Wrap the Callable in a Java Runnable and run it on the Android UI thread to show the toast.
    activity.runOnUiThread(android_runtime.createRunnableFromGodotCallable(toast_callable))

Ví dụ: Rung thiết bị

# Retrieve the AndroidRuntime singleton.
var android_runtime = Engine.get_singleton("AndroidRuntime")
if android_runtime:
    # Retrieve the Android Vibrator system service and check if the device supports it.
    var vibrator_service = android_runtime.getApplicationContext().getSystemService("vibrator")
    if vibrator_service and vibrator_service.hasVibrator():
        # Configure and run a VibrationEffect.
        var VibrationEffect = JavaClassWrapper.wrap("android.os.VibrationEffect")
        var effect = VibrationEffect.createOneShot(500, VibrationEffect.DEFAULT_AMPLITUDE)
        vibrator_service.vibrate(effect)

Ví dụ: Truy cập lớp lồng (inner class)

Có thể truy cập lớp lồng của Java bằng ký hiệu $:

# Accessing 'VERSION' class, which is an inner class from the 'android.os.Build' class.
var version = JavaClassWrapper.wrap("android.os.Build$VERSION")
var sdk_int = version.SDK_INT
if sdk_int == 30:
    # Do something specific on android 11 devices.
else:
    # All other devices

Ví dụ: Gọi constructor

Constructor được gọi bằng cách gọi một phương thức có cùng tên với lớp.

Ví dụ này tạo một intent để gửi văn bản:

# Retrieve the AndroidRuntime singleton.
var android_runtime = Engine.get_singleton("AndroidRuntime")
if android_runtime:
    var Intent = JavaClassWrapper.wrap("android.content.Intent")
    var activity = android_runtime.getActivity()
    var intent = Intent.Intent() # Call the constructor.
    intent.setAction(Intent.ACTION_SEND)
    intent.putExtra(Intent.EXTRA_TEXT, "This is a test message.")
    intent.setType("text/plain")
    activity.startActivity(intent)

Ví dụ: Lưu ảnh vào thư viện ảnh Android

# Retrieve the AndroidRuntime singleton.
var android_runtime = Engine.get_singleton("AndroidRuntime")
if android_runtime:
    var Intent = JavaClassWrapper.wrap("android.content.Intent")
    var activity = android_runtime.getActivity()
    var intent = Intent.Intent()

    # Create the File and Uri.
    var Uri = JavaClassWrapper.wrap("android.net.Uri")
    var File = JavaClassWrapper.wrap("java.io.File")
    var file = File.File(file_path_to_image_here)
    var uri = Uri.fromFile(file)

    # Set Action and Data of Intent.
    intent.setAction(Intent.ACTION_MEDIA_SCANNER_SCAN_FILE)
    intent.setData(uri)

    # Broadcast it.
    activity.sendBroadcast(intent)
