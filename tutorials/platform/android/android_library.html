Thư viện Godot Android

Godot Engine cho nền tảng Android được thiết kế để dùng như một thư viện Android. Kiến trúc này mở ra một số tính năng quan trọng trên nền tảng Android:

  • Khả năng tích hợp hệ thống build Gradle vào trình chỉnh sửa Godot, giúp tận dụng thêm nhiều thành phần từ hệ sinh thái Android như thư viện và công cụ

  • Khả năng làm cho engine có tính di động và có thể nhúng:

    • Yếu tố then chốt giúp port trình chỉnh sửa Godot sang Android và các thiết bị XR di động

    • Yếu tố then chốt cho phép tích hợp và tái sử dụng các khả năng của Godot trong codebase sẵn có

Dưới đây chúng tôi mô tả một số trường hợp sử dụng và kịch bản mà kiến trúc này mang lại.

Sử dụng thư viện Godot Android

Thư viện Godot Android được đóng gói dưới dạng tệp lưu trữ AAR và được lưu trữ trên MavenCentral cùng với tài liệu của nó.

Nó cung cấp quyền truy cập vào các API và khả năng của Godot trên nền tảng Android cho các trường hợp sử dụng sau (danh sách chưa đầy đủ).

Plugin Godot Android

Plugin Android là công cụ mạnh mẽ để mở rộng khả năng của Godot Engine bằng cách khai thác các chức năng do nền tảng và hệ sinh thái Android cung cấp.

Một plugin Android là một thư viện Android phụ thuộc vào thư viện Godot Android, thư viện mà plugin dùng để tích hợp vào vòng đời của engine và truy cập các API của Godot, mang lại cho plugin những khả năng mạnh mẽ như hỗ trợ GDExtension, cho phép cập nhật / mod hành vi của engine khi cần.

Để biết thêm thông tin, hãy xem Plugin Godot Android.

Nhúng Godot vào dự án Android sẵn có

Godot Engine có thể được nhúng vào các ứng dụng hoặc thư viện Android sẵn có, cho phép nhà phát triển tận dụng mã và thư viện đã trưởng thành, đã được kiểm chứng thực tế và phù hợp hơn cho một tác vụ cụ thể.

Thành phần host chịu trách nhiệm điều khiển vòng đời của engine thông qua các API Android của Godot. Các API này cũng có thể được dùng để giao tiếp hai chiều giữa host và instance Godot được nhúng, cho phép kiểm soát tốt hơn trải nghiệm mong muốn.

Chúng tôi minh họa cách làm việc này bằng một ứng dụng Android mẫu nhúng Godot Engine dưới dạng một Android view và dùng nó để kết xuất các mô hình glTF 3D.

Ứng dụng mẫu GLTF Viewer dùng một thành phần Android RecyclerView để tạo danh sách các mục glTF, lấy dữ liệu từ gói Food Kit của Kenney. Khi một mục trong danh sách được chọn, logic của ứng dụng sẽ tương tác với Godot Engine được nhúng để kết xuất mục glTF đã chọn thành mô hình 3D.

Mã nguồn của ứng dụng mẫu có trên GitHub. Hãy làm theo hướng dẫn trong README của nó để build và cài đặt.

Dưới đây chúng tôi phân tích các bước dùng để tạo ứng dụng GLTF Viewer.

Cảnh báo

Hiện tại mỗi tiến trình chỉ hỗ trợ một instance Godot Engine duy nhất. Bạn có thể cấu hình tiến trình mà Android Activity chạy trong đó bằng thuộc tính android:process.

Cảnh báo

Các sự kiện tự động thay đổi kích thước / cấu hình hướng màn hình không được hỗ trợ và có thể gây crash. Bạn có thể tắt các sự kiện đó:

  • Bằng cách khóa ở một hướng màn hình cụ thể với thuộc tính android:screenOrientation.

  • Bằng cách khai báo rằng Activity sẽ tự xử lý các sự kiện cấu hình này với thuộc tính android:configChanges.

1. Tạo ứng dụng Android

Ghi chú

Ứng dụng Android mẫu được tạo bằng Android Studio và dùng Gradle làm hệ thống build.

Hệ sinh thái Android cung cấp nhiều công cụ, IDE và hệ thống build để tạo ứng dụng Android, nên bạn cứ thoải mái dùng thứ mình quen thuộc và điều chỉnh các bước dưới đây cho phù hợp (chúng tôi cũng rất hoan nghênh đóng góp cho tài liệu này!).

  • Thiết lập một dự án ứng dụng Android. Đó có thể là một dự án trống hoàn toàn mới hoặc một dự án sẵn có

  • Thêm maven dependency cho thư viện Godot Android

    • Nếu dùng gradle, hãy thêm nội dung sau vào phần dependency trong tệp build gradle của ứng dụng. Nhớ cập nhật <version> thành phiên bản mới nhất của thư viện Godot Android:

    implementation("org.godotengine:godot:<version>")

  • Nếu dùng gradle, hãy thêm cấu hình aaptOptions sau vào phần android > defaultConfig trong tệp build gradle của ứng dụng. Làm vậy cho phép gradle đưa các thư mục ẩn của Godot vào khi build tệp nhị phân của ứng dụng.

    • Nếu hệ thống build của bạn không hỗ trợ đưa vào các thư mục ẩn, bạn có thể cấu hình dự án Godot không dùng thư mục ẩn bằng cách bỏ chọn Application > Config > Use Hidden Project Data Directory trong Project Settings.

android {

  defaultConfig {
      // The default ignore pattern for the 'assets' directory includes hidden files and
      // directories which are used by Godot projects, so we override it with the following.
      aaptOptions {
          ignoreAssetsPattern "!.svn:!.git:!.gitignore:!.ds_store:!*.scc:<dir>_*:!CVS:!thumbs.db:!picasa.ini:!*~"
      }
    ...

  • Tạo / cập nhật Activity của ứng dụng sẽ host instance Godot Engine. Với ứng dụng mẫu, đó là MainActivity

    • Activity host cần triển khai interface GodotHost

    • Ứng dụng mẫu dùng Fragments để tổ chức giao diện, nên nó dùng GodotFragment, một thành phần fragment do thư viện Godot Android cung cấp để tự động host và quản lý instance Godot Engine.

    private var godotFragment: GodotFragment? = null

override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)

    setContentView(R.layout.activity_main)

    val currentGodotFragment = supportFragmentManager.findFragmentById(R.id.godot_fragment_container)
    if (currentGodotFragment is GodotFragment) {
        godotFragment = currentGodotFragment
    } else {
        godotFragment = GodotFragment()
        supportFragmentManager.beginTransaction()
            .replace(R.id.godot_fragment_container, godotFragment!!)
            .commitNowAllowingStateLoss()
    }

    ...

Ghi chú

Thư viện Godot Android cũng cung cấp GodotActivity, một thành phần Activity có thể kế thừa để tự động host và quản lý instance Godot Engine.

Ngoài ra, ứng dụng có thể trực tiếp tạo một instance Godot, rồi tự host và quản lý nó.

  • Dùng GodotHost#getHostPlugins(...), ứng dụng mẫu tạo một instance GodotPlugin lúc chạy dùng để gửi signal tới logic gdscript

    • GodotPlugin lúc chạy cũng có thể được logic gdscript dùng để truy cập các phương thức JVM. Để biết thêm thông tin, hãy xem Plugin Godot Android.

  • Thêm mọi logic bổ sung mà ứng dụng của bạn sẽ dùng

    • Với ứng dụng mẫu, việc này bao gồm thêm fragment ItemsSelectionFragment (và các lớp liên quan), một fragment dùng để xây dựng và hiển thị danh sách các mục glTF

  • Mở tệp AndroidManifest.xml và cấu hình hướng màn hình nếu cần bằng thuộc tính android:screenOrientation

    • Nếu cần, hãy tắt các thay đổi cấu hình tự động thay đổi kích thước / hướng màn hình bằng thuộc tính android:configChanges

<activity android:name=".MainActivity"
    android:screenOrientation="fullUser"
    android:configChanges="orientation|screenSize|smallestScreenSize|screenLayout"
    android:exported="true">

    ...
</activity>

2. Tạo dự án Godot

Ghi chú

Trên Android, các tệp dự án Godot được xuất vào thư mục assets của tệp nhị phân apk được tạo ra.

Chúng tôi tận dụng kiến trúc đó để gắn kết ứng dụng Android và dự án Godot bằng cách tạo dự án Godot trong thư mục assets của ứng dụng Android.

Lưu ý rằng bạn cũng có thể tạo dự án Godot trong một thư mục riêng và xuất nó thành tệp PCK hoặc ZIP vào thư mục assets của ứng dụng Android. Cách này yêu cầu truyền đối số --main-pack <pck_or_zip_filepath_relative_to_assets_dir> cho instance Godot Engine được host bằng GodotHost#getCommandLine().

Ví dụ:

@Override
public List<String> getCommandLine(){
    List<String> results = new ArrayList<>();
    results.addAll(super.getCommandLine());
    results.add("--main-pack");
    results.add("res://foo.pck");
    return results;
}

Hướng dẫn dưới đây và ứng dụng mẫu theo cách thứ nhất: tạo dự án Godot trong thư mục assets của ứng dụng Android.

  • Như đã nêu trong ghi chú ở trên, hãy mở trình chỉnh sửa Godot và tạo một dự án Godot trực tiếp (không có thư mục con) trong thư mục assets của dự án ứng dụng Android

    • Tham khảo dự án Godot của ứng dụng mẫu

  • Cấu hình dự án Godot theo ý muốn

    • Đảm bảo hướng màn hình đặt cho dự án Godot khớp với hướng đặt trong manifest của ứng dụng Android

    • Với Android, đảm bảo textures/vram_compression/import_etc2_astc được đặt thành true

  • Cập nhật logic script của dự án Godot khi cần

    • Với ứng dụng mẫu, logic script truy vấn instance GodotPlugin lúc chạy và dùng nó để đăng ký nhận các signal do logic ứng dụng phát ra

    • Logic ứng dụng phát ra một signal mỗi khi một mục trong danh sách được chọn. Signal chứa đường dẫn tệp của mô hình glTF, được logic gdscript dùng để kết xuất mô hình.

    extends Node3D

# Reference to the gltf model that's currently being shown.
var current_gltf_node: Node3D = null

func _ready():
  # Default asset to load when the app starts
  _load_gltf("res://gltfs/food_kit/turkey.glb")

  var appPlugin = Engine.get_singleton("AppPlugin")
  if appPlugin:
    print("App plugin is available")

    # Signal fired from the app logic to update the gltf model being shown
    appPlugin.connect("show_gltf", _load_gltf)
  else:
    print("App plugin is not available")


# Load the gltf model specified by the given path
func _load_gltf(gltf_path: String):
  if current_gltf_node != null:
    remove_child(current_gltf_node)

  current_gltf_node = load(gltf_path).instantiate()

  add_child(current_gltf_node)

3. Build và chạy ứng dụng

Sau khi hoàn tất cấu hình dự án Godot, hãy build và chạy ứng dụng Android. Nếu được thiết lập đúng, Activity host sẽ khởi tạo Godot Engine được nhúng khi khởi động. Godot Engine sẽ kiểm tra thư mục assets để tìm các tệp dự án cần tải (trừ khi được cấu hình để tìm một main pack), rồi tiến hành chạy dự án.

Khi ứng dụng đang chạy trên thiết bị, bạn có thể xem Android logcat để điều tra mọi lỗi hoặc crash.

Để tham khảo, hãy xem hướng dẫn build và cài đặt của ứng dụng mẫu GLTF Viewer.
