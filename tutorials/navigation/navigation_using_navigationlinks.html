Sử dụng NavigationLink

NavigationLink được dùng để kết nối các đa giác navigation mesh từ NavigationRegion2D và NavigationRegion3D qua khoảng cách bất kỳ để phục vụ tìm đường.

NavigationLink cũng được dùng để tính đến các lối tắt di chuyển trong tìm đường có được nhờ tương tác với các đối tượng gameplay, ví dụ thang, bệ nhảy hoặc dịch chuyển tức thời.

Phiên bản 2D và 3D của các node NavigationJumplink lần lượt là NavigationLink2D và NavigationLink3D.

Các NavigationRegion khác nhau có thể kết nối navigation mesh của chúng mà không cần NavigationLink, miễn là chúng có các cạnh chồng lấn hoặc các cạnh nằm trong edge_connection_margin của navigation map. Khi khoảng cách trở nên quá lớn, việc tạo các kết nối hợp lệ trở thành vấn đề - một vấn đề mà NavigationLink có thể giải quyết.

Xem Sử dụng NavigationRegion để tìm hiểu thêm về cách dùng navigation region. Xem Kết nối các navigation mesh để tìm hiểu thêm về cách kết nối các navigation mesh.

NavigationLink có chung nhiều thuộc tính với NavigationRegion, như navigation_layers. NavigationLink thêm một kết nối duy nhất giữa hai vị trí qua khoảng cách bất kỳ, trong khi NavigationRegion thêm một khu vực có thể đi qua mang tính cục bộ hơn với một resource navigation mesh.

NavigationLink có start_position và end_position và có thể đi theo cả hai chiều khi bidirectional được bật. Khi được đặt vào, một navigationlink sẽ kết nối các đa giác navigation mesh gần nhất với start_position và end_position của nó trong phạm vi bán kính tìm kiếm để phục vụ tìm đường.

Bán kính tìm kiếm đa giác có thể được cấu hình toàn cục trong ProjectSettings tại navigation/2d_or_3d/default_link_connection_radius hoặc đặt riêng cho từng navigation map bằng hàm NavigationServer.map_set_link_connection_radius().

Cả start_position và end_position đều có marker debug trong Editor. Các mũi tên cho biết link có thể được đi qua theo hướng nào, và bán kính hiển thị của một vị trí thể hiện bán kính tìm kiếm đa giác. Tất cả các đa giác navigation mesh bên trong được so sánh và đa giác gần nhất được chọn cho kết nối cạnh. Nếu không tìm thấy đa giác hợp lệ nào trong bán kính tìm kiếm, navigation link sẽ bị vô hiệu hóa.

Hiển thị debug của link có thể được thay đổi trong ProjectSettings của Editor tại debug/shapes/navigation. Khả năng hiển thị debug cũng có thể được điều khiển trong menu gizmo của Viewport 3D trong Editor.

Navigation link không cung cấp bất kỳ kiểu di chuyển chuyên biệt nào qua link. Thay vào đó, khi agent đến vị trí của một link, code game cần phản ứng (ví dụ qua area trigger) và cung cấp cách để agent di chuyển qua link và đến vị trí còn lại của link (ví dụ qua dịch chuyển tức thời hoặc hoạt ảnh). Nếu không, agent sẽ cố tự di chuyển dọc theo đường đi của link. Bạn có thể gặp tình trạng agent đi qua một hố sâu không đáy thay vì chờ bệ di chuyển, hoặc đi xuyên qua thiết bị dịch chuyển rồi tiếp tục đi xuyên tường.

Script template cho navigation link

Script sau dùng NavigationServer để tạo một navigation link mới.

extends Node2D

var link_rid: RID
var link_start_position: Vector2
var link_end_position: Vector2

func _ready() -> void:
    link_rid = NavigationServer2D.link_create()

    var link_owner_id: int = get_instance_id()
    var link_enter_cost: float = 1.0
    var link_travel_cost: float = 1.0
    var link_navigation_layers: int = 1
    var link_bidirectional: bool = true

    NavigationServer2D.link_set_owner_id(link_rid, link_owner_id)
    NavigationServer2D.link_set_enter_cost(link_rid, link_enter_cost)
    NavigationServer2D.link_set_travel_cost(link_rid, link_travel_cost)
    NavigationServer2D.link_set_navigation_layers(link_rid, link_navigation_layers)
    NavigationServer2D.link_set_bidirectional(link_rid, link_bidirectional)

    # Enable the link and set it to the default navigation map.
    NavigationServer2D.link_set_enabled(link_rid, true)
    NavigationServer2D.link_set_map(link_rid, get_world_2d().get_navigation_map())

    # Move the 2 link positions to their intended global positions.
    NavigationServer2D.link_set_start_position(link_rid, link_start_position)
    NavigationServer2D.link_set_end_position(link_rid, link_end_position)

using Godot;

public partial class MyNode2D : Node2D
{
    private Rid _linkRid;
    private Vector2 _linkStartPosition;
    private Vector2 _linkEndPosition;

    public override void _Ready()
    {
        _linkRid = NavigationServer2D.LinkCreate();

        ulong linkOwnerId = GetInstanceId();
        float linkEnterCost = 1.0f;
        float linkTravelCost = 1.0f;
        uint linkNavigationLayers = 1;
        bool linkBidirectional = true;

        NavigationServer2D.LinkSetOwnerId(_linkRid, linkOwnerId);
        NavigationServer2D.LinkSetEnterCost(_linkRid, linkEnterCost);
        NavigationServer2D.LinkSetTravelCost(_linkRid, linkTravelCost);
        NavigationServer2D.LinkSetNavigationLayers(_linkRid, linkNavigationLayers);
        NavigationServer2D.LinkSetBidirectional(_linkRid, linkBidirectional);

        // Enable the link and set it to the default navigation map.
        NavigationServer2D.LinkSetEnabled(_linkRid, true);
        NavigationServer2D.LinkSetMap(_linkRid, GetWorld2D().NavigationMap);

        // Move the 2 link positions to their intended global positions.
        NavigationServer2D.LinkSetStartPosition(_linkRid, _linkStartPosition);
        NavigationServer2D.LinkSetEndPosition(_linkRid, _linkEndPosition);
    }
}
