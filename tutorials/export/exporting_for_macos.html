Xuất cho macOS

Xem thêm

Trang này mô tả cách xuất một dự án Godot sang macOS. Nếu bạn muốn biên dịch các binary của trình chỉnh sửa hoặc export template từ mã nguồn, hãy đọc Biên dịch cho macOS.

Các ứng dụng macOS xuất bằng export template chính thức được xuất dưới dạng một bundle .app binary "Universal 2" duy nhất, tức một thư mục có cấu trúc riêng chứa file thực thi, thư viện và toàn bộ file của dự án. Bundle này có thể được xuất nguyên dạng, nén trong file ZIP, hoặc đóng gói trong ảnh đĩa DMG (chỉ hỗ trợ khi xuất từ macOS). Universal binary cho macOS hỗ trợ cả kiến trúc Intel x86_64 và ARM64 (Apple Silicon).

Cảnh báo

Do giới hạn của hệ thống file, các bundle .app xuất từ Windows thiếu cờ executable và sẽ không chạy được trên macOS. Các dự án xuất dưới dạng .zip không bị ảnh hưởng bởi vấn đề này. Để chạy bundle .app xuất từ Windows trên macOS, hãy chuyển .app sang một thiết bị chạy macOS hoặc Linux và dùng lệnh terminal chmod +x {executable_name} để thêm quyền executable. File thực thi chính nằm trong thư mục con Contents/MacOS/, cũng như các file thực thi phụ trợ tùy chọn trong thư mục con Contents/Helpers/, cần có quyền executable để bundle .app hợp lệ.

Yêu cầu

  • Tải về các export template của Godot. Dùng menu của Godot: Editor > Manage Export Templates.

  • Cần đặt một Bundle identifier hợp lệ và duy nhất trong mục Application của các tùy chọn xuất.

Ghi chú

Một bundle ID hợp lệ chỉ được chứa ký tự chữ và số, dấu gạch nối và dấu chấm (A-Z, a-z, 0-9, -, và .). Apple khuyến nghị dùng định dạng reverse-DNS (ví dụ com.example.your-game) của một tên miền bạn sở hữu, để đảm bảo bundle ID là duy nhất. Bundle ID không phân biệt chữ hoa chữ thường. Xem CFBundleIdentifier.

Cảnh báo

Các dự án xuất mà không ký code và không notarize sẽ bị Gatekeeper chặn nếu được tải về từ nguồn không xác định, xem trang Chạy ứng dụng Godot trên macOS để biết thêm thông tin.

Ký code và notarization

Theo mặc định, macOS chỉ chạy các ứng dụng đã được ký và notarize. Nếu bạn dùng bất kỳ cấu hình ký nào khác, hãy xem Chạy ứng dụng Godot trên macOS để biết cách khắc phục.

Để notarize một ứng dụng, bạn bắt buộc phải có Apple Developer ID Certificate hợp lệ.

Nếu bạn có Apple Developer ID Certificate và xuất từ macOS

Cài command line tools của Xcode và mở Xcode ít nhất một lần, hoặc chạy lệnh sudo xcodebuild -license accept để chấp nhận thỏa thuận giấy phép.

Để ký ứng dụng đã xuất

  • Chọn Xcode codesign trong tùy chọn Code Signing > Codesign.

  • Đặt danh tính chứng chỉ Apple ID hợp lệ ("Common Name" của chứng chỉ) trong mục Code Signing > Identity.

Để notarize ứng dụng đã xuất

  • Chọn Xcode notarytool trong tùy chọn Notarization > Notarization.

  • Tắt entitlement Debugging.

  • Đặt thông tin đăng nhập Apple ID / mật khẩu riêng cho ứng dụng hợp lệ, hoặc API UUID / Key của App Store Connect trong mục Notarization.

Bạn có thể dùng lệnh xcrun notarytool history để kiểm tra trạng thái notarization và dùng lệnh xcrun notarytool log {ID} để tải log notarization.

Nếu gặp vấn đề khi notarize, hãy xem Resolving common notarization issues để biết thêm thông tin.

Sau khi notarization hoàn tất, hãy staple ticket vào dự án đã xuất.

Nếu bạn có Apple Developer ID Certificate và xuất từ Linux hoặc Windows

Cài rcodesign, và cấu hình đường dẫn tới rcodesign trong tùy chọn Editor Settings > Export > macOS > rcodesign.

Để ký ứng dụng đã xuất

  • Chọn rcodesign trong tùy chọn Code Signing > Codesign.

  • Đặt file chứng chỉ Apple ID PKCS #12 và mật khẩu hợp lệ trong mục Code Signing.

Để notarize ứng dụng đã xuất

  • Chọn rcodesign trong tùy chọn Notarization > Notarization.

  • Tắt entitlement Debugging.

  • Đặt API UUID / Key của App Store Connect hợp lệ trong mục Notarization.

Bạn có thể dùng lệnh rcodesign notary-log để kiểm tra trạng thái notarization.

Sau khi notarization hoàn tất, hãy dùng lệnh rcodesign staple để staple ticket vào dự án đã xuất.

Nếu bạn không có Apple Developer ID Certificate

  • Chọn Built-in (ad-hoc only) trong tùy chọn Code Signing > Codesign.

  • Chọn Disabled trong tùy chọn Notarization > Notarization.

Trong trường hợp này, Godot sẽ dùng chữ ký ad-hoc, giúp người dùng cuối chạy ứng dụng đã xuất dễ dàng hơn, xem trang Chạy ứng dụng Godot trên macOS để biết thêm thông tin.

Entitlements

Entitlement của Hardened Runtime

Các entitlement của Hardened Runtime quản lý các tùy chọn bảo mật và chính sách truy cập tài nguyên. Xem Hardened Runtime để biết thêm thông tin.

Entitlement

Mô tả

Allow JIT Code Execution [4]

Cho phép tạo vùng bộ nhớ vừa ghi được vừa thực thi được cho code JIT. Nếu bạn dùng các add-on có native code động hoặc tự sửa đổi, hãy bật chúng theo tài liệu của add-on.

Allow Unsigned Executable Memory [4]

Cho phép tạo vùng bộ nhớ vừa ghi được vừa thực thi được mà không bị giới hạn JIT. Nếu bạn dùng các add-on có native code động hoặc tự sửa đổi, hãy bật chúng theo tài liệu của add-on.

Allow DYLD Environment Variables [4]

Cho phép ứng dụng dùng biến môi trường của dynamic linker để chèn code. Nếu bạn dùng các add-on có native code động hoặc tự sửa đổi, hãy bật chúng theo tài liệu của add-on.

Disable Library Validation

Cho phép ứng dụng tải các thư viện và framework bất kỳ. Hãy bật nếu bạn dùng add-on GDExtension hoặc ký ad-hoc, hoặc muốn hỗ trợ các add-on bên ngoài do người dùng cung cấp.

Audio Input

Bật nếu bạn cần dùng micro hoặc các nguồn âm thanh đầu vào khác; nếu bật, bạn cũng nên cung cấp thông điệp mô tả mục đích sử dụng trong tùy chọn privacy/microphone_usage_description.

Camera

Bật nếu bạn cần dùng camera; nếu bật, bạn cũng nên cung cấp thông điệp mô tả mục đích sử dụng trong tùy chọn privacy/camera_usage_description.

Location

Bật nếu bạn cần dùng thông tin vị trí từ Location Services; nếu bật, bạn cũng nên cung cấp thông điệp mô tả mục đích sử dụng trong tùy chọn privacy/location_usage_description.

Address Book

[5] Bật để cho phép truy cập danh bạ trong sổ địa chỉ của người dùng; nếu bật, bạn cũng nên cung cấp thông điệp mô tả mục đích sử dụng trong tùy chọn privacy/address_book_usage_description.

Calendars

[5] Bật để cho phép truy cập lịch của người dùng; nếu bật, bạn cũng nên cung cấp thông điệp mô tả mục đích sử dụng trong tùy chọn privacy/calendar_usage_description.

Photo Library

[5] Bật để cho phép truy cập thư viện Photos của người dùng; nếu bật, bạn cũng nên cung cấp thông điệp mô tả mục đích sử dụng trong tùy chọn privacy/photos_library_usage_description.

Apple Events

[5] Bật để cho phép ứng dụng gửi Apple event tới các ứng dụng khác.

Debug

[6] Bạn có thể tạm thời bật entitlement này để dùng trình gỡ lỗi native (GDB, LLDB) với ứng dụng đã xuất. Entitlement này nên được tắt khi xuất bản production.
[4] (1,2,3)

Các entitlement Allow JIT Code Execution, Allow Unsigned Executable Memory và Allow DYLD Environment Variables luôn được bật cho các bản xuất Godot Mono, và không hiển thị trong các tùy chọn xuất.

[5] (1,2,3,4)

Các tính năng này không được Godot hỗ trợ sẵn, chỉ bật chúng nếu bạn đang dùng add-on cần đến chúng.

[6]

Để notarize một ứng dụng, bạn phải tắt entitlement Debugging.

Entitlement của App Sandbox

App Sandbox giới hạn quyền truy cập dữ liệu người dùng, mạng và thiết bị. Ứng dụng chạy trong sandbox không thể truy cập phần lớn hệ thống file, không thể dùng hộp thoại file tùy chỉnh và không thể thực thi binary (bằng OS.execute và OS.create_process) bên ngoài bundle .app. Xem App Sandbox để biết thêm thông tin.

Ghi chú

Để phân phối ứng dụng qua App Store, bạn phải bật App Sandbox.

Entitlement

Mô tả

Enabled

Bật App Sandbox.

Network Server

Bật để cho phép ứng dụng lắng nghe các kết nối mạng đến.

Network Client

Bật để cho phép ứng dụng thiết lập các kết nối mạng đi.

Device USB

Bật để cho phép ứng dụng tương tác với thiết bị USB. Entitlement này là bắt buộc để dùng tay cầm có dây.

Device Bluetooth

Bật để cho phép ứng dụng tương tác với thiết bị Bluetooth. Entitlement này là bắt buộc để dùng tay cầm không dây.

Files Downloads [7]

Cho phép quyền đọc hoặc ghi vào thư mục "Downloads" của người dùng.

Files Pictures [7]

Cho phép quyền đọc hoặc ghi vào thư mục "Pictures" của người dùng.

Files Music [7]

Cho phép quyền đọc hoặc ghi vào thư mục "Music" của người dùng.

Files Movies [7]

Cho phép quyền đọc hoặc ghi vào thư mục "Movies" của người dùng.

Files User Selected [7]

Cho phép quyền đọc hoặc ghi vào thư mục bất kỳ. Để có quyền truy cập, người dùng phải chọn thư mục từ hộp thoại file native.

Helper Executable

Danh sách các file thực thi phụ trợ được nhúng vào bundle ứng dụng. Ứng dụng chạy trong sandbox chỉ được phép thực thi các file này.
[7] (1,2,3,4,5)

Bạn có thể tùy chọn cung cấp thông điệp mô tả mục đích sử dụng cho các thư mục khác nhau trong các tùy chọn privacy/*_folder_usage_description.

Ghi chú

Bạn có thể ghi đè các entitlement mặc định bằng cách chọn file entitlement tùy chỉnh, khi đó tất cả entitlement khác sẽ bị bỏ qua.

Biến môi trường
