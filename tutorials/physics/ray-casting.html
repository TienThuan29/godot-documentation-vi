Ray-casting

Giới thiệu

Một trong những tác vụ phổ biến nhất trong phát triển game là bắn một tia (hoặc một đối tượng có hình dạng tùy chỉnh) và kiểm tra xem nó trúng vào đâu. Điều này cho phép hiện thực các hành vi phức tạp, AI, v.v. Bài hướng dẫn này sẽ giải thích cách làm điều đó trong 2D và 3D.

Godot lưu toàn bộ thông tin game cấp thấp trong các server, còn scene chỉ là phần giao diện phía trước. Vì vậy, ray casting nhìn chung là một tác vụ cấp thấp hơn. Với các raycast đơn giản, những node như RayCast3D và RayCast2D sẽ đáp ứng được, vì chúng trả về kết quả raycast ở mỗi frame.

Tuy nhiên, nhiều khi ray-casting cần là một quá trình tương tác hơn, nên phải có cách thực hiện nó bằng code.

Space

Trong thế giới vật lý, Godot lưu toàn bộ thông tin va chạm và vật lý cấp thấp trong một space. Có thể lấy space 2D hiện tại (cho vật lý 2D) bằng cách truy cập CanvasItem.get_world_2d().space. Với 3D, đó là Node3D.get_world_3d().space.

RID của space thu được có thể dùng trong PhysicsServer3D và PhysicsServer2D, lần lượt cho 3D và 2D.

Truy cập space

Theo mặc định, vật lý của Godot chạy trên cùng thread với logic game, nhưng có thể được thiết lập để chạy trên một thread riêng nhằm hoạt động hiệu quả hơn. Vì thế, thời điểm duy nhất truy cập space an toàn là trong callback Node._physics_process(). Truy cập nó từ bên ngoài hàm này có thể gây lỗi do space đang bị khóa.

Để thực hiện truy vấn vào physics space, bạn phải dùng PhysicsDirectSpaceState2D và PhysicsDirectSpaceState3D.

Dùng đoạn code sau trong 2D:

func _physics_process(delta):
    var space_rid = get_world_2d().space
    var space_state = PhysicsServer2D.space_get_direct_state(space_rid)

public override void _PhysicsProcess(double delta)
{
    var spaceRid = GetWorld2D().Space;
    var spaceState = PhysicsServer2D.SpaceGetDirectState(spaceRid);
}

Hoặc trực tiếp hơn:

func _physics_process(delta):
    var space_state = get_world_2d().direct_space_state

public override void _PhysicsProcess(double delta)
{
    var spaceState = GetWorld2D().DirectSpaceState;
}

Và trong 3D:

func _physics_process(delta):
    var space_state = get_world_3d().direct_space_state

public override void _PhysicsProcess(double delta)
{
    var spaceState = GetWorld3D().DirectSpaceState;
}

Truy vấn raycast

Để thực hiện một truy vấn raycast 2D, có thể dùng phương thức PhysicsDirectSpaceState2D.intersect_ray(). Ví dụ:

func _physics_process(delta):
    var space_state = get_world_2d().direct_space_state
    # use global coordinates, not local to node
    var query = PhysicsRayQueryParameters2D.create(Vector2(0, 0), Vector2(50, 100))
    var result = space_state.intersect_ray(query)

public override void _PhysicsProcess(double delta)
{
    var spaceState = GetWorld2D().DirectSpaceState;
    // use global coordinates, not local to node
    var query = PhysicsRayQueryParameters2D.Create(Vector2.Zero, new Vector2(50, 100));
    var result = spaceState.IntersectRay(query);
}

Kết quả là một dictionary. Nếu tia không trúng gì, dictionary sẽ rỗng. Nếu tia trúng thứ gì đó, nó sẽ chứa thông tin va chạm:

if result:
    print("Hit at point: ", result.position)

if (result.Count > 0)
{
    GD.Print("Hit at point: ", result["position"]);
}

Dictionary result khi xảy ra va chạm chứa các dữ liệu sau:

{
   position: Vector2 # point in world space for collision
   normal: Vector2 # normal in world space for collision
   collider: Object # Object collided or null (if unassociated)
   collider_id: ObjectID # Object it collided against
   rid: RID # RID it collided against
   shape: int # shape index of collider
   metadata: Variant() # metadata of collider
}

Dữ liệu trong không gian 3D cũng tương tự, sử dụng tọa độ Vector3. Lưu ý rằng để bật va chạm với Area3D, tham số boolean collide_with_areas phải được đặt thành true.

const RAY_LENGTH = 1000

func _physics_process(delta):
    var space_state = get_world_3d().direct_space_state
    var cam = $Camera3D
    var mousepos = get_viewport().get_mouse_position()

    var origin = cam.project_ray_origin(mousepos)
    var end = origin + cam.project_ray_normal(mousepos) * RAY_LENGTH
    var query = PhysicsRayQueryParameters3D.create(origin, end)
    query.collide_with_areas = true

    var result = space_state.intersect_ray(query)

private const int RayLength = 1000;

public override void _PhysicsProcess(double delta)
{
    var spaceState = GetWorld3D().DirectSpaceState;
    var cam = GetNode<Camera3D>("Camera3D");
    var mousePos = GetViewport().GetMousePosition();

    var origin = cam.ProjectRayOrigin(mousePos);
    var end = origin + cam.ProjectRayNormal(mousePos) * RayLength;
    var query = PhysicsRayQueryParameters3D.Create(origin, end);
    query.CollideWithAreas = true;

    var result = spaceState.IntersectRay(query);
}

Ngoại lệ va chạm

Một trường hợp dùng ray casting phổ biến là giúp nhân vật thu thập dữ liệu về thế giới xung quanh. Một vấn đề ở đây là chính nhân vật đó cũng có collider, nên tia sẽ chỉ phát hiện collider của node cha, như trong hình sau:

Để tránh tự giao cắt, đối tượng tham số của intersect_ray() có thể nhận một mảng ngoại lệ thông qua thuộc tính exclude. Đây là ví dụ cách dùng nó từ một CharacterBody2D hoặc bất kỳ node collision object nào khác:

extends CharacterBody2D

func _physics_process(delta):
    var space_state = get_world_2d().direct_space_state
    var query = PhysicsRayQueryParameters2D.create(global_position, player_position)
    query.exclude = [self]
    var result = space_state.intersect_ray(query)

using Godot;

public partial class MyCharacterBody2D : CharacterBody2D
{
    public override void _PhysicsProcess(double delta)
    {
        var spaceState = GetWorld2D().DirectSpaceState;
        var query = PhysicsRayQueryParameters2D.Create(globalPosition, playerPosition);
        query.Exclude = [GetRid()];
        var result = spaceState.IntersectRay(query);
    }
}

Mảng ngoại lệ có thể chứa các đối tượng hoặc RID.

Collision Mask

Dù cách dùng ngoại lệ hoạt động tốt để loại trừ body cha, nó trở nên rất bất tiện nếu bạn cần một danh sách ngoại lệ lớn và/hoặc thay đổi động. Trong trường hợp này, dùng hệ thống collision layer/mask hiệu quả hơn nhiều.

Đối tượng tham số của intersect_ray() cũng có thể nhận một collision mask. Ví dụ, để dùng cùng mask với body cha, hãy dùng biến thành viên collision_mask. Mảng ngoại lệ cũng có thể được truyền vào làm đối số cuối cùng:

extends CharacterBody2D

func _physics_process(delta):
    var space_state = get_world_2d().direct_space_state
    var query = PhysicsRayQueryParameters2D.create(global_position, target_position,
        collision_mask, [self])
    var result = space_state.intersect_ray(query)

using Godot;

public partial class MyCharacterBody2D : CharacterBody2D
{
    public override void _PhysicsProcess(double delta)
    {
        var spaceState = GetWorld2D().DirectSpaceState;
        var query = PhysicsRayQueryParameters2D.Create(globalPosition, targetPosition,
            CollisionMask, [GetRid()]);
        var result = spaceState.IntersectRay(query);
    }
}

Xem Ví dụ mã để biết chi tiết cách thiết lập collision mask.

Ray casting 3D từ màn hình

Bắn một tia từ màn hình vào physics space 3D rất hữu ích cho việc chọn đối tượng. Thường thì không cần làm vậy vì CollisionObject3D có signal "input_event" cho bạn biết khi nó được nhấp, nhưng nếu bạn muốn tự làm thủ công thì đây là cách.

Để bắn một tia từ màn hình, bạn cần một node Camera3D. Một Camera3D có thể ở hai chế độ chiếu: phối cảnh (perspective) và trực giao (orthogonal). Vì vậy, phải lấy cả điểm gốc lẫn hướng của tia. Lý do là origin thay đổi trong chế độ trực giao, còn normal thay đổi trong chế độ phối cảnh:

Để lấy chúng bằng camera, có thể dùng đoạn code sau:

const RAY_LENGTH = 1000.0

func _input(event):
    if event is InputEventMouseButton and event.pressed and event.button_index == 1:
        var camera3d = $Camera3D
        var from = camera3d.project_ray_origin(event.position)
        var to = from + camera3d.project_ray_normal(event.position) * RAY_LENGTH

private const float RayLength = 1000.0f;

public override void _Input(InputEvent @event)
{
    if (@event is InputEventMouseButton eventMouseButton && eventMouseButton.Pressed && eventMouseButton.ButtonIndex == MouseButton.Left)
    {
        var camera3D = GetNode<Camera3D>("Camera3D");
        var from = camera3D.ProjectRayOrigin(eventMouseButton.Position);
        var to = from + camera3D.ProjectRayNormal(eventMouseButton.Position) * RayLength;
    }
}

Hãy nhớ rằng trong _input(), space có thể bị khóa, nên trên thực tế truy vấn này nên được chạy trong _physics_process().
