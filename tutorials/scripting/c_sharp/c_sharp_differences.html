Khác biệt API giữa C# và GDScript

Đây là danh sách (chưa đầy đủ) các khác biệt API giữa C# và GDScript.

Khác biệt chung

Như đã giải thích trong Khác biệt chung giữa C# và GDScript, C# dùng PascalCase để truy cập API Godot thay vì snake_case như GDScript và C++. Khi có thể, các field và getter/setter đã được chuyển thành property. Nhìn chung, API Godot cho C# cố gắng viết theo phong cách chuẩn của C# nhiều nhất có thể. Xem Hướng dẫn phong cách C#, chúng tôi khuyến khích bạn cũng áp dụng nó cho code C# của mình.

Trong GDScript, có thể gọi trực tiếp setter/getter của một thuộc tính, dù điều này không được khuyến khích. Trong C#, chỉ có property được định nghĩa. Ví dụ, để chuyển code GDScript x.set_name("Friend") sang C#, hãy viết x.Name = "Friend";.

Một IDE cho C# sẽ cung cấp intellisense, cực kỳ hữu ích khi tìm các API C# đã được đổi tên. Trình chỉnh sửa script tích hợp của Godot không hỗ trợ intellisense cho C#, và cũng không cung cấp nhiều công cụ phát triển C# khác được coi là thiết yếu. Xem Cấu hình trình chỉnh sửa bên ngoài.

Phạm vi toàn cục

Các hàm toàn cục và một số hằng số phải được chuyển vào lớp, vì C# không cho phép khai báo chúng trong namespace. Hầu hết hằng số toàn cục đã được chuyển vào enum riêng.

Hằng số

Trong C#, chỉ kiểu nguyên thủy mới có thể là hằng số. Ví dụ, hằng số TAU được thay bằng hằng số Mathf.Tau, nhưng hằng số Vector2.RIGHT được thay bằng property chỉ đọc Vector2.Right. Nó hoạt động tương tự hằng số, nhưng không dùng được trong một số ngữ cảnh như câu lệnh switch.

Các hằng số enum toàn cục đã được chuyển vào enum riêng. Ví dụ, các hằng số ERR_* đã được chuyển vào enum Error.

Trường hợp đặc biệt:

GDScript

C#

TYPE_*

Enum Variant.Type

OP_*

Enum Variant.Operator

Hàm toán học

Các hàm toán học toàn cục, như abs, acos, asin, atan và atan2, nằm trong Mathf dưới dạng Abs, Acos, Asin, Atan và Atan2. Hằng số PI có thể tìm thấy dưới dạng Mathf.Pi.

C# cũng cung cấp các lớp tĩnh System.Math và System.MathF có thể chứa các phép toán hữu ích khác.

Hàm ngẫu nhiên

Các hàm ngẫu nhiên toàn cục, như rand_range và rand_seed, nằm trong GD. Ví dụ: GD.RandRange và GD.RandSeed.

Hãy cân nhắc dùng System.Random hoặc, nếu cần ngẫu nhiên đủ mạnh cho mật mã học, dùng System.Security.Cryptography.RandomNumberGenerator.

Các hàm khác

Nhiều hàm toàn cục khác như print và var_to_str nằm trong GD. Ví dụ: GD.Print và GD.VarToStr.

Ngoại lệ:

GDScript

C#

Mẹo

Đôi khi dùng chỉ thị using static có thể hữu ích. Chỉ thị này cho phép truy cập các thành viên và kiểu lồng nhau của một lớp mà không cần ghi tên lớp.

Ví dụ:

using static Godot.GD;

public class Test
{
    static Test()
    {
        Print("Hello"); // Instead of GD.Print("Hello");
    }
}

Annotation @export

Dùng attribute [Export] thay cho annotation @export của GDScript. Attribute này cũng có thể nhận thêm các tham số tùy chọn PropertyHint và hintString. Có thể đặt giá trị mặc định bằng cách gán giá trị.

Ví dụ:

using Godot;

public partial class MyNode : Node
{
    [Export]
    private NodePath _nodePath;

    [Export]
    private string _name = "default";

    [Export(PropertyHint.Range, "0,100000,1000,or_greater")]
    private int _income;

    [Export(PropertyHint.File, "*.png,*.jpg")]
    private string _icon;
}

Xem thêm: Thuộc tính export trong C#.

Từ khóa signal

Dùng attribute [Signal] để khai báo signal thay cho từ khóa signal của GDScript. Attribute này nên được dùng trên một delegate, có chữ ký tên sẽ được dùng để định nghĩa signal. delegate phải có hậu tố EventHandler; một event sẽ được tạo trong lớp với cùng tên nhưng không có hậu tố, hãy dùng tên của event đó với EmitSignal.

[Signal]
delegate void MySignalEventHandler(string willSendAString);

Xem thêm: Signal trong C#.

Annotation @onready

GDScript có khả năng trì hoãn việc khởi tạo một biến thành viên cho tới khi hàm ready được gọi bằng @onready (xem Annotation @onready). Ví dụ:

@onready var my_label = get_node("MyLabel")

Tuy nhiên C# không có khả năng này. Để đạt hiệu quả tương tự, bạn cần làm như sau.

private Label _myLabel;

public override void _Ready()
{
    _myLabel = GetNode<Label>("MyLabel");
}

Singleton

Singleton có sẵn dưới dạng lớp tĩnh thay vì dùng mẫu singleton. Điều này giúp code bớt dài dòng so với khi dùng property Instance.

Ví dụ:

Input.IsActionPressed("ui_down")

Tuy nhiên, trong một số rất ít trường hợp, như vậy là chưa đủ. Ví dụ, bạn có thể muốn truy cập một thành viên từ lớp cơ sở GodotObject, như Connect. Cho những trường hợp như vậy, chúng tôi cung cấp một property tĩnh tên Singleton trả về instance singleton. Kiểu của instance này là GodotObject.

Ví dụ:

Input.Singleton.JoyConnectionChanged += Input_JoyConnectionChanged;

Nếu bạn phát triển plugin màn hình chính, cần lưu ý rằng EditorInterface không phải lớp tĩnh trong C#, khác với GDScript. Vì vậy, bạn phải dùng mẫu singleton để lấy instance của EditorInterface:

String

Dùng System.String (string). Hầu hết phương thức String của Godot có tương đương trong System.String hoặc được lớp StringExtensions cung cấp dưới dạng phương thức mở rộng (extension method).

Lưu ý rằng string của C# dùng mã hóa UTF-16, còn String của Godot dùng mã hóa UTF-32.

Ví dụ:

string text = "Get up!";
string[] bigrams = text.Bigrams(); // ["Ge", "et", "t ", " u", "up", "p!"]

String trong .NET là bất biến (immutable), nên mọi phương thức thao tác trên string đều không sửa string gốc mà trả về một string mới đã áp dụng thay đổi. Để tránh tạo nhiều lần cấp phát string, hãy cân nhắc dùng StringBuilder.

Hiện tại C# hỗ trợ Callable nếu thỏa một trong các điều kiện sau:

  • Callable được tạo bằng kiểu Callable của C#.

  • Callable là phiên bản cơ bản của Callable trong engine. Các Callable tùy chỉnh không được hỗ trợ. Một Callable được coi là tùy chỉnh khi thỏa bất kỳ điều kiện nào sau đây:

    • Callable có thông tin bind (các Callable tạo bằng bind/unbind không được hỗ trợ).

    • Callable được tạo từ ngôn ngữ khác thông qua API GDExtension.

Một số phương thức như bind và unbind chưa được triển khai, hãy dùng lambda thay thế:

string name = "John Doe";
Callable callable = Callable.From(() => SayHello(name));

void SayHello(string name)
{
    GD.Print($"Hello {name}");
}

Lambda bắt (capture) biến name để có thể gắn nó vào phương thức SayHello.

Giao tiếp với các ngôn ngữ script khác

Nội dung này được giải thích chi tiết trong Lập trình script đa ngôn ngữ.

Từ khóa await

Bạn có thể đạt được điều tương tự từ khóa await của GDScript bằng từ khóa await của C#.

Từ khóa await trong C# có thể dùng với bất kỳ biểu thức awaitable nào. Nó thường được dùng với toán hạng thuộc các kiểu Task, Task<TResult>, ValueTask hoặc ValueTask<TResult>.

Một biểu thức t là awaitable nếu thỏa một trong các điều kiện sau:

  • t có kiểu tại thời điểm biên dịch là dynamic.

  • t có một phương thức instance hoặc phương thức mở rộng truy cập được tên là GetAwaiter, không có tham số và không có tham số kiểu, với kiểu trả về A thỏa tất cả các điều kiện sau:

    • A triển khai interface System.Runtime.CompilerServices.INotifyCompletion.

    • A có một thuộc tính instance truy cập được và đọc được tên là IsCompleted với kiểu bool.

    • A có một phương thức instance truy cập được tên là GetResult, không có tham số và không có tham số kiểu.

Tương đương với việc await một signal trong GDScript có thể thực hiện bằng từ khóa await và GodotObject.ToSignal.

Ví dụ:

public async Task SomeFunction()
{
    await ToSignal(timer, Timer.SignalName.Timeout);
    GD.Print("After timeout");
}
