C# Variant

Để xem giải thích chi tiết về Variant nói chung, hãy xem trang tài liệu Variant.

Godot.Variant được dùng để biểu diễn kiểu Variant gốc của Godot. Mọi kiểu tương thích Variant đều có thể chuyển đổi sang và từ kiểu này. Chúng tôi khuyến nghị tránh dùng Godot.Variant trừ khi cần tương tác với các API không định kiểu của engine. Hãy tận dụng tính an toàn kiểu của C# khi có thể.

Việc chuyển đổi từ một kiểu C# tương thích Variant sang Godot.Variant có thể thực hiện bằng chuyển đổi ngầm. Ngoài ra còn có các overload phương thức CreateFrom và các phương thức generic Variant.From<T>. Chỉ cú pháp khác nhau: hành vi là như nhau.

int x = 42;
Variant numberVariant = x;
Variant helloVariant = "Hello, World!";

Variant numberVariant2 = Variant.CreateFrom(x);
Variant numberVariant3 = Variant.From(x);

Chuyển đổi ngầm sang Godot.Variant giúp việc truyền variant làm đối số phương thức rất thuận tiện. Ví dụ, đối số thứ ba của tween_property chỉ định màu cuối cùng của tween là một Godot.Variant.

Tween tween = CreateTween();
tween.TweenProperty(GetNode("Sprite"), "modulate", Colors.Red, 1.0f);

Việc chuyển đổi từ Godot.Variant sang một kiểu C# có thể thực hiện bằng chuyển đổi tường minh. Ngoài ra còn có các phương thức Variant.As{TYPE} và phương thức generic Variant.As<T>. Tất cả đều hoạt động như nhau.

int number = (int)numberVariant;
string hello = (string)helloVariant;

int number2 = numberVariant.As<int>();
int number3 = numberVariant.AsInt32();

Ghi chú

Các phương thức Variant.As{TYPE} thường được đặt tên theo kiểu C# (Int32), không theo từ khóa C# (int).

Nếu kiểu Variant không khớp với kiểu đích của phép chuyển đổi, hệ quả sẽ khác nhau tùy theo giá trị nguồn và giá trị đích.

  • Phép chuyển đổi có thể xem xét giá trị và trả về một giá trị tương tự nhưng có thể không như mong đợi của kiểu đích. Ví dụ, chuỗi "42a" có thể được chuyển thành số nguyên 42.

  • Có thể trả về giá trị mặc định của kiểu đích.

  • Có thể trả về một mảng rỗng.

  • Có thể ném ra ngoại lệ.

Chuyển đổi sang đúng kiểu giúp tránh hành vi phức tạp và nên được ưu tiên.

Thuộc tính Variant.Obj trả về một object C# với giá trị đúng cho mọi variant. Điều này có thể hữu ích khi hoàn toàn không biết kiểu của Variant. Tuy nhiên, khi có thể, hãy ưu tiên các phép chuyển đổi cụ thể hơn. Variant.Obj thực hiện một switch trên Variant.VariantType và điều đó có thể không cần thiết. Ngoài ra, nếu kết quả là kiểu giá trị, nó sẽ bị boxing.

Ví dụ, nếu khả năng Variant.As<MyNode>() ném ra ngoại lệ ép kiểu không hợp lệ là không chấp nhận được, hãy cân nhắc dùng type pattern Variant.As<GodotObject>() is MyNode n thay thế.

Ghi chú

Vì kiểu Variant trong C# là struct, nó không thể là null. Để tạo một Variant "null", hãy dùng từ khóa default hoặc constructor không tham số của Godot.Variant.

Các kiểu tương thích Variant

Một kiểu tương thích Variant có thể được chuyển đổi sang và từ Godot.Variant. Các kiểu C# sau là tương thích Variant:

  • Mọi kiểu giá trị tích hợp, trừ decimal, nint và nuint.

  • string.

  • Các lớp dẫn xuất từ GodotObject.

  • Các kiểu collection được định nghĩa trong namespace Godot.Collections.

Cảnh báo

Godot dùng số nguyên và số thực 64-bit trong Variant. Các kiểu số nguyên và số thực nhỏ hơn như int, short và float được hỗ trợ vì chúng vừa với kiểu lớn hơn. Lưu ý rằng khi thực hiện chuyển đổi, dùng sai kiểu có thể dẫn đến mất độ chính xác.

Cảnh báo

Enum được Godot.Variant hỗ trợ vì kiểu nền của chúng là kiểu số nguyên, vốn đều tương thích. Tuy nhiên, không có chuyển đổi ngầm, enum phải được chuyển thủ công sang kiểu số nguyên nền trước khi có thể chuyển sang/từ Godot.Variant, hoặc dùng các phương thức generic Variant.As<T> và Variant.From<T> để chuyển đổi chúng.

enum MyEnum { A, B, C }

Variant variant1 = (int)MyEnum.A;
MyEnum enum1 = (MyEnum)(int)variant1;

Variant variant2 = Variant.From(MyEnum.A);
MyEnum enum2 = variant2.As<MyEnum>();

Dùng Variant trong ngữ cảnh generic

Khi dùng generic, bạn có thể muốn giới hạn kiểu generic T chỉ là một trong các kiểu tương thích Variant. Điều này có thể thực hiện bằng attribute [MustBeVariant].

public void MethodThatOnlySupportsVariants<[MustBeVariant] T>(T onlyVariant)
{
    // Do something with the Variant-compatible value.
}

Kết hợp với phương thức generic Variant.From<T>, bạn có thể lấy một instance Godot.Variant từ một instance của kiểu generic T. Sau đó có thể dùng nó trong bất kỳ API nào chỉ hỗ trợ struct Godot.Variant.

public void Method1<[MustBeVariant] T>(T variantCompatible)
{
    Variant variant = Variant.From(variantCompatible);
    Method2(variant);
}

public void Method2(Variant variant)
{
    // Do something with variant.
}

Để gọi một phương thức có tham số generic được đánh dấu attribute [MustBeVariant], giá trị phải là kiểu tương thích Variant hoặc một kiểu generic T cũng được đánh dấu attribute [MustBeVariant].

public class ObjectDerivedClass : GodotObject { }

public class NonObjectDerivedClass { }

public void Main<[MustBeVariant] T1, T2>(T1 someGeneric1, T2 someGeneric2)
{
    MyMethod(42); // Works because `int` is a Variant-compatible type.
    MyMethod(new ObjectDerivedClass()); // Works because any type that derives from `GodotObject` is a Variant-compatible type.
    MyMethod(new NonObjectDerivedClass()); // Does NOT work because the type is not Variant-compatible.
    MyMethod(someGeneric1); // Works because `T1` is annotated with the `[MustBeVariant]` attribute.
    MyMethod(someGeneric2); // Does NOT work because `T2` is NOT annotated with the `[MustBeVariant]` attribute.
}

public void MyMethod<[MustBeVariant] T>(T variant)
{
    // Do something with variant.
}
