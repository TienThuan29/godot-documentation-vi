Thuộc tính export trong C#

Trong Godot, các thành viên của lớp có thể được export. Điều này nghĩa là giá trị của chúng được lưu cùng với resource (chẳng hạn scene) mà chúng gắn vào. Chúng cũng sẽ có thể chỉnh sửa trong trình chỉnh sửa thuộc tính. Việc export được thực hiện bằng attribute [Export].

using Godot;

public partial class ExportExample : Node3D
{
    [Export]
    public int Number { get; set; } = 5;
}

Trong ví dụ đó, giá trị 5 sẽ được lưu, và sau khi build dự án hiện tại, nó sẽ hiển thị trong trình chỉnh sửa thuộc tính.

Một trong những lợi ích cơ bản của việc export biến thành viên là giúp chúng hiển thị và chỉnh sửa được trong trình chỉnh sửa. Nhờ vậy, họa sĩ và game designer có thể thay đổi các giá trị ảnh hưởng đến cách chương trình chạy. Để làm điều này, Godot cung cấp một cú pháp export đặc biệt.

Chỉ có thể export với Các kiểu tương thích Variant.

Ghi chú

Bạn cũng có thể export thuộc tính trong GDScript, xem thông tin tại Thuộc tính export trong GDScript.

Cách dùng cơ bản

Export hoạt động với field và thuộc tính. Chúng có thể có bất kỳ access modifier nào.

[Export]
private int _number;

[Export]
public int Number { get; set; }

Thành viên được export có thể chỉ định giá trị mặc định; nếu không, giá trị mặc định của kiểu sẽ được dùng thay thế.

Một int như Number mặc định là 0. Text mặc định là null vì string là kiểu tham chiếu.

[Export]
public int Number { get; set; }

[Export]
public string Text { get; set; }

Có thể chỉ định giá trị mặc định cho field và thuộc tính.

[Export]
private string _greeting = "Hello World";

[Export]
public string Greeting { get; set; } = "Hello World";

Thuộc tính có backing field sẽ dùng giá trị mặc định của backing field.

private int _number = 2;

[Export]
public int NumberWithBackingField
{
    get => _number;
    set => _number = value;
}

Ghi chú

get của thuộc tính thực ra không được thực thi để xác định giá trị mặc định. Thay vào đó, Godot phân tích mã nguồn C#. Cách này hoạt động tốt trong hầu hết trường hợp, như các ví dụ trên trang này. Tuy nhiên, một số thuộc tính quá phức tạp để bộ phân tích hiểu được.

Ví dụ, thuộc tính sau cố gắng dùng phép tính để hiển thị giá trị mặc định là 5 trong trình chỉnh sửa thuộc tính, nhưng không hoạt động:

[Export]
public int NumberWithBackingField
{
    get => _number + 3;
    set => _number = value - 3;
}

private int _number = 2;

Bộ phân tích không hiểu đoạn mã này và quay về giá trị mặc định của int là 0. Tuy nhiên, khi chạy scene hoặc xem một node có gắn tool script, _number sẽ là 2 và NumberWithBackingField sẽ trả về 5. Sự khác biệt này có thể gây ra hành vi khó hiểu. Để tránh điều đó, đừng dùng thuộc tính phức tạp. Ngoài ra, nếu giá trị mặc định có thể được chỉ định rõ ràng, bạn có thể ghi đè nó bằng các phương thức _PropertyCanRevert() và _PropertyGetRevert().

Mọi kiểu Resource hoặc Node đều có thể được export. Trình chỉnh sửa thuộc tính hiển thị một hộp thoại gán thân thiện cho các kiểu này. Cách này có thể dùng thay cho GD.Load và GetNode. Xem Node và Resource.

[Export]
public PackedScene PackedScene { get; set; }

[Export]
public RigidBody2D RigidBody2D { get; set; }

Nhóm các export

Bạn có thể nhóm các thuộc tính được export trong Inspector bằng attribute [ExportGroup]. Mọi thuộc tính được export sau attribute này sẽ được thêm vào nhóm. Hãy bắt đầu một nhóm mới hoặc dùng [ExportGroup("")] để thoát khỏi nhóm.

[ExportGroup("My Properties")]
[Export]
public int Number { get; set; } = 3;

Đối số thứ hai của attribute có thể dùng để chỉ nhóm các thuộc tính có tiền tố được chỉ định.

Không thể lồng các nhóm, hãy dùng [ExportSubgroup] để tạo nhóm con bên trong một nhóm.

[ExportSubgroup("Extra Properties")]
[Export]
public string Text { get; set; } = "";
[Export]
public bool Flag { get; set; } = false;

Bạn cũng có thể đổi tên danh mục chính, hoặc tạo thêm danh mục trong danh sách thuộc tính bằng attribute [ExportCategory].

[ExportCategory("Main Category")]
[Export]
public int Number { get; set; } = 3;
[Export]
public string Text { get; set; } = "";

[ExportCategory("Extra Category")]
[Export]
public bool Flag { get; set; } = false;

Ghi chú

Danh sách thuộc tính được sắp xếp dựa trên kế thừa lớp, và các danh mục mới sẽ phá vỡ kỳ vọng đó. Hãy dùng chúng cẩn thận, nhất là khi tạo dự án cho cộng đồng sử dụng.

Chuỗi làm đường dẫn

Có thể dùng property hint để export chuỗi dưới dạng đường dẫn

Chuỗi dùng làm đường dẫn tới file.

[Export(PropertyHint.File)]
public string GameFile { get; set; }

Chuỗi là đường dẫn tới một thư mục.

[Export(PropertyHint.Dir)]
public string GameDirectory { get; set; }

Chuỗi là đường dẫn tới một file, với bộ lọc tùy chỉnh được cung cấp làm hint.

[Export(PropertyHint.File, "*.txt,")]
public string GameFile { get; set; }

Cũng có thể dùng đường dẫn trong hệ thống file toàn cục, nhưng chỉ trong script ở chế độ tool.

Chuỗi là đường dẫn tới một file PNG trong hệ thống file toàn cục.

[Export(PropertyHint.GlobalFile, "*.png")]
public string ToolImage { get; set; }

Chuỗi là đường dẫn tới một thư mục trong hệ thống file toàn cục.

[Export(PropertyHint.GlobalDir)]
public string ToolDir { get; set; }

Annotation multiline yêu cầu trình chỉnh sửa hiển thị một ô nhập lớn để chỉnh sửa trên nhiều dòng.

[Export(PropertyHint.MultilineText)]
public string Text { get; set; }

Giới hạn khoảng giá trị nhập trong trình chỉnh sửa

Dùng property hint range cho phép bạn giới hạn giá trị có thể nhập khi dùng trình chỉnh sửa.

Cho phép giá trị số nguyên từ 0 đến 20.

[Export(PropertyHint.Range, "0,20,")]
public int Number { get; set; }

Cho phép giá trị số nguyên từ -10 đến 20.

[Export(PropertyHint.Range, "-10,20,")]
public int Number { get; set; }

Cho phép số thực từ -10 đến 20 và làm tròn (snap) giá trị theo bội số của 0.2.

[Export(PropertyHint.Range, "-10,20,0.2")]
public float Number { get; set; }

Nếu thêm hint "or_greater" và/hoặc "or_less", bạn có thể vượt trên hoặc dưới giới hạn khi điều chỉnh giá trị bằng cách gõ vào thay vì dùng thanh trượt.

[Export(PropertyHint.Range, "0,100,1,or_greater,or_less")]
public int Number { get; set; }

Số thực với easing hint

Hiển thị biểu diễn trực quan của hàm ease khi chỉnh sửa.

[Export(PropertyHint.ExpEasing)]
public float TransitionSpeed { get; set; }

Export với suffix hint

Hiển thị hậu tố đơn vị cho biến được export. Hoạt động với các kiểu số, chẳng hạn số thực hoặc vector:

[Export(PropertyHint.None, "suffix:m/s\u00b2")]
public float Gravity { get; set; } = 9.8f;
[Export(PropertyHint.None, "suffix:m/s")]
public Vector3 Velocity { get; set; }

Trong ví dụ trên, \u00b2 được dùng để viết ký tự "bình phương" (²).

Màu sắc

Màu thông thường, cho dưới dạng giá trị đỏ-lục-lam-alpha.

[Export]
public Color Color { get; set; }

Màu cho dưới dạng giá trị đỏ-lục-lam (alpha luôn là 1).

[Export(PropertyHint.ColorNoAlpha)]
public Color Color { get; set; }

Node

Node cũng có thể được export trực tiếp mà không cần dùng NodePath.

[Export]
public Node Node { get; set; }

Một loại node cụ thể cũng có thể được export trực tiếp. Danh sách node hiển thị sau khi nhấn "Assign" trong Inspector sẽ được lọc theo loại đã chỉ định, và chỉ node đúng loại mới có thể được gán.

[Export]
public Sprite2D Sprite2D { get; set; }

Các lớp node tùy chỉnh cũng có thể được export trực tiếp. Hành vi lọc phụ thuộc vào việc lớp tùy chỉnh có phải là lớp toàn cục hay không.

Việc export NodePath như trong Godot 3.x vẫn khả thi, phòng khi bạn cần:

[Export]
public NodePath NodePath { get; set; }

public override void _Ready()
{
    var node = GetNode(NodePath);
}

Tài nguyên

[Export]
public Resource Resource { get; set; }

Trong Inspector, bạn có thể kéo thả một file resource từ FileSystem dock vào ô biến.

Tuy nhiên, mở menu thả xuống trong Inspector có thể cho ra một danh sách cực dài các lớp có thể tạo. Vì vậy, nếu bạn chỉ định một kiểu dẫn xuất từ Resource như:

[Export]
public AnimationNode AnimationNode { get; set; }

Menu thả xuống sẽ chỉ giới hạn ở AnimationNode và mọi lớp dẫn xuất của nó. Cũng có thể dùng các lớp resource tùy chỉnh, xem Lớp toàn cục trong C#.

Cần lưu ý rằng ngay cả khi script không chạy trong trình chỉnh sửa, các thuộc tính được export vẫn có thể chỉnh sửa. Điều này có thể dùng kết hợp với script ở chế độ "tool".

Export bit flag

Thành viên có kiểu là enum mang attribute [Flags] có thể được export và giá trị của chúng bị giới hạn trong các thành viên của kiểu enum. Trình chỉnh sửa sẽ tạo một widget trong Inspector, cho phép chọn không, một hoặc nhiều thành viên enum. Giá trị sẽ được lưu dưới dạng số nguyên.

Một flags enum dùng lũy thừa của 2 cho giá trị các thành viên enum. Cũng có thể có thành viên kết hợp nhiều flag bằng phép OR logic (|).

[Flags]
public enum SpellElements
{
    Fire = 1 << 1,
    Water = 1 << 2,
    Earth = 1 << 3,
    Wind = 1 << 4,

    FireAndWater = Fire | Water,
}

[Export]
public SpellElements MySpellElements { get; set; }

Số nguyên dùng làm bit flag có thể lưu nhiều giá trị true/false (boolean) trong một thuộc tính. Bằng cách dùng property hint Flags, bất kỳ flag nào trong số đã cho đều có thể được bật từ trình chỉnh sửa.

[Export(PropertyHint.Flags, "Fire,Water,Earth,Wind")]
public int SpellElements { get; set; } = 0;

Bạn phải cung cấp mô tả dạng chuỗi cho mỗi flag. Trong ví dụ này, Fire có giá trị 1, Water có giá trị 2, Earth có giá trị 4 và Wind ứng với giá trị 8. Thông thường, các hằng số nên được định nghĩa tương ứng (ví dụ private const int ElementWind = 8 và tương tự).

Bạn có thể thêm giá trị tường minh bằng dấu hai chấm:

[Export(PropertyHint.Flags, "Self:4,Allies:8,Foes:16")]
public int SpellTargets { get; set; } = 0;

Chỉ các giá trị lũy thừa của 2 mới hợp lệ làm tùy chọn bit flag. Giá trị nhỏ nhất được phép là 1, vì 0 nghĩa là không có gì được chọn. Bạn cũng có thể thêm các tùy chọn là tổ hợp của các flag khác:

[Export(PropertyHint.Flags, "Self:4,Allies:8,Self and Allies:12,Foes:16")]
public int SpellTargets { get; set; } = 0;

Godot cũng cung cấp các annotation export cho các layer vật lý và layer kết xuất được định nghĩa trong cài đặt dự án.

[Export(PropertyHint.Layers2DPhysics)]
public uint Layers2DPhysics { get; set; }
[Export(PropertyHint.Layers2DRender)]
public uint Layers2DRender { get; set; }
[Export(PropertyHint.Layers3DPhysics)]
public uint Layers3DPhysics { get; set; }
[Export(PropertyHint.Layers3DRender)]
public uint Layers3DRender { get; set; }

Dùng bit flag đòi hỏi bạn hiểu đôi chút về các phép toán bitwise. Nếu không chắc, hãy dùng biến boolean thay thế.

Export enum

Thành viên có kiểu là enum có thể được export và giá trị của chúng bị giới hạn trong các thành viên của kiểu enum. Trình chỉnh sửa sẽ tạo một widget trong Inspector, liệt kê các mục sau là "Thing 1", "Thing 2", "Another Thing". Giá trị sẽ được lưu dưới dạng số nguyên.

public enum MyEnum
{
    Thing1,
    Thing2,
    AnotherThing = -1,
}

[Export]
public MyEnum MyEnumCurrent { get; set; }

Thành viên kiểu số nguyên và chuỗi cũng có thể bị giới hạn trong một danh sách giá trị cụ thể bằng annotation [Export] với hint PropertyHint.Enum. Trình chỉnh sửa sẽ tạo một widget trong Inspector, liệt kê các mục sau là Warrior, Magician, Thief. Giá trị sẽ được lưu dưới dạng số nguyên, ứng với chỉ số của tùy chọn được chọn (tức 0, 1 hoặc 2).

[Export(PropertyHint.Enum, "Warrior,Magician,Thief")]
public int CharacterClass { get; set; }

Bạn có thể thêm giá trị tường minh bằng dấu hai chấm:

[Export(PropertyHint.Enum, "Slow:30,Average:60,Very Fast:200")]
public int CharacterSpeed { get; set; }

Nếu kiểu là string, giá trị sẽ được lưu dưới dạng chuỗi.

[Export(PropertyHint.Enum, "Rebecca,Mary,Leah")]
public string CharacterName { get; set; }

Nếu muốn đặt giá trị ban đầu, bạn phải chỉ định nó một cách tường minh:

[Export(PropertyHint.Enum, "Rebecca,Mary,Leah")]
public string CharacterName { get; set; } = "Rebecca";

Export nút bấm trong Inspector bằng [ExportToolButton]

Nếu muốn tạo một nút bấm được trong Inspector, bạn có thể dùng attribute [ExportToolButton]. Attribute này export một thuộc tính hoặc field kiểu Callable thành nút bấm được. Vì nó chạy trong trình chỉnh sửa, bắt buộc phải dùng attribute [Tool]. Khi nút được nhấn, callable sẽ được gọi:

[Tool]
public partial class MyNode : Node
{
    [ExportToolButton("Click me!")]
    public Callable ClickMeButton => Callable.From(ClickMe);

    public void ClickMe()
    {
        GD.Print("Hello world!");
    }
}

Bạn cũng có thể đặt biểu tượng cho nút bằng đối số thứ hai. Nếu được chỉ định, biểu tượng sẽ được lấy qua GetThemeIcon(), từ theme type "EditorIcons".

[ExportToolButton("Click me!", Icon = "CharacterBody2D")]
public Callable ClickMeButton => Callable.From(ClickMe);

Export collection

Như đã giải thích trong tài liệu C# Variant, chỉ một số mảng C# nhất định và các kiểu collection được định nghĩa trong namespace Godot.Collections là tương thích Variant, do đó chỉ những kiểu này mới có thể được export.

Export mảng Godot

[Export]
public Godot.Collections.Array Array { get; set; }

Dùng kiểu generic Godot.Collections.Array<T> cho phép chỉ định kiểu của các phần tử mảng, kiểu này sẽ được dùng làm hint cho trình chỉnh sửa. Inspector sẽ giới hạn các phần tử theo kiểu đã chỉ định.

[Export]
public Godot.Collections.Array<string> Array { get; set; }

Giá trị mặc định của mảng Godot là null. Có thể chỉ định giá trị mặc định khác:

[Export]
public Godot.Collections.Array<string> CharacterNames { get; set; } =
[
    "Rebecca",
    "Mary",
    "Leah",
];

Mảng có kiểu được chỉ định kế thừa từ resource có thể được thiết lập bằng cách kéo thả nhiều file từ FileSystem dock.

[Export]
public Godot.Collections.Array<Texture> Textures { get; set; }

[Export]
public Godot.Collections.Array<PackedScene> Scenes { get; set; }

Export dictionary Godot

[Export]
public Godot.Collections.Dictionary Dictionary { get; set; }

Dùng kiểu generic Godot.Collections.Dictionary<TKey, TValue> cho phép chỉ định kiểu của khóa và giá trị trong dictionary.

[Export]
public Godot.Collections.Dictionary<string, int> Dictionary { get; set; }

Giá trị mặc định của dictionary Godot là null. Có thể chỉ định giá trị mặc định khác:

[Export]
public Godot.Collections.Dictionary<string, int> CharacterLives { get; set; } = new Godot.Collections.Dictionary<string, int>
{
    ["Rebecca"] = 10,
    ["Mary"] = 42,
    ["Leah"] = 0,
};

Export mảng C#

Mảng C# có thể được export miễn là kiểu phần tử là kiểu tương thích Variant.

[Export]
public Vector3[] Vectors { get; set; }

[Export]
public NodePath[] NodePaths { get; set; }

Giá trị mặc định của mảng C# là null. Có thể chỉ định giá trị mặc định khác:

[Export]
public Vector3[] Vectors { get; set; } =
[
    new Vector3(1, 2, 3),
    new Vector3(3, 2, 1),
];

Thiết lập biến được export từ tool script

Khi thay đổi giá trị của một biến được export từ một script ở Chế độ tool, giá trị trong Inspector sẽ không tự động cập nhật. Để cập nhật, hãy gọi NotifyPropertyListChanged() sau khi đặt giá trị cho biến được export.

Export nâng cao

Không phải loại export nào cũng được cung cấp ở cấp độ ngôn ngữ, nhằm tránh độ phức tạp thiết kế không cần thiết. Phần sau mô tả một số tính năng export ít nhiều phổ biến có thể được triển khai bằng API cấp thấp.

Trước khi đọc tiếp, bạn nên làm quen với cách các thuộc tính được xử lý và cách tùy biến chúng bằng các phương thức _Set(), _Get() và _GetPropertyList() như mô tả trong Truy cập dữ liệu hoặc logic từ một đối tượng.
