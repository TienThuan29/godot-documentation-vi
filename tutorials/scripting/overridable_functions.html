Các hàm có thể override

Lớp Node của Godot cung cấp các hàm ảo mà bạn có thể ghi đè để cập nhật node mỗi frame hoặc khi có các sự kiện cụ thể, chẳng hạn khi chúng đi vào scene tree.

Tài liệu này giới thiệu những hàm mà bạn sẽ dùng thường xuyên nhất.

Xem thêm

Bên dưới, các hàm này dựa vào hệ thống notification cấp thấp của Godot. Để tìm hiểu thêm, xem Notification trong Godot.

Ngoài hàm khởi tạo (constructor) của lớp, có hai hàm cho phép bạn khởi tạo và lấy node: _enter_tree() và _ready().

Khi node đi vào Scene Tree, nó trở nên hoạt động và engine gọi phương thức _enter_tree() của nó. Các node con của node đó có thể chưa thuộc scene đang hoạt động. Vì bạn có thể gỡ bỏ và thêm lại node vào scene tree, hàm này có thể được gọi nhiều lần trong suốt vòng đời của một node.

Hầu hết thời gian, bạn sẽ dùng _ready() thay thế. Hàm này chỉ được gọi một lần trong vòng đời của node, sau _enter_tree(). _ready() đảm bảo rằng tất cả node con đã đi vào scene tree trước, nên bạn có thể gọi get_node() lên chúng một cách an toàn.

Xem thêm

Để tìm hiểu thêm về việc lấy tham chiếu node, hãy đọc Node và instance của scene.

Một callback liên quan khác là _exit_tree(), được engine gọi mỗi khi một node sắp rời khỏi scene tree. Đó có thể là khi bạn gọi Node.remove_child() hoặc khi bạn giải phóng một node.

# Called every time the node enters the scene tree.
func _enter_tree():
    pass

# Called when both the node and its children have entered the scene tree.
func _ready():
    pass

# Called when the node is about to leave the scene tree, after all its
# children received the _exit_tree() callback.
func _exit_tree():
    pass

// Called every time the node enters the scene tree.
public override void _EnterTree()
{
    base._EnterTree();
}

// Called when both the node and its children have entered the scene tree.
public override void _Ready()
{
    base._Ready();
}

// Called when the node is about to leave the scene tree, after all its
// children.
public override void _ExitTree()
{
    base._ExitTree();
}

Hai phương thức ảo _process() và _physics_process() cho phép bạn cập nhật node lần lượt mỗi frame và mỗi frame vật lý. Để biết thêm thông tin, hãy đọc tài liệu chuyên biệt: Xử lý idle và xử lý vật lý.

# Called every frame.
func _process(delta):
    pass

# Called every physics frame.
func _physics_process(delta):
    pass

public override void _Process(double delta)
{
    // Called every frame.
    base._Process(delta);
}

public override void _PhysicsProcess(double delta)
{
    // Called every physics frame.
    base._PhysicsProcess(delta);
}

Hai hàm callback tích hợp thiết yếu khác của node là Node._unhandled_input() và Node._input(), mà bạn dùng để vừa nhận vừa xử lý từng sự kiện input. Phương thức _unhandled_input() nhận mọi lần nhấn phím, nhấp chuột, v.v. chưa được xử lý trong callback _input() hoặc trong một thành phần giao diện người dùng. Nhìn chung, bạn nên dùng nó cho input của gameplay. Callback _input() cho phép bạn chặn và xử lý các sự kiện input trước khi _unhandled_input() nhận được chúng.

Để tìm hiểu thêm về đầu vào trong Godot, xem phần Đầu vào.

# Called once for every event.
func _unhandled_input(event):
    pass

# Called once for every event before _unhandled_input(), allowing you to
# consume some events.
func _input(event):
    pass

// Called once for every event.
public override void _UnhandledInput(InputEvent @event)
{
    base._UnhandledInput(@event);
}

// Called once for every event before _UnhandledInput(), allowing you to
// consume some events.
public override void _Input(InputEvent @event)
{
    base._Input(@event);
}

Còn có một số hàm có thể ghi đè khác như Node._get_configuration_warnings(). Các kiểu node chuyên biệt cung cấp thêm callback như CanvasItem._draw() để vẽ bằng code hoặc Control._gui_input() để xử lý nhấp chuột và input trên các phần tử UI.
