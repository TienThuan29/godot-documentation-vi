Comment tài liệu trong GDScript

Trong GDScript, comment có thể được dùng để viết tài liệu cho code và thêm mô tả cho các thành viên của script. Có hai điểm khác biệt giữa comment thông thường và comment tài liệu. Thứ nhất, comment tài liệu phải bắt đầu bằng hai dấu thăng ##. Thứ hai, nó phải đứng ngay trước một thành viên của script, hoặc với phần mô tả script, phải được đặt ở đầu script. Nếu một biến được export có tài liệu, phần mô tả của nó sẽ được dùng làm tooltip trong trình chỉnh sửa. Trình chỉnh sửa có thể tạo tài liệu này dưới dạng file XML.

Viết tài liệu cho script

Comment tài liệu cho script phải đứng trước mọi tài liệu của thành viên. Định dạng gợi ý cho tài liệu script có thể chia thành ba phần.

  • Mô tả ngắn gọn về script.

  • Mô tả chi tiết.

  • Bài hướng dẫn và các đánh dấu deprecated/experimental.

Để phân tách các phần này với nhau, comment tài liệu dùng các tag đặc biệt. Tag phải nằm ở đầu dòng (bỏ qua khoảng trắng phía trước) và phải có định dạng @, theo sau là từ khóa.

Thẻ (tag)

Mô tả ngắn

Không có tag. Nằm ở ngay đầu phần tài liệu.

Mô tả

Không có tag. Dùng một dòng trống để tách phần mô tả khỏi phần mô tả ngắn.

Bài hướng dẫn
@tutorial: https://example.com
@tutorial(The Title Here): https://example.com

Không còn khuyến khích dùng
@deprecated
@deprecated: Use [AnotherClass] instead.

Thử nghiệm
@experimental
@experimental: This class is unstable.

Ví dụ:

class_name MyClass
extends Node2D
## A brief description of the class's role and functionality.
##
## The description of the script, what it can do,
## and any further detail.
##
## @tutorial:             https://example.com/tutorial_1
## @tutorial(Tutorial 2): https://example.com/tutorial_2
## @experimental

Cảnh báo

Nếu có khoảng trắng giữa tên tag và dấu hai chấm, ví dụ @tutorial  :, nó sẽ không được coi là tag hợp lệ và sẽ bị bỏ qua.

Ghi chú

Khi phần mô tả trải dài nhiều dòng, khoảng trắng ở đầu và cuối mỗi dòng sẽ bị loại bỏ và các dòng được nối lại bằng một dấu cách. Để giữ ngắt dòng, hãy dùng [br]. Xem thêm BBCode and class reference bên dưới.

Viết tài liệu cho các thành viên của script

Các thành viên có thể viết tài liệu:

  • Signal

  • Enum

  • Giá trị enum

  • Hằng số

  • Biến

  • Hàm

  • Lớp con bên trong

Tài liệu của một thành viên script phải đứng ngay trước thành viên đó hoặc trước các annotation của nó nếu có. Phần mô tả có thể có nhiều dòng nhưng mỗi dòng phải bắt đầu bằng hai dấu thăng ## để được coi là một phần của tài liệu.

Thẻ (tag)

Mô tả

Không có tag.

Không còn khuyến khích dùng
@deprecated
@deprecated: Use [member another] instead.

Thử nghiệm
@experimental
@experimental: This method is incomplete.

Ví dụ:

## The description of the variable.
## @deprecated: Use [member other_var] instead.
var my_var

Ngoài ra, bạn có thể dùng comment tài liệu inline:

signal my_signal ## My signal.

enum MyEnum { ## My enum.
    VALUE_A = 0, ## Value A.
    VALUE_B = 1, ## Value B.
}

const MY_CONST = 1 ## My constant.

var my_var ## My variable.


func my_func(): ## My func.
    pass


class MyClass: ## My class.
    pass

Tài liệu script sẽ được cập nhật trong cửa sổ trợ giúp của trình chỉnh sửa mỗi khi script được cập nhật. Nếu tên biến thành viên hoặc tên hàm bắt đầu bằng dấu gạch dưới, nó sẽ được coi là private. Nó sẽ không xuất hiện trong tài liệu và sẽ bị bỏ qua trong cửa sổ trợ giúp.

Ví dụ script hoàn chỉnh

class_name MyClass
extends Node2D
## A brief description of the class's role and functionality.
##
## The description of the script, what it can do,
## and any further detail.
##
## @tutorial:             https://example.com/tutorial_1
## @tutorial(Tutorial 2): https://example.com/tutorial_2
## @experimental

## The description of a signal.
signal my_signal

## This is a description of the below enum.
enum Direction {
    ## Direction up.
    UP = 0,
    ## Direction down.
    DOWN = 1,
    ## Direction left.
    LEFT = 2,
    ## Direction right.
    RIGHT = 3,
}

## The description of a constant.
const GRAVITY = 9.8

## The description of the variable v1.
var v1

## This is a multiline description of the variable v2.[br]
## The type information below will be extracted for the documentation.
var v2: int

## If the member has any annotation, the annotation should
## immediately precede it.
@export
var v3 := some_func()


## As the following function is documented, even though its name starts with
## an underscore, it will appear in the help window.
func _fn(p1: int, p2: String) -> int:
    return 0


# The below function isn't documented and its name starts with an underscore
# so it will treated as private and will not be shown in the help window.
func _internal() -> void:
    pass


## Documenting an inner class.
##
## The same rules apply here. The documentation must
## immediately precede the class definition.
##
## @tutorial: https://example.com/tutorial
## @experimental
class Inner:

    ## Inner class variable v4.
    var v4


    ## Inner class function fn.
    func fn(): pass

Tag @deprecated và @experimental

Bạn có thể đánh dấu một lớp hoặc bất kỳ thành viên nào của nó là deprecated hoặc experimental. Việc này sẽ thêm chỉ báo tương ứng trong trình xem tài liệu dựng sẵn. Bạn có thể tùy chọn cung cấp một thông điệp ngắn giải thích vì sao API này không được khuyến khích. Điều này đặc biệt hữu ích cho người tạo plugin và thư viện.

  • Deprecated đánh dấu một API không được khuyến khích, có thể bị loại bỏ hoặc thay đổi không tương thích trong một bản phát hành lớn tương lai. Thông thường API được giữ lại để tương thích ngược.

  • Experimental đánh dấu một API mới chưa ổn định, có thể bị thay đổi hoặc loại bỏ trong nhánh phiên bản lớn hiện tại. Không khuyến khích dùng API này trong code production.

Ghi chú

Mặc dù về mặt kỹ thuật bạn có thể dùng cả tag @deprecated và @experimental trên cùng một lớp/thành viên, điều này không được khuyến khích vì đi ngược với các quy ước thông thường.

BBCode và tham chiếu lớp

Class reference của Godot hỗ trợ các tag giống BBCode. Chúng giúp định dạng văn bản đẹp hơn và cũng có thể được dùng trong tài liệu. Xem thêm BBCode trong class reference. Lưu ý rằng nó hơi khác so với BBCode của RichTextLabel.

Bất cứ khi nào liên kết tới một thành viên của lớp khác, bạn cần chỉ định tên lớp. Với liên kết trong cùng một lớp, tên lớp là tùy chọn và có thể bỏ qua.

Ghi chú

  1. Hiện tại chỉ class_@GDScript có annotation.

  2. [kbd] vô hiệu hóa BBCode cho đến khi parser gặp [/kbd].

  3. [code] vô hiệu hóa BBCode cho đến khi parser gặp [/code].

Cảnh báo

Dùng [codeblock] cho các khối code đã định dạng sẵn. Bên trong [codeblock], luôn dùng bốn dấu cách để thụt lề (trình phân tích sẽ xóa tab).

## Do something for this plugin. Before using the method
## you first have to [method initialize] [MyPlugin].[br]
## [color=yellow]Warning:[/color] Always [method clean] after use.[br]
## Usage:
## [codeblock]
## func _ready():
##     the_plugin.initialize()
##     the_plugin.do_something()
##     the_plugin.clean()
## [/codeblock]
func do_something():
    pass

Theo mặc định, [codeblock] tô sáng cú pháp GDScript. Bạn có thể thay đổi bằng thuộc tính lang. Các tùy chọn hiện được hỗ trợ là:

  • [codeblock lang=text] tắt tô sáng cú pháp;

  • [codeblock lang=gdscript] tô sáng cú pháp GDScript;

  • [codeblock lang=csharp] tô sáng cú pháp C# (chỉ trong phiên bản .NET).
