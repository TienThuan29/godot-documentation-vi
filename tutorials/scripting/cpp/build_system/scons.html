Hệ thống build chính: Làm việc với SCons

Xem thêm

Trang này hướng dẫn cách biên dịch godot-cpp. Nếu bạn muốn biên dịch Godot, hãy xem Giới thiệu về hệ thống build.

godot-cpp dùng SCons làm hệ thống build chính. Nó được mô phỏng theo hệ thống build của Godot, và một số lệnh có sẵn ở đó cũng dùng được trong các dự án godot-cpp.

Bắt đầu

Để build một dự án godot-cpp, thường chỉ cần cài SCons và chạy nó trong thư mục dự án:

scons

Bạn có thể muốn tìm hiểu các tùy chọn có sẵn:

scons --help

Để build lại dự án từ đầu một cách sạch sẽ, thêm --clean vào lệnh build:

scons --clean

Bạn có thể tìm thêm thông tin về các đối số SCons thông dụng và các mẫu build trong Hướng dẫn sử dụng SCons. Từng dự án godot-cpp có thể bổ sung thêm lệnh, vì vậy hãy tham khảo tài liệu riêng của chúng để biết thêm.

Cấu hình IDE

Hầu hết IDE có thể dùng file compile_commands.json để hiểu một dự án C++. Bạn có thể tạo file này với godot-cpp bằng lệnh sau:

# Generate compile_commands.json while compiling.
scons compiledb=yes

# Generate compile_commands.json without compiling.
scons compiledb=yes compile_commands.json

Để biết thêm thông tin, hãy xem các hướng dẫn cấu hình IDE. Dù được viết cho những người đóng góp cho Godot engine, phần lớn nội dung cũng áp dụng được cho các dự án godot-cpp.

Nạp GDExtension của bạn trong Godot

Godot nạp GDExtension bằng cách tìm các file .gdextension trong thư mục dự án. File .gdextension được dùng để chọn và nạp binary tương thích với máy tính / hệ điều hành hiện tại.

godot-cpp-template, cũng như phần Bắt đầu, cung cấp các file .gdextension mẫu cho GDExtension, tương thích rộng rãi với nhiều hệ thống khác nhau.

Build cho nhiều nền tảng

GDExtension được kỳ vọng chạy trên nhiều hệ thống khác nhau, mỗi hệ thống có binary và cấu hình build riêng. Nếu bạn định phát hành GDExtension của mình, chúng tôi khuyên bạn cung cấp binary cho mọi cấu hình được nêu trong file .gdextension của godot-cpp-template.

Có hai cách phổ biến để build đa nền tảng:

  • Công cụ build đa nền tảng

  • Tích hợp liên tục (CI)

godot-cpp-template có sẵn một thiết lập mẫu cho quy trình CI dựa trên GitHub.

Dùng file API tùy chỉnh

Mỗi nhánh của godot-cpp đi kèm một file API (extension_api.json) phù hợp với phiên bản Godot tương ứng (ví dụ nhánh 4.3 đi kèm file API tương thích với Godot phiên bản 4.3 trở lên).

Tuy nhiên, bạn có thể muốn dùng một file extension_api.json tùy chỉnh, chẳng hạn:

  • Nếu bạn muốn dùng các API mới nhất từ Godot master.

  • Nếu bạn tự build Godot với các tùy chọn khác so với bản build chính thức (ví dụ disable_3d=yes hoặc precision=double).

  • Nếu bạn muốn dùng các API do module tùy chỉnh cung cấp.

Để dùng file API tùy chỉnh, trước tiên bạn phải tạo nó từ bản thực thi Godot phù hợp:

godot --dump-extension-api

File extension_api.json kết quả sẽ được tạo trong thư mục của bản thực thi. Để dùng nó, bạn có thể thêm custom_api_file vào lệnh build:

scons platform=<platform> custom_api_file=<PATH_TO_FILE>

Hoặc bạn có thể đặt nó làm file API mặc định cho dự án bằng cách thêm dòng sau vào file SConstruct:

localEnv["custom_api_file"] = "extension_api.json"
