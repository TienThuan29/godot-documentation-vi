Tính giá trị biểu thức

Godot cung cấp lớp class_Expression mà bạn có thể dùng để tính giá trị biểu thức.

Một biểu thức có thể là:

  • Một biểu thức toán học như (2 + 4) * 16/4.0.

  • Một biểu thức boolean như true && false.

  • Một lời gọi phương thức dựng sẵn như deg_to_rad(90).

  • Một lời gọi phương thức trên script do người dùng cung cấp như update_health(), nếu base_instance được đặt thành giá trị khác null khi gọi Expression.execute().

Ghi chú

Lớp Expression độc lập với GDScript. Nó vẫn khả dụng ngay cả khi bạn biên dịch Godot với module GDScript bị tắt.

Cách dùng cơ bản

Để tính giá trị một biểu thức toán học, dùng:

var expression = Expression.new()
expression.parse("20 + 10*2 - 5/2.0")
var result = expression.execute()
print(result)  # 37.5

Các toán tử sau đây được hỗ trợ:

Toán tử

Ghi chú

Cộng (+)

Cũng có thể dùng để nối chuỗi và mảng: - "hello" + " world" = hello world - [1, 2] + [3, 4] = [1, 2, 3, 4]

Trừ (-)

Nhân (*)

Chia (/)

Thực hiện phép chia nguyên nếu cả hai toán hạng đều là số nguyên. Nếu ít nhất một trong hai là số thực dấu phẩy động, kết quả trả về là giá trị dấu phẩy động.

Chia lấy dư (%)

Trả về phần dư của phép chia nguyên (modulo). Kết quả luôn mang dấu của số bị chia.

Phép hội (&&)

Trả về kết quả của phép AND boolean.

Phép tuyển (||)

Trả về kết quả của phép OR boolean.

Phép phủ định (!)

Trả về kết quả của phép NOT boolean.

Khoảng trắng quanh toán tử là tùy chọn. Ngoài ra, hãy nhớ rằng thứ tự thực hiện phép tính thông thường vẫn được áp dụng. Dùng dấu ngoặc đơn để thay đổi thứ tự thực hiện khi cần.

Có thể dùng mọi kiểu Variant được Godot hỗ trợ: số nguyên, số thực dấu phẩy động, chuỗi, mảng, dictionary, màu, vector, …

Mảng và dictionary có thể được truy cập theo chỉ số giống như trong GDScript:

# Returns 1.
[1, 2][0]

# Returns 3. Negative indices can be used to count from the end of the array.
[1, 3][-1]

# Returns "green".
{"favorite_color": "green"}["favorite_color"]

# All 3 lines below return 7.0 (Vector3 is floating-point).
Vector3(5, 6, 7)[2]
Vector3(5, 6, 7)["z"]
Vector3(5, 6, 7).z

Truyền biến vào biểu thức

Bạn có thể truyền biến vào một biểu thức. Các biến này sau đó sẽ khả dụng trong "ngữ cảnh" của biểu thức và sẽ được thay thế khi được dùng trong biểu thức:

var expression = Expression.new()
# Define the variable names first in the second parameter of `parse()`.
# In this example, we use `x` for the variable name.
expression.parse("20 + 2 * x", ["x"])
# Then define the variable values in the first parameter of `execute()`.
# Here, `x` is assigned the integer value 5.
var result = expression.execute([5])
print(result)  # 30

Cả tên biến và giá trị biến bắt buộc phải được chỉ định dưới dạng mảng, kể cả khi bạn chỉ định nghĩa một biến. Ngoài ra, tên biến phân biệt chữ hoa chữ thường.

Đặt base instance cho biểu thức

Mặc định, một biểu thức có base instance là null. Điều này nghĩa là biểu thức không gắn với base instance nào.

Khi gọi Expression.execute(), bạn có thể đặt giá trị của tham số base_instance thành một instance đối tượng cụ thể như self, một instance script khác hoặc thậm chí một singleton:

func double(number):
    return number * 2


func _ready():
    var expression = Expression.new()
    expression.parse("double(10)")

    # This won't work since we're not passing the current script as the base instance.
    var result = expression.execute([], null)
    print(result)  # null

    # This will work since we're passing the current script (i.e. self)
    # as the base instance.
    result = expression.execute([], self)
    print(result)  # 20

Gắn một base instance cho phép bạn làm những việc sau:

  • Tham chiếu các hằng số (const) của instance trong biểu thức.

  • Tham chiếu các biến thành viên (var) của instance trong biểu thức.

  • Gọi các phương thức được định nghĩa trong instance và dùng giá trị trả về của chúng trong biểu thức.

Cảnh báo

Đặt base instance thành giá trị khác null cho phép tham chiếu hằng số, biến thành viên và gọi mọi phương thức được định nghĩa trong script gắn với instance đó. Việc cho phép người dùng nhập biểu thức có thể dẫn đến gian lận trong game, hoặc thậm chí gây ra lỗ hổng bảo mật nếu bạn cho phép client bất kỳ chạy biểu thức trên thiết bị của người chơi khác.

Script ví dụ

Script dưới đây minh họa những gì lớp Expression có thể làm:

const DAYS_IN_YEAR = 365
var script_member_variable = 1000


func _ready():
    # Constant boolean expression.
    evaluate("true && false")
    # Boolean expression with variables.
    evaluate("!(a && b)", ["a", "b"], [true, false])

    # Constant mathexpression.
    evaluate("2 + 2")
    # Math expression with variables.
    evaluate("x + y", ["x", "y"], [60, 100])

    # Call built-in method (built-in math function call).
    evaluate("deg_to_rad(90)")

    # Call user method (defined in the script).
    # We can do this because the expression execution is bound to `self`
    # in the `evaluate()` method.
    # Since this user method returns a value, we can use it in math expressions.
    evaluate("call_me() + DAYS_IN_YEAR + script_member_variable")
    evaluate("call_me(42)")
    evaluate("call_me('some string')")


func evaluate(command, variable_names = [], variable_values = []) -> void:
    var expression = Expression.new()
    var error = expression.parse(command, variable_names)
    if error != OK:
        push_error(expression.get_error_text())
        return

    var result = expression.execute(variable_values, self)

    if not expression.has_execute_failed():
        print(str(result))


func call_me(argument = null):
    print("\nYou called 'call_me()' in the expression text.")
    if argument:
        print("Argument passed: %s" % argument)

    # The method's return value is also the expression's return value.
    return 0

Hàm dựng sẵn

Mọi phương thức trong Global Scope đều khả dụng trong lớp Expression, kể cả khi biểu thức không được gắn base instance nào. Tham số và kiểu trả về cũng giống hệt.

Tuy nhiên, khác với GDScript, các tham số luôn bắt buộc kể cả khi chúng được ghi là tùy chọn trong tài liệu tham khảo lớp. Ngược lại, giới hạn về đối số này không áp dụng cho các hàm do người dùng tạo khi bạn gắn base instance cho biểu thức.
