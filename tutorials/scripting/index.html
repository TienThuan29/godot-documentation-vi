Lập trình script

Phần này trình bày các ngôn ngữ lập trình và tính năng cốt lõi để lập trình game của bạn trong Godot.

Tại đây, bạn sẽ tìm thấy những thông tin chưa được đề cập trong các phần chuyên biệt hơn. Ví dụ, để tìm hiểu về đầu vào, chúng tôi khuyên bạn đọc Đầu vào.

Ngôn ngữ lập trình

Mỗi phần dưới đây tập trung vào một ngôn ngữ lập trình cụ thể.

  • GDScript
  • C#/.NET
  • C++ (godot-cpp)
  • Các ngôn ngữ khác

Tính năng cốt lõi

Một số tính năng gắn liền với engine và có sẵn trong mọi ngôn ngữ được hỗ trợ. Dù bạn viết code bằng GDScript, C# hay ngôn ngữ khác, các trang dưới đây sẽ giúp bạn tận dụng tối đa Godot.
