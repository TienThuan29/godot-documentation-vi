Xử lý idle và xử lý vật lý

Game chạy theo một vòng lặp. Mỗi frame, bạn cần cập nhật trạng thái thế giới game trước khi vẽ nó lên màn hình. Godot cung cấp hai phương thức ảo trong lớp Node để làm việc này: Node._process() và Node._physics_process(). Nếu bạn định nghĩa một hoặc cả hai trong script, engine sẽ tự động gọi chúng.

Có hai kiểu xử lý mà bạn có thể dùng:

  1. Xử lý idle cho phép bạn chạy mã cập nhật một node mỗi frame, thường xuyên nhất có thể.

  2. Xử lý vật lý diễn ra với tần suất cố định, mặc định là 60 lần mỗi giây. Nó độc lập với framerate thực tế của game và giúp vật lý chạy mượt mà. Bạn nên dùng nó cho mọi thứ liên quan đến physics engine, chẳng hạn như di chuyển một body va chạm với môi trường.

Bạn có thể kích hoạt xử lý idle bằng cách định nghĩa phương thức _process() trong script. Bạn có thể tắt và bật lại nó bằng cách gọi Node.set_process().

Engine gọi phương thức này mỗi khi vẽ một frame:

func _process(delta):
    # Do something...
    pass

public override void _Process(double delta)
{
    // Do something...
}

Hãy nhớ rằng tần suất engine gọi _process() phụ thuộc vào framerate của ứng dụng, vốn thay đổi theo thời gian và giữa các thiết bị.

Tham số delta của hàm là thời gian (tính bằng giây) đã trôi qua kể từ lần gọi _process() trước đó. Hãy dùng tham số này để các phép tính không phụ thuộc vào framerate. Ví dụ, bạn luôn nên nhân giá trị tốc độ với delta để tạo hoạt ảnh cho một vật thể chuyển động.

Xử lý vật lý hoạt động với một hàm ảo tương tự: _physics_process(). Hãy dùng nó cho các phép tính phải diễn ra trước mỗi bước vật lý, chẳng hạn như di chuyển một nhân vật va chạm với thế giới game. Như đã nói ở trên, _physics_process() chạy theo các khoảng thời gian cố định nhất có thể để giữ cho các tương tác vật lý ổn định. Bạn có thể thay đổi khoảng thời gian giữa các bước vật lý trong Project Settings, tại Physics -> Common -> Physics Fps. Mặc định, nó được đặt để chạy 60 lần mỗi giây.

Engine gọi phương thức này trước mỗi bước vật lý:

func _physics_process(delta):
    # Do something...
    pass

public override void _PhysicsProcess(double delta)
{
    // Do something...
}

Hàm _process() không được đồng bộ với vật lý. Tần suất của nó phụ thuộc vào phần cứng và mức độ tối ưu của game. Trong các game đơn luồng, nó cũng chạy sau bước vật lý.

Bạn có thể thấy hàm _process() hoạt động bằng cách tạo một scene chỉ có một node Label, gắn script sau vào nó:

extends Label

var time = 0

func _process(delta):
    time += delta
    text = str(time) # 'text' is a built-in Label property.

using Godot;

public partial class CustomLabel : Label
{
    private double _time;

    public override void _Process(double delta)
    {
        _time += delta;
        Text = _time.ToString(); // 'Text' is a built-in Label property.
    }
}

Khi chạy scene, bạn sẽ thấy một bộ đếm tăng lên sau mỗi frame.
