Lập trình script đa ngôn ngữ

Godot cho phép bạn kết hợp nhiều ngôn ngữ script tùy theo nhu cầu. Nghĩa là một dự án có thể định nghĩa node bằng cả C# và GDScript. Trang này trình bày các cách tương tác có thể có giữa hai node viết bằng hai ngôn ngữ khác nhau.

Hai script sau sẽ được dùng làm tham chiếu xuyên suốt trang này.

extends Node

var my_property: String = "my gdscript value":
    get:
        return my_property
    set(value):
        my_property = value

signal my_signal
signal my_signal_with_params(msg: String, n: int)

func print_node_name(node: Node) -> void:
    print(node.get_name())

func print_array(arr: Array) -> void:
    for element in arr:
        print(element)

func print_n_times(msg: String, n: int) -> void:
    for i in range(n):
        print(msg)

func my_signal_handler():
    print("The signal handler was called!")

func my_signal_with_params_handler(msg: String, n: int):
    print_n_times(msg, n)

using Godot;

public partial class MyCSharpNode : Node
{
    public string MyProperty { get; set; } = "my c# value";

    [Signal] public delegate void MySignalEventHandler();
    [Signal] public delegate void MySignalWithParamsEventHandler(string msg, int n);

    public void PrintNodeName(Node node)
    {
        GD.Print(node.Name);
    }

    public void PrintArray(string[] arr)
    {
        foreach (string element in arr)
        {
            GD.Print(element);
        }
    }

    public void PrintNTimes(string msg, int n)
    {
        for (int i = 0; i < n; ++i)
        {
            GD.Print(msg);
        }
    }

    public void MySignalHandler()
    {
        GD.Print("The signal handler was called!");
    }

    public void MySignalWithParamsHandler(string msg, int n)
    {
        PrintNTimes(msg, n);
    }
}

Tạo instance node

Nếu không dùng node từ scene tree, có lẽ bạn sẽ muốn tạo instance node trực tiếp từ code.

Tạo instance node C# từ GDScript

Dùng C# từ GDScript không tốn nhiều công. Sau khi được tải (xem Lớp dưới dạng resource), script có thể được tạo instance bằng new().

var MyCSharpScript = load("res://Path/To/MyCSharpNode.cs")
var my_csharp_node = MyCSharpScript.new()

Cảnh báo

Khi tạo script .cs, hãy luôn nhớ rằng lớp mà Godot sử dụng là lớp có tên trùng với chính tệp .cs. Nếu lớp đó không tồn tại trong tệp, bạn sẽ gặp lỗi sau: Invalid call. Nonexistent function `new` in base.

Ví dụ, MyCoolNode.cs phải chứa một lớp tên là MyCoolNode.

Lớp C# cần kế thừa từ một lớp Godot, ví dụ GodotObject. Nếu không, lỗi tương tự sẽ xảy ra.

Bạn cũng cần kiểm tra tệp .cs đã được tham chiếu trong tệp .csproj của dự án. Nếu không, lỗi tương tự sẽ xảy ra.

Tạo instance node GDScript từ C#

Từ phía C#, mọi thứ hoạt động tương tự. Sau khi được tải, GDScript có thể được tạo instance bằng GDScript.New().

var myGDScript = GD.Load<GDScript>("res://path/to/my_gd_script.gd");
var myGDScriptNode = (GodotObject)myGDScript.New(); // This is a GodotObject.

Ở đây chúng ta dùng một class_Object, nhưng bạn có thể dùng chuyển đổi kiểu như được giải thích trong Chuyển đổi kiểu và ép kiểu.

Truy cập trường

Truy cập trường C# từ GDScript

Truy cập trường C# từ GDScript rất đơn giản, bạn không cần lo lắng gì cả.

# Output: "my c# value".
print(my_csharp_node.MyProperty)
my_csharp_node.MyProperty = "MY C# VALUE"
# Output: "MY C# VALUE".
print(my_csharp_node.MyProperty)

Truy cập trường GDScript từ C#

Vì C# là ngôn ngữ kiểu tĩnh, việc truy cập GDScript từ C# phức tạp hơn một chút. Bạn sẽ phải dùng GodotObject.Get() và GodotObject.Set(). Đối số đầu tiên là tên của trường bạn muốn truy cập.

// Output: "my gdscript value".
GD.Print(myGDScriptNode.Get("my_property"));
myGDScriptNode.Set("my_property", "MY GDSCRIPT VALUE");
// Output: "MY GDSCRIPT VALUE".
GD.Print(myGDScriptNode.Get("my_property"));

Lưu ý rằng khi gán giá trị cho trường, bạn chỉ nên dùng các kiểu mà phía GDScript biết đến. Về cơ bản, bạn nên làm việc với các kiểu có sẵn như mô tả trong Kiểu dựng sẵn hoặc các lớp kế thừa class_Object.

Gọi phương thức

Gọi phương thức C# từ GDScript

Một lần nữa, gọi phương thức C# từ GDScript khá đơn giản. Quá trình marshalling sẽ cố gắng hết sức để ép kiểu các đối số cho khớp với chữ ký hàm. Nếu không thể, bạn sẽ gặp lỗi sau: Invalid call. Nonexistent function `FunctionName`.

# Output: "my_gd_script_node" (or name of node where this code is placed).
my_csharp_node.PrintNodeName(self)
# This line will fail.
# my_csharp_node.PrintNodeName()

# Outputs "Hello there!" twice, once per line.
my_csharp_node.PrintNTimes("Hello there!", 2)

# Output: "a", "b", "c" (one per line).
my_csharp_node.PrintArray(["a", "b", "c"])
# Output: "1", "2", "3"  (one per line).
my_csharp_node.PrintArray([1, 2, 3])

Gọi phương thức GDScript từ C#

Để gọi phương thức GDScript từ C#, bạn cần dùng GodotObject.Call(). Đối số đầu tiên là tên phương thức bạn muốn gọi. Các đối số tiếp theo sẽ được truyền cho phương thức đó.

// Output: "MyCSharpNode" (or name of node where this code is placed).
myGDScriptNode.Call("print_node_name", this);
// This line will fail silently and won't error out.
// myGDScriptNode.Call("print_node_name");

// Outputs "Hello there!" twice, once per line.
myGDScriptNode.Call("print_n_times", "Hello there!", 2);

string[] arr = ["a", "b", "c"];
// Output: "a", "b", "c" (one per line).
myGDScriptNode.Call("print_array", arr);
// Output: "1", "2", "3"  (one per line).
myGDScriptNode.Call("print_array", new int[] { 1, 2, 3 });
// Note how the type of each array entry does not matter
// as long as it can be handled by the marshaller.

Kết nối với signal

Kết nối với signal C# từ GDScript

Kết nối với một signal C# từ GDScript cũng giống như kết nối với signal được định nghĩa trong GDScript:

my_csharp_node.MySignal.connect(my_signal_handler)

my_csharp_node.MySignalWithParams.connect(my_signal_with_params_handler)

Kết nối với signal GDScript từ C#

Kết nối với signal GDScript từ C# chỉ hoạt động với phương thức Connect vì không có kiểu tĩnh C# nào cho các signal được định nghĩa bằng GDScript:

myGDScriptNode.Connect("my_signal", Callable.From(MySignalHandler));

myGDScriptNode.Connect("my_signal_with_params", Callable.From<string, int>(MySignalWithParamsHandler));

Kế thừa

Tệp GDScript không thể kế thừa từ script C#. Tương tự, script C# không thể kế thừa từ tệp GDScript. Do việc triển khai điều này rất phức tạp, giới hạn này khó có khả năng được gỡ bỏ trong tương lai. Xem issue GitHub này để biết thêm thông tin.
