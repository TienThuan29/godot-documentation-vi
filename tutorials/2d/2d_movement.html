Tổng quan về chuyển động 2D

Giới thiệu

Người mới bắt đầu nào cũng từng hỏi: "Làm sao để di chuyển nhân vật?" Tùy vào thể loại game bạn làm, bạn có thể có những yêu cầu đặc biệt, nhưng nhìn chung chuyển động trong hầu hết game 2D đều dựa trên một số ít kiểu thiết kế.

Chúng ta sẽ dùng CharacterBody2D cho các ví dụ này, nhưng các nguyên tắc cũng áp dụng cho các loại node khác (Area2D, RigidBody2D).

Thiết lập

Mỗi ví dụ dưới đây dùng cùng một thiết lập scene. Hãy bắt đầu với một CharacterBody2D có hai node con: Sprite2D và CollisionShape2D. Bạn có thể dùng biểu tượng Godot (icon.svg) làm texture cho Sprite2D hoặc dùng bất kỳ hình ảnh 2D nào khác bạn có.

Mở Project -> Project Settings và chọn thẻ "Input Map". Thêm các input action sau (xem InputEvent để biết chi tiết):

Chuyển động 8 hướng

Trong tình huống này, bạn muốn người dùng nhấn bốn phím hướng (lên/trái/xuống/phải hoặc W/A/S/D) để di chuyển theo hướng đã chọn. Tên gọi "chuyển động 8 hướng" xuất phát từ việc người chơi có thể di chuyển chéo bằng cách nhấn hai phím cùng lúc.

Gắn một script vào character body và thêm đoạn code sau:

extends CharacterBody2D

@export var speed = 400

func get_input():
    var input_direction = Input.get_vector("left", "right", "up", "down")
    velocity = input_direction * speed

func _physics_process(delta):
    get_input()
    move_and_slide()

using Godot;

public partial class Movement : CharacterBody2D
{
    [Export]
    public int Speed { get; set; } = 400;

    public void GetInput()
    {

        Vector2 inputDirection = Input.GetVector("left", "right", "up", "down");
        Velocity = inputDirection * Speed;
    }

    public override void _PhysicsProcess(double delta)
    {
        GetInput();
        MoveAndSlide();
    }
}

Trong hàm get_input(), chúng ta dùng get_vector() của Input để kiểm tra bốn sự kiện phím và trả về một vector hướng tổng hợp.

Sau đó, chúng ta có thể đặt vận tốc bằng cách nhân vector hướng này, có độ dài 1, với tốc độ mong muốn.

Mẹo

Nếu bạn chưa từng dùng toán vector, hoặc cần ôn lại, bạn có thể xem giải thích về cách dùng vector trong Godot tại Toán vector.

Ghi chú

Nếu đoạn code trên không làm gì khi bạn nhấn phím, hãy kiểm tra lại xem bạn đã thiết lập input action đúng như mô tả trong phần Thiết lập của bài hướng dẫn này chưa.

Xoay + di chuyển

Kiểu chuyển động này đôi khi được gọi là "kiểu Asteroids" vì nó giống cách hoạt động của game arcade kinh điển đó. Nhấn trái/phải sẽ xoay nhân vật, còn lên/xuống sẽ di chuyển nó tiến hoặc lùi theo hướng nó đang quay mặt.

extends CharacterBody2D

@export var speed = 400
@export var rotation_speed = 1.5

var rotation_direction = 0

func get_input():
    rotation_direction = Input.get_axis("left", "right")
    velocity = transform.x * Input.get_axis("down", "up") * speed

func _physics_process(delta):
    get_input()
    rotation += rotation_direction * rotation_speed * delta
    move_and_slide()

using Godot;

public partial class Movement : CharacterBody2D
{
    [Export]
    public int Speed { get; set; } = 400;

    [Export]
    public float RotationSpeed { get; set; } = 1.5f;

    private float _rotationDirection;

    public void GetInput()
    {
        _rotationDirection = Input.GetAxis("left", "right");
        Velocity = Transform.X * Input.GetAxis("down", "up") * Speed;
    }

    public override void _PhysicsProcess(double delta)
    {
        GetInput();
        Rotation += _rotationDirection * RotationSpeed * (float)delta;
        MoveAndSlide();
    }
}

Ở đây chúng ta đã thêm hai biến để theo dõi hướng và tốc độ xoay. Góc xoay được áp dụng trực tiếp vào thuộc tính rotation của body.

Để đặt vận tốc, chúng ta dùng transform.x của body, là vector chỉ theo hướng "phía trước" của body, rồi nhân nó với tốc độ.

Xoay + di chuyển (chuột)

Kiểu chuyển động này là biến thể của kiểu trước. Lần này, hướng được xác định bởi vị trí chuột thay vì bàn phím. Nhân vật sẽ luôn "nhìn về" con trỏ chuột. Tuy nhiên, input tiến/lùi vẫn giữ nguyên.

extends CharacterBody2D

@export var speed = 400

func get_input():
    look_at(get_global_mouse_position())
    velocity = transform.x * Input.get_axis("down", "up") * speed

func _physics_process(delta):
    get_input()
    move_and_slide()

using Godot;

public partial class Movement : CharacterBody2D
{
    [Export]
    public int Speed { get; set; } = 400;

    public void GetInput()
    {
        LookAt(GetGlobalMousePosition());
        Velocity = Transform.X * Input.GetAxis("down", "up") * Speed;
    }

    public override void _PhysicsProcess(double delta)
    {
        GetInput();
        MoveAndSlide();
    }
}

Ở đây chúng ta dùng phương thức look_at() của Node2D để hướng người chơi về phía vị trí chuột. Nếu không có hàm này, bạn có thể đạt hiệu quả tương tự bằng cách đặt góc như sau:

rotation = get_global_mouse_position().angle_to_point(position)

var rotation = GetGlobalMousePosition().AngleToPoint(Position);

Nhấp để di chuyển

Ví dụ cuối cùng này chỉ dùng chuột để điều khiển nhân vật. Nhấp lên màn hình sẽ khiến người chơi di chuyển đến vị trí đích.

extends CharacterBody2D

@export var speed = 400

var target = position

func _input(event):
    # Use is_action_pressed to only accept single taps as input instead of mouse drags.
    if event.is_action_pressed(&"click"):
        target = get_global_mouse_position()

func _physics_process(delta):
    velocity = position.direction_to(target) * speed
    # look_at(target)
    if position.distance_to(target) > 10:
        move_and_slide()

using Godot;

public partial class Movement : CharacterBody2D
{
    [Export]
    public int Speed { get; set; } = 400;

    private Vector2 _target;

    public override void _Input(InputEvent @event)
    {
        // Use IsActionPressed to only accept single taps as input instead of mouse drags.
        if (@event.IsActionPressed("click"))
        {
            _target = GetGlobalMousePosition();
        }
    }

    public override void _PhysicsProcess(double delta)
    {
        Velocity = Position.DirectionTo(_target) * Speed;
        // LookAt(_target);
        if (Position.DistanceTo(_target) > 10)
        {
            MoveAndSlide();
        }
    }
}

Hãy chú ý phép kiểm tra distance_to() chúng ta thực hiện trước khi di chuyển. Nếu không có phép kiểm tra này, body sẽ bị "rung" khi đến vị trí đích, vì nó di chuyển hơi vượt quá vị trí rồi cố quay lại, chỉ để lại đi quá xa và lặp lại.

Bỏ comment dòng look_at() cũng sẽ khiến body quay theo hướng chuyển động nếu bạn muốn.

Mẹo

Kỹ thuật này cũng có thể dùng làm cơ sở cho nhân vật "đi theo". Vị trí target có thể là vị trí của bất kỳ đối tượng nào bạn muốn di chuyển tới.

Tóm tắt

Bạn có thể thấy các đoạn code mẫu này hữu ích làm điểm khởi đầu cho dự án của mình. Hãy thoải mái sử dụng và thử nghiệm với chúng để xem bạn có thể làm được gì.
