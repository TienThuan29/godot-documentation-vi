Tải và lưu file khi chạy

Xem thêm

Xem Lưu game để biết thông tin về việc lưu và tải tiến trình game.

Đôi khi, xuất pack, patch và mod không phải là lựa chọn lý tưởng khi bạn muốn người chơi có thể tải nội dung do người dùng tạo vào dự án. Cách đó yêu cầu người dùng tạo file PCK hoặc ZIP qua trình chỉnh sửa Godot, chứa các resource đã được Godot import.

Một số ví dụ về trường hợp sử dụng việc tải và lưu file lúc runtime:

  • Tải các gói texture được thiết kế cho game.

  • Tải các bản nhạc do người dùng cung cấp và phát chúng trên một đài radio trong game.

  • Tải các màn chơi tùy chỉnh hoặc mô hình 3D có thể được thiết kế bằng bất kỳ phần mềm DCC 3D nào có khả năng xuất sang glTF hoặc FBX (bao gồm cả các scene glTF do Godot lưu lúc runtime).

  • Sử dụng font do người dùng cung cấp cho menu và HUD.

  • Lưu/tải một định dạng file có thể chứa nhiều file nhưng vẫn dễ dàng được các ứng dụng khác đọc (ZIP).

  • Tải các file được tạo bởi một game hoặc chương trình khác, thậm chí là các file dữ liệu game từ một game khác không được làm bằng Godot.

Việc tải file lúc runtime có thể kết hợp với HTTP request để tải resource trực tiếp từ Internet.

Cảnh báo

Không sử dụng cách tải lúc runtime này để tải các resource thuộc dự án, vì nó kém hiệu quả hơn và không cho phép tận dụng chức năng xử lý resource của Godot (chẳng hạn như translation remap). Xem Quy trình import để biết chi tiết.

Xem thêm

Bạn có thể xem cách lưu và tải hoạt động trong thực tế qua dự án demo Run-time File Saving and Loading (Serialization).

File văn bản thuần và file nhị phân

Lớp class_FileAccess của Godot cung cấp các phương thức để truy cập file trên hệ thống file nhằm đọc và ghi:

func save_file(content):
    var file = FileAccess.open("/path/to/file.txt", FileAccess.WRITE)
    file.store_string(content)

func load_file():
    var file = FileAccess.open("/path/to/file.txt", FileAccess.READ)
    var content = file.get_as_text()
    return content

private void SaveFile(string content)
{
    using var file = FileAccess.Open("/Path/To/File.txt", FileAccess.ModeFlags.Write);
    file.StoreString(content);
}

private string LoadFile()
{
    using var file = FileAccess.Open("/Path/To/File.txt", FileAccess.ModeFlags.Read);
    string content = file.GetAsText();
    return content;
}

Để xử lý các định dạng nhị phân tùy chỉnh (chẳng hạn như tải các định dạng file mà Godot không hỗ trợ), class_FileAccess cung cấp nhiều phương thức để đọc/ghi số nguyên, số thực, chuỗi và nhiều kiểu khác. Các phương thức FileAccess này có tên bắt đầu bằng get_ và store_.

Nếu bạn cần kiểm soát nhiều hơn khi đọc file nhị phân hoặc cần đọc các luồng nhị phân không thuộc một file, class_PackedByteArray cung cấp nhiều phương thức hỗ trợ để giải mã/mã hóa chuỗi byte thành số nguyên, số thực, chuỗi và nhiều kiểu khác. Các phương thức PackedByteArray này có tên bắt đầu bằng decode_ và encode_. Xem thêm API tuần tự hóa nhị phân.

Hình ảnh

Phương thức tĩnh Image.load_from_file của Image xử lý mọi thứ, từ việc nhận diện định dạng dựa trên phần mở rộng file cho đến việc đọc file từ ổ đĩa.

Nếu bạn cần xử lý lỗi hoặc kiểm soát nhiều hơn (chẳng hạn như thay đổi tỉ lệ khi tải một file SVG), hãy dùng một trong các phương thức sau tùy theo định dạng file:

  • Image.load_jpg_from_buffer

  • Image.load_ktx_from_buffer

  • Image.load_png_from_buffer

  • Image.load_svg_from_buffer hoặc Image.load_svg_from_string

  • Image.load_tga_from_buffer

  • Image.load_webp_from_buffer

  • Image.load_exr_from_buffer

Godot cũng có thể lưu một số định dạng hình ảnh khi đang chạy bằng các phương thức sau:

  • Image.save_png hoặc Image.save_png_to_buffer

  • Image.save_webp hoặc Image.save_webp_to_buffer

  • Image.save_jpg hoặc Image.save_jpg_to_buffer

  • Image.save_exr hoặc Image.save_exr_to_buffer

Các phương thức có hậu tố to_buffer lưu hình ảnh vào một PackedByteArray thay vì vào hệ thống file. Điều này hữu ích khi gửi hình ảnh qua mạng hoặc vào một file nén ZIP mà không cần ghi nó ra hệ thống file. Cách này có thể tăng hiệu năng nhờ giảm mức sử dụng I/O.

Ghi chú

Nếu hiển thị hình ảnh đã tải lên một bề mặt 3D, hãy nhớ gọi Image.generate_mipmaps để texture không bị lấm tấm hạt khi nhìn từ xa. Điều này cũng hữu ích trong 2D khi làm theo hướng dẫn về giảm răng cưa khi downsampling.

Ví dụ về việc tải một hình ảnh và hiển thị nó trong node class_TextureRect (cần chuyển đổi sang class_ImageTexture):

# Load an image of any format supported by Godot from the filesystem.
var image = Image.load_from_file(path)
# Optionally, generate mipmaps if displaying the texture on a 3D surface
# so that the texture doesn't look grainy when viewed at a distance.
#image.generate_mipmaps()
$TextureRect.texture = ImageTexture.create_from_image(image)

# Save the loaded Image to a PNG image.
image.save_png("/path/to/file.png")

# Save the converted ImageTexture to a PNG image.
$TextureRect.texture.get_image().save_png("/path/to/file.png")

// Load an image of any format supported by Godot from the filesystem.
var image = Image.LoadFromFile(path);
// Optionally, generate mipmaps if displaying the texture on a 3D surface
// so that the texture doesn't look grainy when viewed at a distance.
// image.GenerateMipmaps();
GetNode<TextureRect>("TextureRect").Texture = ImageTexture.CreateFromImage(image);

// Save the loaded Image to a PNG image.
image.SavePng("/Path/To/File.png");

// Save the converted ImageTexture to a PNG image.
GetNode<TextureRect>("TextureRect").Texture.GetImage().SavePng("/Path/To/File.png");

File âm thanh/video

Godot hỗ trợ tải âm thanh Ogg Vorbis, MP3 và WAV lúc runtime. Lưu ý rằng không phải tất cả các file có phần mở rộng .ogg đều là file Ogg Vorbis. Một số có thể là video Ogg Theora, hoặc chứa âm thanh Opus bên trong container Ogg. Các file này sẽ không được tải đúng như file âm thanh trong Godot.

Ví dụ về việc tải một file âm thanh Ogg Vorbis trong node class_AudioStreamPlayer:

$AudioStreamPlayer.stream = AudioStreamOggVorbis.load_from_file(path)

GetNode<AudioStreamPlayer>("AudioStreamPlayer").Stream = AudioStreamOggVorbis.LoadFromFile(path);

Ví dụ về việc tải một file video Ogg Theora trong node class_VideoStreamPlayer:

var video_stream_theora = VideoStreamTheora.new()
# File extension is ignored, so it is possible to load Ogg Theora videos
# that have a `.ogg` extension this way.
video_stream_theora.file = "/path/to/file.ogv"
$VideoStreamPlayer.stream = video_stream_theora

# VideoStreamPlayer's Autoplay property won't work if the stream is empty
# before this property is set, so call `play()` after setting `stream`.
$VideoStreamPlayer.play()

var videoStreamTheora = new VideoStreamTheora();
// File extension is ignored, so it is possible to load Ogg Theora videos
// that have a `.ogg` extension this way.
videoStreamTheora.File = "/Path/To/File.ogv";
GetNode<VideoStreamPlayer>("VideoStreamPlayer").Stream = videoStreamTheora;

// VideoStreamPlayer's Autoplay property won't work if the stream is empty
// before this property is set, so call `Play()` after setting `Stream`.
GetNode<VideoStreamPlayer>("VideoStreamPlayer").Play();

Scene 3D

Godot hỗ trợ glTF 2.0 ở mức hàng đầu, cả trong trình chỉnh sửa lẫn trong các dự án đã xuất. Kết hợp class_gltfdocument và class_gltfstate, Godot có thể tải và lưu file glTF trong các dự án đã xuất, ở cả định dạng văn bản (.gltf) và nhị phân (.glb). Nên ưu tiên định dạng nhị phân vì ghi nhanh hơn và kích thước nhỏ hơn, nhưng định dạng văn bản thì dễ debug hơn.

Kể từ Godot 4.3, các scene FBX cũng có thể được tải (nhưng không thể lưu) lúc runtime bằng các lớp class_fbxdocument và class_fbxstate. Code để làm việc này giống với glTF, nhưng bạn cần thay tất cả GLTFDocument và GLTFState bằng FBXDocument và FBXState trong các đoạn code mẫu bên dưới.

Ví dụ về việc tải một scene glTF và thêm node gốc của nó vào scene:

# Load an existing glTF scene.
# GLTFState is used by GLTFDocument to store the loaded scene's state.
# GLTFDocument is the class that handles actually loading glTF data into a Godot node tree,
# which means it supports glTF features such as lights and cameras.
var gltf_document_load = GLTFDocument.new()
var gltf_state_load = GLTFState.new()
var error = gltf_document_load.append_from_file("/path/to/file.gltf", gltf_state_load)
if error == OK:
    var gltf_scene_root_node = gltf_document_load.generate_scene(gltf_state_load)
    add_child(gltf_scene_root_node)
else:
    show_error("Couldn't load glTF scene (error code: %s)." % error_string(error))

# Save a new glTF scene.
var gltf_document_save := GLTFDocument.new()
var gltf_state_save := GLTFState.new()
gltf_document_save.append_from_scene(gltf_scene_root_node, gltf_state_save)
# The file extension in the output `path` (`.gltf` or `.glb`) determines
# whether the output uses text or binary format.
# `GLTFDocument.generate_buffer()` is also available for saving to memory.
gltf_document_save.write_to_filesystem(gltf_state_save, path)

// Load an existing glTF scene.
// GLTFState is used by GLTFDocument to store the loaded scene's state.
// GLTFDocument is the class that handles actually loading glTF data into a Godot node tree,
// which means it supports glTF features such as lights and cameras.
var gltfDocumentLoad = new GltfDocument();
var gltfStateLoad = new GltfState();
var error = gltfDocumentLoad.AppendFromFile("/Path/To/File.gltf", gltfStateLoad);
if (error == Error.Ok)
{
    var gltfSceneRootNode = gltfDocumentLoad.GenerateScene(gltfStateLoad);
    AddChild(gltfSceneRootNode);
}
else
{
    GD.PrintErr($"Couldn't load glTF scene (error code: {error}).");
}

// Save a new glTF scene.
var gltfDocumentSave = new GltfDocument();
var gltfStateSave = new GltfState();
gltfDocumentSave.AppendFromScene(gltfSceneRootNode, gltfStateSave);
// The file extension in the output `path` (`.gltf` or `.glb`) determines
// whether the output uses text or binary format.
// `GltfDocument.GenerateBuffer()` is also available for saving to memory.
gltfDocumentSave.WriteToFilesystem(gltfStateSave, path);

Ghi chú

Khi tải một scene glTF, cần thiết lập một base path để các resource bên ngoài như texture có thể được tải đúng. Khi tải từ file, base path sẽ tự động được đặt thành thư mục chứa file. Khi tải từ buffer, base path này phải được đặt thủ công vì Godot không có cách nào suy ra đường dẫn này.

Để thiết lập base path, hãy đặt GLTFState.base_path trên instance GLTFState của bạn trước khi gọi GLTFDocument.append_from_buffer hoặc GLTFDocument.append_from_file.

Phông chữ

FontFile.load_dynamic_font hỗ trợ các định dạng file font sau: TTF, OTF, WOFF, WOFF2, PFB, PFM

Mặt khác, FontFile.load_bitmap_font hỗ trợ định dạng BMFont (.fnt hoặc .font).

Ngoài ra, bạn có thể tải bất kỳ font nào được cài trên hệ thống nhờ khả năng hỗ trợ Phông chữ hệ thống của Godot.

Ví dụ về việc tải một file font tự động theo phần mở rộng file, sau đó thêm nó làm theme override cho node class_Label:

var path = "/path/to/font.ttf"
var path_lower = path.to_lower()
var font_file = FontFile.new()
if (
        path_lower.ends_with(".ttf")
        or path_lower.ends_with(".otf")
        or path_lower.ends_with(".woff")
        or path_lower.ends_with(".woff2")
        or path_lower.ends_with(".pfb")
        or path_lower.ends_with(".pfm")
):
    font_file.load_dynamic_font(path)
elif path_lower.ends_with(".fnt") or path_lower.ends_with(".font"):
    font_file.load_bitmap_font(path)
else:
    push_error("Invalid font file format.")

if not font_file.data.is_empty():
    # If font was loaded successfully, add it as a theme override.
    $Label.add_theme_font_override("font", font_file)

string path = "/Path/To/Font.ttf";
var fontFile = new FontFile();

if (
    path.EndsWith(".ttf", StringComparison.OrdinalIgnoreCase)
    || path.EndsWith(".otf", StringComparison.OrdinalIgnoreCase)
    || path.EndsWith(".woff", StringComparison.OrdinalIgnoreCase)
    || path.EndsWith(".woff2", StringComparison.OrdinalIgnoreCase)
    || path.EndsWith(".pfb", StringComparison.OrdinalIgnoreCase)
    || path.EndsWith(".pfm", StringComparison.OrdinalIgnoreCase)
)
{
    fontFile.LoadDynamicFont(path);
}
else if (path.EndsWith(".fnt", StringComparison.OrdinalIgnoreCase) || path.EndsWith(".font", StringComparison.OrdinalIgnoreCase))
{
    fontFile.LoadBitmapFont(path);
}
else
{
    GD.PrintErr("Invalid font file format.");
}

if (!fontFile.Data.IsEmpty())
{
    // If font was loaded successfully, add it as a theme override.
    GetNode<Label>("Label").AddThemeFontOverride("font", fontFile);
}

File nén ZIP

Godot hỗ trợ đọc và ghi file nén ZIP bằng các lớp class_zipreader và class_zippacker. Tính năng này hỗ trợ mọi file ZIP, kể cả các file được tạo bởi chức năng "Export PCK/ZIP" của Godot (dù các file này sẽ chứa resource Godot đã được import thay vì các file gốc của dự án).

Ghi chú

Dùng ProjectSettings.load_resource_pack để tải các file PCK hoặc ZIP do Godot xuất làm gói dữ liệu bổ sung. Cách này được ưu tiên cho DLC, vì nó giúp việc tương tác với các gói dữ liệu bổ sung trở nên liền mạch (hệ thống file ảo).

Khả năng hỗ trợ file nén ZIP này có thể kết hợp với việc tải hình ảnh, scene 3D và âm thanh lúc runtime để mang lại trải nghiệm modding liền mạch mà không yêu cầu người dùng phải dùng trình chỉnh sửa Godot để tạo file PCK/ZIP.

Ví dụ liệt kê các file trong một file nén ZIP vào node class_ItemList, sau đó ghi nội dung đọc được vào một file nén ZIP mới (về cơ bản là nhân bản file nén):

# Load an existing ZIP archive.
var zip_reader = ZIPReader.new()
zip_reader.open(path)
var files = zip_reader.get_files()
# The list of files isn't sorted by default. Sort it for more consistent processing.
files.sort()
for file in files:
    $ItemList.add_item(file, null)
    # Make folders disabled in the list.
    $ItemList.set_item_disabled(-1, file.ends_with("/"))

# Save a new ZIP archive.
var zip_packer = ZIPPacker.new()
var error = zip_packer.open(path)
if error != OK:
    push_error("Couldn't open path for saving ZIP archive (error code: %s)." % error_string(error))
    return

# Reuse the above ZIPReader instance to read files from an existing ZIP archive.
for file in zip_reader.get_files():
    zip_packer.start_file(file)
    zip_packer.write_file(zip_reader.read_file(file))
    zip_packer.close_file()

zip_packer.close()

// Load an existing ZIP archive.
var zipReader = new ZipReader();
zipReader.Open(path);
string[] files = zipReader.GetFiles();
// The list of files isn't sorted by default. Sort it for more consistent processing.
Array.Sort(files);
foreach (string file in files)
{
    GetNode<ItemList>("ItemList").AddItem(file);
    // Make folders disabled in the list.
    GetNode<ItemList>("ItemList").SetItemDisabled(-1, file.EndsWith('/'));
}

// Save a new ZIP archive.
var zipPacker = new ZipPacker();
var error = zipPacker.Open(path);
if (error != Error.Ok)
{
    GD.PrintErr($"Couldn't open path for saving ZIP archive (error code: {error}).");
    return;
}

// Reuse the above ZIPReader instance to read files from an existing ZIP archive.
foreach (string file in zipReader.GetFiles())
{
    zipPacker.StartFile(file);
    zipPacker.WriteFile(zipReader.ReadFile(file));
    zipPacker.CloseFile();
}

zipPacker.Close();
