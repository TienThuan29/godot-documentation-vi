Tùy chỉnh con trỏ chuột

Bạn có thể muốn thay đổi giao diện con trỏ chuột trong game cho phù hợp với thiết kế tổng thể. Có hai cách để tùy chỉnh con trỏ chuột:

  1. Dùng cài đặt dự án. Cách này đơn giản hơn nhưng hạn chế hơn.

  2. Dùng script. Cách này tùy biến được nhiều hơn nhưng cần viết script.

Ghi chú

Bạn có thể hiển thị con trỏ chuột "phần mềm" bằng cách ẩn con trỏ chuột và di chuyển một Sprite2D tới vị trí con trỏ trong phương thức _process(), nhưng việc này sẽ thêm ít nhất một frame độ trễ so với con trỏ chuột "phần cứng". Vì vậy, bạn nên dùng cách được mô tả ở đây bất cứ khi nào có thể.

Nếu bạn buộc phải dùng cách "phần mềm", hãy cân nhắc thêm bước ngoại suy để hiển thị đúng hơn đầu vào chuột thực tế.

Dùng cài đặt dự án

Mở Project Settings và vào Display > Mouse Cursor. Bạn sẽ thấy các cài đặt Custom Image, Custom Image Hotspot và Tooltip Position Offset.

Custom Image là hình ảnh bạn muốn đặt làm con trỏ chuột. Custom Hotspot là điểm trong hình ảnh mà bạn muốn dùng làm điểm nhận diện của con trỏ.

Cảnh báo

Hình ảnh tùy chỉnh phải có kích thước tối đa 256×256 pixel. Để tránh lỗi kết xuất, nên dùng kích thước 128×128 hoặc nhỏ hơn.

Trên nền tảng web, kích thước hình ảnh con trỏ tối đa cho phép là 128×128.

Dùng script

Tạo một Node và gắn script sau.

extends Node


# Load the custom images for the mouse cursor.
var arrow = load("res://arrow.png")
var beam = load("res://beam.png")


func _ready():
    # Changes only the arrow shape of the cursor.
    # This is similar to changing it in the project settings.
    Input.set_custom_mouse_cursor(arrow)

    # Changes a specific shape of the cursor (here, the I-beam shape).
    Input.set_custom_mouse_cursor(beam, Input.CURSOR_IBEAM)

using Godot;

public partial class MyNode : Node
{
    public override void _Ready()
    {
        // Load the custom images for the mouse cursor.
        var arrow = ResourceLoader.Load("res://arrow.png");
        var beam = ResourceLoader.Load("res://beam.png");

        // Changes only the arrow shape of the cursor.
        // This is similar to changing it in the project settings.
        Input.SetCustomMouseCursor(arrow);

        // Changes a specific shape of the cursor (here, the I-beam shape).
        Input.SetCustomMouseCursor(beam, Input.CursorShape.Ibeam);
    }
}

Xem thêm

Xem tài liệu của Input.set_custom_mouse_cursor() để biết thêm thông tin về cách dùng và các lưu ý riêng cho từng nền tảng.

Danh sách con trỏ

Có nhiều con trỏ chuột bạn có thể định nghĩa, được mô tả trong enum Input.CursorShape. Bạn muốn dùng con trỏ nào tùy thuộc vào trường hợp sử dụng của bạn.
