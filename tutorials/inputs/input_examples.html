Ví dụ về đầu vào

Giới thiệu

Trong bài hướng dẫn này, bạn sẽ học cách dùng hệ thống InputEvent của Godot để bắt đầu vào của người chơi. Có nhiều loại đầu vào khác nhau mà game của bạn có thể dùng - bàn phím, gamepad, chuột, v.v. - và nhiều cách khác nhau để biến các đầu vào đó thành hành động trong game. Tài liệu này sẽ trình bày một số tình huống phổ biến nhất, bạn có thể dùng chúng làm điểm khởi đầu cho các dự án của mình.

Ghi chú

Để có cái nhìn tổng quan chi tiết về cách hoạt động của hệ thống sự kiện input trong Godot, xem Sử dụng InputEvent.

Sự kiện và polling

Đôi khi bạn muốn game phản hồi một sự kiện input nhất định - ví dụ như nhấn nút "nhảy". Trong các tình huống khác, bạn có thể muốn điều gì đó xảy ra chừng nào một phím còn được nhấn, chẳng hạn như di chuyển. Trong trường hợp đầu, bạn có thể dùng hàm _input(), hàm này sẽ được gọi mỗi khi có sự kiện input xảy ra. Trong trường hợp thứ hai, Godot cung cấp singleton Input, bạn có thể dùng nó để truy vấn trạng thái của một đầu vào.

Ví dụ:

func _input(event):
    if event.is_action_pressed("jump"):
        jump()


func _physics_process(delta):
    if Input.is_action_pressed("move_right"):
        # Move as long as the key/button is pressed.
        position.x += speed * delta

public override void _Input(InputEvent @event)
{
    if (@event.IsActionPressed("jump"))
    {
        Jump();
    }
}

public override void _PhysicsProcess(double delta)
{
    if (Input.IsActionPressed("move_right"))
    {
        // Move as long as the key/button is pressed.
        position.X += speed * (float)delta;
    }
}

Điều này cho bạn sự linh hoạt để kết hợp các kiểu xử lý đầu vào.

Trong phần còn lại của bài hướng dẫn, chúng ta sẽ tập trung vào việc bắt các sự kiện riêng lẻ trong _input().

Sự kiện input

Sự kiện input là các đối tượng kế thừa từ InputEvent. Tùy theo loại sự kiện, đối tượng sẽ chứa các thuộc tính cụ thể liên quan đến sự kiện đó. Để xem các sự kiện thực sự trông như thế nào, hãy thêm một Node và gắn script sau:

extends Node


func _input(event):
    print(event.as_text())

using Godot;

public partial class Node : Godot.Node
{
    public override void _Input(InputEvent @event)
    {
        GD.Print(@event.AsText());
    }
}

Khi bạn nhấn phím, di chuyển chuột và thực hiện các thao tác đầu vào khác, bạn sẽ thấy từng sự kiện lần lượt hiện ra trong cửa sổ output. Đây là ví dụ về output:

A
Mouse motion at position ((971, 5)) with velocity ((0, 0))
Right Mouse Button
Mouse motion at position ((870, 243)) with velocity ((0.454937, -0.454937))
Left Mouse Button
Mouse Wheel Up
A
B
Shift
Alt+Shift
Alt
Shift+T
Mouse motion at position ((868, 242)) with velocity ((-2.134768, 2.134768))

Như bạn thấy, kết quả rất khác nhau đối với các loại đầu vào khác nhau. Sự kiện phím thậm chí còn được in ra dưới dạng ký hiệu phím. Ví dụ, hãy xét InputEventMouseButton. Nó kế thừa từ các lớp sau:

  • InputEvent - lớp cơ sở cho mọi sự kiện input

  • InputEventWithModifiers - thêm khả năng kiểm tra các phím bổ trợ có được nhấn hay không, như Shift hoặc Alt.

  • InputEventMouse - thêm các thuộc tính sự kiện chuột, như position

  • InputEventMouseButton - chứa chỉ số của nút được nhấn, có phải nhấp đúp hay không, v.v.

Mẹo

Bạn nên mở sẵn class reference khi làm việc với sự kiện để có thể kiểm tra các thuộc tính và phương thức có sẵn của loại sự kiện.

Bạn có thể gặp lỗi nếu cố truy cập một thuộc tính trên loại đầu vào không chứa thuộc tính đó - ví dụ gọi position trên InputEventKey. Để tránh điều này, hãy kiểm tra loại sự kiện trước:

func _input(event):
    if event is InputEventMouseButton:
        print("mouse button event at ", event.position)

public override void _Input(InputEvent @event)
{
    if (@event is InputEventMouseButton mouseEvent)
    {
        GD.Print("mouse button event at ", mouseEvent.Position);
    }
}

InputMap

InputMap là cách linh hoạt nhất để xử lý nhiều loại đầu vào. Bạn dùng nó bằng cách tạo các action input có tên, mỗi action có thể được gán bất kỳ số lượng sự kiện input nào, như nhấn phím hoặc nhấp chuột. Để xem chúng và thêm action của riêng bạn, hãy mở Project -> Project Settings và chọn tab InputMap:

Mẹo

Một dự án Godot mới đã có sẵn một số action mặc định được định nghĩa. Để xem chúng, hãy bật Show Built-in Actions trong hộp thoại InputMap.

Dù không bắt buộc, bạn nên dùng quy ước đặt tên snake_case cho tên input action.

Bắt các action

Sau khi đã định nghĩa các action, bạn có thể xử lý chúng trong script bằng is_action_pressed() và is_action_released() bằng cách truyền vào tên action bạn cần:

func _input(event):
    if event.is_action_pressed("my_action"):
        print("my_action occurred!")

public override void _Input(InputEvent @event)
{
    if (@event.IsActionPressed("my_action"))
    {
        GD.Print("my_action occurred!");
    }
}

Sự kiện bàn phím

Sự kiện bàn phím được bắt trong InputEventKey. Dù nên dùng input action, có thể có những trường hợp bạn muốn xem xét cụ thể các sự kiện phím. Trong ví dụ này, hãy kiểm tra phím T:

func _input(event):
    if event is InputEventKey and event.pressed:
        if event.keycode == KEY_T:
            print("T was pressed")

public override void _Input(InputEvent @event)
{
    if (@event is InputEventKey keyEvent && keyEvent.Pressed)
    {
        if (keyEvent.Keycode == Key.T)
        {
            GD.Print("T was pressed");
        }
    }
}

Mẹo

Xem @GlobalScope_Key để biết danh sách các hằng số mã phím.

Cảnh báo

Do hiện tượng keyboard ghosting, không phải mọi phím đều được ghi nhận tại một thời điểm nếu bạn nhấn quá nhiều phím cùng lúc. Do vị trí trên bàn phím, một số phím dễ bị ghosting hơn những phím khác. Một số bàn phím có tính năng chống ghosting ở mức phần cứng, nhưng tính năng này thường không có trên bàn phím giá rẻ và bàn phím laptop.

Do đó, bạn nên dùng bố cục phím mặc định được thiết kế để hoạt động tốt trên bàn phím không có chống ghosting. Xem câu hỏi này trên Gamedev Stack Exchange để biết thêm thông tin.

Phím bổ trợ

Các thuộc tính phím bổ trợ được kế thừa từ InputEventWithModifiers. Điều này cho phép bạn kiểm tra các tổ hợp phím bổ trợ bằng thuộc tính boolean. Giả sử bạn muốn một việc xảy ra khi nhấn T, nhưng một việc khác khi nhấn Shift + T:

func _input(event):
    if event is InputEventKey and event.pressed:
        if event.keycode == KEY_T:
            if event.shift_pressed:
                print("Shift+T was pressed")
            else:
                print("T was pressed")

public override void _Input(InputEvent @event)
{
    if (@event is InputEventKey keyEvent && keyEvent.Pressed)
    {
        switch (keyEvent.Keycode)
        {
            case Key.T:
                GD.Print(keyEvent.ShiftPressed ? "Shift+T was pressed" : "T was pressed");
                break;
        }
    }
}

Mẹo

Xem @GlobalScope_Key để biết danh sách các hằng số mã phím.

Sự kiện chuột

Sự kiện chuột bắt nguồn từ lớp InputEventMouse và được chia thành hai loại: InputEventMouseButton và InputEventMouseMotion. Lưu ý rằng điều này có nghĩa là mọi sự kiện chuột đều chứa thuộc tính position.

Nút chuột

Bắt nút chuột rất giống với xử lý sự kiện phím. @GlobalScope_MouseButton chứa danh sách các hằng số MOUSE_BUTTON_* cho từng nút có thể có, giá trị này sẽ được báo trong thuộc tính button_index của sự kiện. Lưu ý rằng con lăn chuột cũng được tính là một nút - chính xác là hai nút, với MOUSE_BUTTON_WHEEL_UP và MOUSE_BUTTON_WHEEL_DOWN là các sự kiện riêng biệt.

func _input(event):
    if event is InputEventMouseButton:
        if event.button_index == MOUSE_BUTTON_LEFT and event.pressed:
            print("Left button was clicked at ", event.position)
        if event.button_index == MOUSE_BUTTON_WHEEL_UP and event.pressed:
            print("Wheel up")

public override void _Input(InputEvent @event)
{
    if (@event is InputEventMouseButton mouseEvent && mouseEvent.Pressed)
    {
        switch (mouseEvent.ButtonIndex)
        {
            case MouseButton.Left:
                GD.Print($"Left button was clicked at {mouseEvent.Position}");
                break;
            case MouseButton.WheelUp:
                GD.Print("Wheel up");
                break;
        }
    }
}

Chuyển động chuột

Sự kiện InputEventMouseMotion xảy ra mỗi khi chuột di chuyển. Bạn có thể tìm khoảng cách di chuyển bằng thuộc tính relative.

Đây là ví dụ dùng sự kiện chuột để kéo thả một node Sprite2D:

extends Node


var dragging = false
var click_radius = 32 # Size of the sprite.


func _input(event):
    if event is InputEventMouseButton and event.button_index == MOUSE_BUTTON_LEFT:
        if (event.position - $Sprite2D.position).length() < click_radius:
            # Start dragging if the click is on the sprite.
            if not dragging and event.pressed:
                dragging = true
        # Stop dragging if the button is released.
        if dragging and not event.pressed:
            dragging = false

    if event is InputEventMouseMotion and dragging:
        # While dragging, move the sprite with the mouse.
        $Sprite2D.position = event.position

using Godot;

public partial class MyNode2D : Node2D
{
    private bool _dragging = false;
    private int _clickRadius = 32; // Size of the sprite.

    public override void _Input(InputEvent @event)
    {
        Sprite2D sprite = GetNodeOrNull<Sprite2D>("Sprite2D");
        if (sprite == null)
        {
            return; // No suitable node was found.
        }

        if (@event is InputEventMouseButton mouseEvent && mouseEvent.ButtonIndex == MouseButton.Left)
        {
            if ((mouseEvent.Position - sprite.Position).Length() < _clickRadius)
            {
                // Start dragging if the click is on the sprite.
                if (!_dragging && mouseEvent.Pressed)
                {
                    _dragging = true;
                }
            }
            // Stop dragging if the button is released.
            if (_dragging && !mouseEvent.Pressed)
            {
                _dragging = false;
            }
        }
        else
        {
            if (@event is InputEventMouseMotion motionEvent && _dragging)
            {
                // While dragging, move the sprite with the mouse.
                sprite.Position = motionEvent.Position;
            }
        }
    }
}

Sự kiện chạm

Nếu bạn đang dùng thiết bị màn hình cảm ứng, bạn có thể tạo sự kiện chạm. InputEventScreenTouch tương đương với sự kiện nhấp chuột, còn InputEventScreenDrag hoạt động gần giống chuyển động chuột.

Mẹo

Để kiểm tra sự kiện chạm trên thiết bị không có màn hình cảm ứng, hãy mở Project Settings và vào mục "Input Devices/Pointing". Bật "Emulate Touch From Mouse" và dự án của bạn sẽ hiểu các thao tác nhấp và di chuyển chuột là sự kiện chạm.
