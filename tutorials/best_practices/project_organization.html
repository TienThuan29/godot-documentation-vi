Tổ chức dự án

Giới thiệu

Vì Godot không có giới hạn nào về cấu trúc dự án hay cách dùng hệ thống file, việc tổ chức file khi mới học engine có thể trông khá khó khăn. Bài hướng dẫn này đề xuất một quy trình làm việc là điểm khởi đầu tốt. Chúng ta cũng sẽ đề cập đến việc dùng quản lý phiên bản (version control) với Godot.

Tổ chức

Về bản chất, Godot dựa trên scene và dùng hệ thống file như vốn có, không có metadata hay cơ sở dữ liệu asset.

Khác với các engine khác, nhiều resource được chứa ngay bên trong scene, nên số lượng file trong hệ thống file ít hơn đáng kể.

Xét điều đó, cách tiếp cận phổ biến nhất là nhóm asset càng gần scene càng tốt; khi dự án lớn dần, điều này giúp dự án dễ bảo trì hơn.

Ví dụ, thường thì bạn có thể đặt các asset cơ bản vào một thư mục duy nhất, chẳng hạn ảnh sprite, mesh của mô hình 3D, material, âm nhạc, v.v. Sau đó có thể dùng một thư mục riêng để chứa các màn chơi đã dựng sử dụng chúng.

/project.godot
/docs/.gdignore  # See "Ignoring specific folders" below
/docs/learning.html
/models/town/house/house.dae
/models/town/house/window.png
/models/town/house/door.png
/characters/player/cubio.dae
/characters/player/cubio.png
/characters/enemies/goblin/goblin.dae
/characters/enemies/goblin/goblin.png
/characters/npcs/suzanne/suzanne.dae
/characters/npcs/suzanne/suzanne.png
/levels/riverdale/riverdale.scn

Hướng dẫn phong cách

Để nhất quán giữa các dự án, chúng tôi khuyên bạn tuân theo các hướng dẫn sau:

  • Dùng snake_case cho tên thư mục và tên file (ngoại trừ script C#). Cách này tránh được các vấn đề phân biệt chữ hoa/thường có thể phát sinh sau khi xuất (export) dự án trên Windows. Script C# là ngoại lệ của quy tắc này, vì quy ước là đặt tên theo tên lớp, vốn nên viết theo PascalCase.

  • Dùng PascalCase cho tên node, vì cách này khớp với cách viết hoa của các node có sẵn.

  • Nhìn chung, hãy giữ các resource của bên thứ ba trong một thư mục addons/ ở cấp cao nhất, kể cả khi chúng không phải plugin cho trình chỉnh sửa. Điều này giúp dễ theo dõi file nào là của bên thứ ba hơn. Có một số ngoại lệ cho quy tắc này; ví dụ, nếu bạn dùng asset game của bên thứ ba cho một nhân vật, thì hợp lý hơn là đặt chúng chung thư mục với các scene và script của nhân vật đó.

Import

Các phiên bản Godot trước 3.0 thực hiện quá trình import từ các file nằm ngoài dự án. Dù điều này có thể hữu ích trong các dự án lớn, nó lại gây phiền phức trong việc tổ chức cho hầu hết lập trình viên.

Vì vậy, giờ đây asset được import một cách trong suốt từ bên trong thư mục dự án. Xem Quy trình import để biết thêm chi tiết về cách import hoạt động trong Godot.

Bỏ qua các thư mục cụ thể

Để ngăn Godot import các file trong một thư mục cụ thể, hãy tạo một file rỗng tên .gdignore trong thư mục đó (dấu . ở đầu là bắt buộc). Điều này có thể hữu ích để tăng tốc lần import dự án đầu tiên.

Ghi chú

Để tạo file có tên bắt đầu bằng dấu chấm trên Windows, hãy đặt dấu chấm ở cả đầu và cuối tên file (.gdignore.). Windows sẽ tự động xóa dấu chấm ở cuối khi bạn xác nhận tên.

Ngoài ra, bạn có thể dùng một trình soạn thảo văn bản như Notepad++ hoặc dùng lệnh sau trong command prompt: type nul > .gdignore

Khi thư mục đã bị bỏ qua, các resource trong thư mục đó sẽ không thể nạp được nữa bằng các phương thức load() và preload(). Bỏ qua một thư mục cũng sẽ tự động ẩn nó khỏi FileSystem dock, điều này có thể hữu ích để giảm sự lộn xộn.

Lưu ý rằng nội dung của file .gdignore bị bỏ qua, đó là lý do file nên để rỗng. Nó không hỗ trợ các mẫu (pattern) như file .gitignore.

Phân biệt chữ hoa/thường

Windows và các phiên bản macOS gần đây mặc định dùng hệ thống file không phân biệt chữ hoa/thường, trong khi các bản phân phối Linux mặc định dùng hệ thống file có phân biệt chữ hoa/thường. Điều này có thể gây ra vấn đề sau khi xuất dự án, vì hệ thống file ảo PCK của Godot có phân biệt chữ hoa/thường. Để tránh điều này, bạn nên dùng cách đặt tên snake_case cho mọi file trong dự án (và nói chung là dùng chữ thường).

Ghi chú

Bạn có thể phá vỡ quy tắc này khi hướng dẫn phong cách quy định khác (chẳng hạn hướng dẫn phong cách C#). Dù vậy, hãy nhất quán để tránh sai sót.

Trên Windows 10, để tránh thêm các sai sót liên quan đến phân biệt chữ hoa/thường, bạn cũng có thể đặt thư mục dự án ở chế độ phân biệt chữ hoa/thường. Sau khi bật tính năng Windows Subsystem for Linux, hãy chạy lệnh sau trong cửa sổ PowerShell:

# To enable case-sensitivity:
fsutil file setcasesensitiveinfo <path to project folder> enable

# To disable case-sensitivity:
fsutil file setcasesensitiveinfo <path to project folder> disable

Nếu bạn chưa bật Windows Subsystem for Linux, bạn có thể nhập dòng sau trong cửa sổ PowerShell chạy với quyền Administrator rồi khởi động lại khi được yêu cầu:

Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux
