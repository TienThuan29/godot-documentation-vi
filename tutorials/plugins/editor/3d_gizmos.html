Plugin gizmo 3D

Giới thiệu

Plugin gizmo 3D được trình chỉnh sửa và các plugin tùy chỉnh sử dụng để định nghĩa các gizmo gắn với bất kỳ loại node Node3D nào.

Bài hướng dẫn này trình bày hai cách chính để định nghĩa gizmo tùy chỉnh của riêng bạn. Cách thứ nhất phù hợp với các gizmo đơn giản và giúp cấu trúc plugin gọn gàng hơn, còn cách thứ hai cho phép bạn lưu trữ một số dữ liệu riêng cho từng gizmo.

Ghi chú

Bài hướng dẫn này giả định rằng bạn đã biết cách tạo plugin thông thường. Nếu chưa chắc, hãy tham khảo trang Tạo plugin.

EditorNode3DGizmoPlugin

Bất kể chọn cách nào, chúng ta đều cần tạo một EditorNode3DGizmoPlugin mới. Việc này cho phép chúng ta đặt tên cho loại gizmo mới và định nghĩa các hành vi khác, chẳng hạn gizmo có thể bị ẩn hay không.

Đây là một thiết lập cơ bản:

# my_custom_gizmo_plugin.gd
extends EditorNode3DGizmoPlugin


func _get_gizmo_name():
    return "CustomNode"

# MyCustomEditorPlugin.gd
@tool
extends EditorPlugin


const MyCustomGizmoPlugin = preload("res://addons/my-addon/my_custom_gizmo_plugin.gd")

var gizmo_plugin = MyCustomGizmoPlugin.new()


func _enter_tree():
    add_node_3d_gizmo_plugin(gizmo_plugin)


func _exit_tree():
    remove_node_3d_gizmo_plugin(gizmo_plugin)

Với các gizmo đơn giản, chỉ cần kế thừa EditorNode3DGizmoPlugin là đủ. Nếu bạn muốn lưu trữ một số dữ liệu riêng cho từng gizmo, bạn nên chọn cách thứ hai.

Cách đơn giản

Bước đầu tiên là, trong plugin gizmo tùy chỉnh của chúng ta, ghi đè phương thức _has_gizmo() để nó trả về true khi tham số node thuộc kiểu mà chúng ta nhắm tới.

# ...


func _has_gizmo(node):
    return node is MyCustomNode3D


# ...

Sau đó, chúng ta có thể ghi đè các phương thức như _redraw() hoặc tất cả các phương thức liên quan đến handle.

# ...


func _init():
    create_material("main", Color(1, 0, 0))
    create_handle_material("handles")


func _redraw(gizmo):
    gizmo.clear()

    var node3d = gizmo.get_node_3d()

    var lines = PackedVector3Array()

    lines.push_back(Vector3(0, 1, 0))
    lines.push_back(Vector3(0, node3d.my_custom_value, 0))

    var handles = PackedVector3Array()

    handles.push_back(Vector3(0, 1, 0))
    handles.push_back(Vector3(0, node3d.my_custom_value, 0))

    gizmo.add_lines(lines, get_material("main", gizmo), false)
    gizmo.add_handles(handles, get_material("handles", gizmo), [])


# ...

Lưu ý rằng chúng ta đã tạo một material trong phương thức _init, và lấy nó trong phương thức _redraw bằng get_material(). Phương thức này lấy một trong các biến thể của material tùy theo trạng thái của gizmo (được chọn và/hoặc có thể chỉnh sửa).

Vậy plugin hoàn chỉnh sẽ trông đại khái như sau:

extends EditorNode3DGizmoPlugin


const MyCustomNode3D = preload("res://addons/my-addon/my_custom_node_3d.gd")


func _init():
    create_material("main", Color(1,0,0))
    create_handle_material("handles")


func _has_gizmo(node):
    return node is MyCustomNode3D


func _redraw(gizmo):
    gizmo.clear()

    var node3d = gizmo.get_node_3d()

    var lines = PackedVector3Array()

    lines.push_back(Vector3(0, 1, 0))
    lines.push_back(Vector3(0, node3d.my_custom_value, 0))

    var handles = PackedVector3Array()

    handles.push_back(Vector3(0, 1, 0))
    handles.push_back(Vector3(0, node3d.my_custom_value, 0))

    gizmo.add_lines(lines, get_material("main", gizmo), false)
    gizmo.add_handles(handles, get_material("handles", gizmo), [])


# You should implement the rest of handle-related callbacks
# (_get_handle_name(), _get_handle_value(), _commit_handle(), ...).

Lưu ý rằng chúng ta mới chỉ thêm một vài handle trong phương thức _redraw, nhưng vẫn cần hiện thực các callback còn lại liên quan đến handle trong EditorNode3DGizmoPlugin để các handle hoạt động đúng.

Cách thay thế

Trong một số trường hợp, chúng ta muốn cung cấp bản hiện thực riêng của EditorNode3DGizmo, có thể vì muốn lưu một số trạng thái trong từng gizmo, hoặc vì đang chuyển đổi một plugin gizmo cũ và không muốn phải viết lại.

Trong những trường hợp này, tất cả những gì cần làm là, trong plugin gizmo mới, ghi đè _create_gizmo() để nó trả về bản hiện thực gizmo tùy chỉnh của chúng ta cho các node Node3D mà chúng ta nhắm tới.

# my_custom_gizmo_plugin.gd
extends EditorNode3DGizmoPlugin


const MyCustomNode3D = preload("res://addons/my-addon/my_custom_node_3d.gd")
const MyCustomGizmo = preload("res://addons/my-addon/my_custom_gizmo.gd")


func _init():
    create_material("main", Color(1, 0, 0))
    create_handle_material("handles")


func _create_gizmo(node):
    if node is MyCustomNode3D:
        return MyCustomGizmo.new()
    else:
        return null

Bằng cách này, toàn bộ logic của gizmo và các phương thức vẽ có thể được hiện thực trong một lớp mới kế thừa EditorNode3DGizmo, như sau:

# my_custom_gizmo.gd
extends EditorNode3DGizmo


# You can store data in the gizmo itself (more useful when working with handles).
var gizmo_size = 3.0


func _redraw():
    clear()

    var node3d = get_node_3d()

    var lines = PackedVector3Array()

    lines.push_back(Vector3(0, 1, 0))
    lines.push_back(Vector3(gizmo_size, node3d.my_custom_value, 0))

    var handles = PackedVector3Array()

    handles.push_back(Vector3(0, 1, 0))
    handles.push_back(Vector3(gizmo_size, node3d.my_custom_value, 0))

    var material = get_plugin().get_material("main", self)
    add_lines(lines, material, false)

    var handles_material = get_plugin().get_material("handles", self)
    add_handles(handles, handles_material, [])


# You should implement the rest of handle-related callbacks
# (_get_handle_name(), _get_handle_value(), _commit_handle(), ...).

Lưu ý rằng chúng ta mới chỉ thêm một vài handle trong phương thức _redraw, nhưng vẫn cần hiện thực các callback còn lại liên quan đến handle trong EditorNode3DGizmo để các handle hoạt động đúng.
