Cài đặt plugin

Godot có hệ thống plugin cho trình chỉnh sửa với rất nhiều plugin do cộng đồng phát triển. Plugin có thể mở rộng chức năng của trình chỉnh sửa với node mới, dock bổ sung, các tính năng tiện lợi, và nhiều hơn nữa.

Tìm plugin

Cách được khuyến nghị để tìm plugin Godot là dùng Asset Library. Dù có thể duyệt trực tuyến, việc dùng nó trực tiếp từ trình chỉnh sửa sẽ tiện hơn. Để làm vậy, hãy nhấn tab AssetLib ở phía trên trình chỉnh sửa:

Bạn cũng có thể tìm asset trên các trang lưu trữ mã nguồn như GitHub.

Ghi chú

Một số repository tự mô tả là "plugin" nhưng thực ra có thể không phải là plugin trình chỉnh sửa. Điều này đặc biệt đúng với các script được dùng trong dự án đang chạy. Bạn không cần bật những plugin như vậy để dùng chúng. Chỉ cần tải về và giải nén các tệp vào thư mục dự án.

Một cách để phân biệt plugin trình chỉnh sửa với các plugin khác là tìm tệp plugin.cfg trong repository chứa plugin. Nếu repository chứa tệp plugin.cfg trong một thư mục nằm trong thư mục addons/, thì đó là plugin trình chỉnh sửa.

Cài đặt một plugin

Để cài đặt plugin, hãy tải nó về dưới dạng tệp nén ZIP. Trên Asset Library, có thể làm việc này bằng nút Download, từ trình chỉnh sửa hoặc qua giao diện Web.

Trên GitHub, nếu plugin có khai báo tag (phiên bản), hãy vào tab Releases để tải bản phát hành ổn định. Điều này đảm bảo bạn tải về phiên bản đã được tác giả công bố là ổn định.

Trên GitHub, nếu plugin không khai báo tag nào, hãy dùng nút Download ZIP để tải về tệp ZIP của bản sửa đổi mới nhất:

Giải nén tệp ZIP và di chuyển thư mục addons/ bên trong vào thư mục dự án của bạn. Nếu dự án đã có sẵn thư mục addons/, hãy di chuyển thư mục addons/ của plugin vào thư mục dự án để gộp nội dung thư mục mới với thư mục hiện có. Trình quản lý tệp có thể hỏi bạn có muốn ghi vào thư mục không; hãy trả lời Yes. Sẽ không có tệp nào bị ghi đè trong quá trình này.

Bật plugin

Để bật plugin vừa cài đặt, hãy mở Project > Project Settings ở phía trên trình chỉnh sửa rồi vào tab Plugins. Nếu plugin được đóng gói đúng, bạn sẽ thấy nó trong danh sách plugin. Nhấn vào ô Enable để bật plugin.

Bạn có thể dùng plugin ngay sau khi bật; không cần khởi động lại trình chỉnh sửa. Tương tự, có thể tắt plugin mà không cần khởi động lại trình chỉnh sửa.
