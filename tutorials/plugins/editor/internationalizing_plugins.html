Quốc tế hóa plugin

Tương tự như cách Quốc tế hóa game hoạt động, bạn có thể tạo bản dịch cho plugin trình chỉnh sửa. Mọi điều áp dụng cho game cũng áp dụng cho plugin, nhưng quy trình bật bản dịch cho plugin hơi khác một chút.

Sau khi tạo tệp CSV hoặc POT và tạo bản dịch, bạn không thể chỉ đơn giản tải bản dịch trong cài đặt dự án; thay vào đó, bạn phải thông qua class_TranslationServer để thêm một class_TranslationDomain mới.

func _enter_tree():
    var domain = TranslationServer.get_or_add_domain("addons/my_plugin")
    var dir = "res://addons/my_plugin/locale"
    for file in DirAccess.get_files_at(dir):
        var translation = ResourceLoader.load(dir.path_join(file)) as Translation
        if translation:
            domain.add_translation(translation)

    # Existing plugin initialization...

Đoạn mã trên sẽ tải tất cả các bản dịch có sẵn cho plugin của bạn, với giả định các bản dịch nằm trong thư mục addons/my_plugin/locale. Bạn cũng nên chọn một tên translation domain duy nhất để tránh xung đột với các domain khác; dùng đường dẫn của plugin làm tên domain sẽ đảm bảo điều này.

Nếu xét dock trong Dock tùy chỉnh, giờ bạn cần yêu cầu dock dùng translation domain này:

dock.set_translation_domain("addons/my_plugin")

Việc cuối cùng cần làm là gỡ bỏ translation domain khi plugin bị vô hiệu hóa:

func _exit_tree():
    # Existing plugin cleanup...
    TranslationServer.remove_domain("addons/my_plugin")

Sau khi hoàn tất tất cả những việc này, bạn có thể đổi ngôn ngữ của trình chỉnh sửa để kiểm tra bản dịch.

Ghi chú

Bạn sẽ cần tắt rồi bật lại plugin một lần, vì nó cần gọi _enter_tree() để tải bản dịch.
