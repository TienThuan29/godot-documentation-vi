Tạo plugin màn hình chính

Nội dung của bài hướng dẫn này

Plugin màn hình chính cho phép bạn tạo giao diện mới ở phần trung tâm của trình chỉnh sửa, xuất hiện bên cạnh các nút "2D", "3D", "Script", "Game" và "AssetLib". Những plugin trình chỉnh sửa như vậy được gọi là "Main screen plugins" (plugin màn hình chính).

Bài hướng dẫn này dẫn dắt bạn tạo một plugin màn hình chính cơ bản. Để đơn giản, plugin màn hình chính của chúng ta sẽ chỉ chứa một nút in văn bản ra console.

Khởi tạo plugin

Trước tiên, hãy tạo một plugin mới từ menu Plugins. Trong bài hướng dẫn này, chúng ta sẽ đặt nó trong thư mục tên main_screen, nhưng bạn có thể dùng bất kỳ tên nào bạn muốn.

Script của plugin sẽ có sẵn các phương thức _enter_tree() và _exit_tree(), nhưng với plugin màn hình chính, chúng ta cần thêm vài phương thức nữa. Hãy thêm bốn phương thức để script trông như sau:

@tool
extends EditorPlugin


func _enter_tree():
    pass


func _exit_tree():
    pass


func _has_main_screen():
    return true


func _make_visible(visible):
    pass


func _get_plugin_name():
    return "Main Screen Plugin"


func _get_plugin_icon():
    return EditorInterface.get_editor_theme().get_icon("Node", "EditorIcons")

#if TOOLS
using Godot;

[Tool]
public partial class MainScreenPlugin : EditorPlugin
{
    public override void _EnterTree()
    {

    }

    public override void _ExitTree()
    {

    }

    public override bool _HasMainScreen()
    {
        return true;
    }

    public override void _MakeVisible(bool visible)
    {

    }

    public override string _GetPluginName()
    {
        return "Main Screen Plugin";
    }

    public override Texture2D _GetPluginIcon()
    {
        return EditorInterface.Singleton.GetEditorTheme().GetIcon("Node", "EditorIcons");
    }
}
#endif

Phần quan trọng trong script này là hàm _has_main_screen(), được ghi đè để trả về true. Hàm này được trình chỉnh sửa tự động gọi khi kích hoạt plugin, để cho trình chỉnh sửa biết plugin này thêm một khung nhìn trung tâm mới. Hiện tại, chúng ta sẽ để nguyên script này và quay lại sau.

Scene màn hình chính

Tạo một scene mới với node gốc kế thừa từ Control (trong plugin ví dụ này, chúng ta sẽ dùng CenterContainer làm node gốc). Chọn node gốc này, và trong viewport, nhấn menu Layout rồi chọn Full Rect. Bạn cũng cần bật cờ kích thước theo chiều dọc Expand trong inspector. Giờ panel sẽ sử dụng toàn bộ không gian có sẵn trong viewport chính.

Tiếp theo, hãy thêm một nút vào plugin màn hình chính ví dụ. Thêm một node Button và đặt văn bản thành "Print Hello" hoặc tương tự. Thêm script cho nút như sau:

@tool
extends Button


func _on_print_hello_pressed():
    print("Hello from the main screen plugin!")

using Godot;

[Tool]
public partial class PrintHello : Button
{
    private void OnPrintHelloPressed()
    {
        GD.Print("Hello from the main screen plugin!");
    }
}

Sau đó kết nối signal "pressed" với chính nó. Nếu bạn cần trợ giúp về signal, xem bài viết Sử dụng signal.

Vậy là xong panel màn hình chính. Lưu scene thành main_panel.tscn.

Cập nhật script của plugin

Chúng ta cần cập nhật script main_screen_plugin.gd để plugin tạo instance cho scene panel chính và đặt nó vào đúng vị trí. Đây là toàn bộ script của plugin:

@tool
extends EditorPlugin


const MainPanel = preload("res://addons/main_screen/main_panel.tscn")

var main_panel_instance


func _enter_tree():
    main_panel_instance = MainPanel.instantiate()
    # Add the main panel to the editor's main viewport.
    EditorInterface.get_editor_main_screen().add_child(main_panel_instance)
    # Hide the main panel. Very much required.
    _make_visible(false)


func _exit_tree():
    if main_panel_instance:
        main_panel_instance.queue_free()


func _has_main_screen():
    return true


func _make_visible(visible):
    if main_panel_instance:
        main_panel_instance.visible = visible


func _get_plugin_name():
    return "Main Screen Plugin"


func _get_plugin_icon():
    # Must return some kind of Texture for the icon.
    return EditorInterface.get_editor_theme().get_icon("Node", "EditorIcons")

#if TOOLS
using Godot;

[Tool]
public partial class MainScreenPlugin : EditorPlugin
{
    PackedScene MainPanel = ResourceLoader.Load<PackedScene>("res://addons/main_screen/main_panel.tscn");
    Control MainPanelInstance;

    public override void _EnterTree()
    {
        MainPanelInstance = (Control)MainPanel.Instantiate();
        // Add the main panel to the editor's main viewport.
        EditorInterface.Singleton.GetEditorMainScreen().AddChild(MainPanelInstance);
        // Hide the main panel. Very much required.
        _MakeVisible(false);
    }

    public override void _ExitTree()
    {
        if (MainPanelInstance != null)
        {
            MainPanelInstance.QueueFree();
        }
    }

    public override bool _HasMainScreen()
    {
        return true;
    }

    public override void _MakeVisible(bool visible)
    {
        if (MainPanelInstance != null)
        {
            MainPanelInstance.Visible = visible;
        }
    }

    public override string _GetPluginName()
    {
        return "Main Screen Plugin";
    }

    public override Texture2D _GetPluginIcon()
    {
        // Must return some kind of Texture for the icon.
        return EditorInterface.Singleton.GetEditorTheme().GetIcon("Node", "EditorIcons");
    }
}
#endif

Một vài dòng cụ thể đã được thêm vào. MainPanel là một hằng số giữ tham chiếu đến scene, và chúng ta tạo instance của nó vào main_panel_instance.

Hàm _enter_tree() được gọi trước _ready(). Đây là nơi chúng ta tạo instance cho scene panel chính và thêm chúng làm con của những phần cụ thể trong trình chỉnh sửa. Chúng ta dùng EditorInterface.get_editor_main_screen() để lấy màn hình chính của trình chỉnh sửa và thêm instance panel chính làm con của nó. Chúng ta gọi hàm _make_visible(false) để ẩn panel chính, tránh việc nó chiếm chỗ khi plugin vừa được kích hoạt.

Hàm _exit_tree() được gọi khi plugin bị vô hiệu hóa. Nếu màn hình chính vẫn còn tồn tại, chúng ta gọi queue_free() để giải phóng instance và xóa nó khỏi bộ nhớ.

Hàm _make_visible() được ghi đè để ẩn hoặc hiện panel chính khi cần. Hàm này được trình chỉnh sửa tự động gọi khi người dùng nhấn vào các nút viewport chính ở phía trên trình chỉnh sửa.

Các hàm _get_plugin_name() và _get_plugin_icon() kiểm soát tên và biểu tượng hiển thị trên nút viewport chính của plugin.

Một hàm khác bạn có thể thêm là _handles(), cho phép bạn xử lý một loại node, tự động chuyển sang màn hình chính khi loại node đó được chọn. Điều này tương tự như việc nhấn vào một node 3D sẽ tự động chuyển sang viewport 3D.

Biểu tượng màn hình chính

Bạn có thể dùng một trong các biểu tượng có sẵn của trình chỉnh sửa, hoặc cung cấp biểu tượng riêng cho plugin màn hình chính. Trong cả hai trường hợp, việc này được thực hiện bằng cách ghi đè phương thức _get_plugin_icon() trong script của plugin.

Để dùng biểu tượng có sẵn, hãy sao chép tên biểu tượng từ trang web Godot editor icons. Dùng tên đã sao chép từ trang web làm tham số đầu tiên của EditorInterface.get_editor_theme().get_icon() (tham số thứ hai vẫn giữ là "EditorIcons").

Bạn có thể dùng biểu tượng tùy chỉnh bằng cách trả về một giá trị như preload("res://addons/main_screen/icon.svg"). Khi thiết kế biểu tượng riêng, bạn nên tuân theo các nguyên tắc giống như với biểu tượng node (khuyến nghị định dạng SVG, kích thước 16×16). Xem Biểu tượng trình chỉnh sửa để biết cách tạo biểu tượng cho plugin của bạn.

Thử plugin

Kích hoạt plugin trong Project Settings. Bạn sẽ thấy một nút mới bên cạnh 2D, 3D, Script phía trên viewport chính. Nhấn vào nút đó sẽ đưa bạn đến plugin màn hình chính mới, và nút ở giữa sẽ in văn bản.

Nếu bạn muốn thử phiên bản hoàn chỉnh của plugin này, hãy xem các demo plugin tại đây: https://github.com/godotengine/godot-demo-projects/tree/master/plugins

Nếu bạn muốn xem một ví dụ đầy đủ hơn về những gì plugin màn hình chính có thể làm, hãy xem các dự án demo 2.5D tại đây: https://github.com/godotengine/godot-demo-projects/tree/master/misc/2.5d
