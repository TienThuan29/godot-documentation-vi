Sử dụng DrawableTexture

DrawableTexture là một loại Texture2D có thêm các hàm để sửa đổi texture qua GPU. Có thể dùng nó cho texture thủ tục (procedural), hiệu ứng thời gian thực và nhiều thứ khác.

Blit hình chữ nhật cơ bản

Thao tác cơ bản nhất trên drawable texture là blit_rect(). Thao tác này blit (sao chép) toàn bộ một texture vào hình chữ nhật cho trước trên DrawableTexture.

texture.blit_rect(Rect2(20, 50, 60, 60), preload("res://circle.svg"))
texture.blit_rect(Rect2(20, 50, 60, 60), preload("res://circle.svg"), Color.WHITE, 0)

texture.BlitRect(new Rect2I(20, 50, 60, 60), GD.Load<Texture2D>("res://circle.svg"));
texture.BlitRect(new Rect2I(20, 50, 60, 60), GD.Load<Texture2D>("res://circle.svg"), Colors.White, 0);

Đoạn code trên blit texture hình tròn vào hình chữ nhật (20, 50, 60, 60) trên DrawableTexture. (20, 50) là góc trên bên trái của hình chữ nhật được vẽ vào, và (60, 60) là kích thước của nó. Nếu muốn vẽ đè lên toàn bộ texture, chỉ cần đặt tham số rect khớp với kích thước của DrawableTexture.

Tham số thứ ba của blit_rect() là tham số tùy chọn modulate. Đây là màu mà kết quả đầu ra được nhân với (theo hành vi mặc định). Có thể dùng nó để đổi màu, hoặc thậm chí tạo mask cho kết quả vẽ của blit_rect(). Ví dụ, dùng modulate là Color(0, 0, 1, 0) sẽ chỉ vẽ vào và cập nhật giá trị kênh xanh dương của mỗi pixel trên DrawableTexture.

Tham số thứ tư của blit_rect(), mipmap, có thể chỉ định cấp mipmap để vẽ vào. Bạn chỉ cần dùng nó nếu muốn kiểm soát chi tiết từng lớp mipmap. Lưu ý rằng bạn không cần điều chỉnh kích thước hình chữ nhật; nó được quy đổi thành một phần của kích thước toàn bộ texture. Nếu chỉ muốn cập nhật tất cả các lớp mipmap, bạn nên vẽ vào texture rồi gọi generate_mipmaps() trên nó.

Chế độ hòa trộn và texture blit shader

Quá trình vẽ của blit_rect() và DrawableTexture được điều khiển bởi một texture blit shader. Ngay cả khi người dùng không cung cấp, engine vẫn có một texture blit shader mặc định để sử dụng.

// Default texture blit shader.

shader_type texture_blit;
render_mode blend_mix;

uniform sampler2D source_texture0 : hint_blit_source0;
uniform sampler2D source_texture1 : hint_blit_source1;
uniform sampler2D source_texture2 : hint_blit_source2;
uniform sampler2D source_texture3 : hint_blit_source3;

void blit() {
    // Copies from each whole source texture to a rect on each output texture.
    COLOR0 = texture(source_texture0, UV) * MODULATE;
    COLOR1 = texture(source_texture1, UV) * MODULATE;
    COLOR2 = texture(source_texture2, UV) * MODULATE;
    COLOR3 = texture(source_texture3, UV) * MODULATE;
}

Chế độ hòa trộn được chỉ định trong render_mode xác định cách giá trị màu đầu ra được hòa trộn với màu hiện tại của pixel trên DrawableTexture. Engine mặc định dùng blend_mix nếu không có chế độ hòa trộn nào được chỉ định trong render_mode. Texture blit shader cũng hỗ trợ blend_add (cộng), blend_sub (trừ), blend_mul (nhân) và blend_disabled (alpha không đóng vai trò độ trong suốt và được ghi nguyên trạng). Chế độ hòa trộn premultiplied alpha không được hỗ trợ ở đây.

Bạn cũng có thể dùng chế độ hòa trộn khác với chế độ được chỉ định trong shader. Để làm vậy, bạn có thể tạo instance và truyền vào một class_BlitMaterial mới trong script.

var blit_material = BlitMaterial.new()
blit_material.blend_mode = BlitMaterial.BLEND_MODE_DISABLED
texture.blit_rect(Rect2(0, 0, 200, 200), load("res://icon.svg"), Color.WHITE, 0, blit_material)

var blitMaterial = new BlitMaterial
{
    BlendMode = BlitMaterial.BlendModeEnum.Disabled,
};
texture.BlitRect(new Rect2I(0, 0, 200, 200), GD.Load<Texture2D>("res://icon.svg"), Colors.White, 0, blitMaterial);

Nếu muốn hành vi phức tạp hơn, bạn có thể tự viết texture blit shader. Tạo một shader mới với kiểu shader texture_blit, viết code shader, rồi nạp nó vào một material để truyền cho hàm.

Ghi chú

Material được truyền dưới dạng tham số hàm thay vì gắn với resource. Điều này giúp dễ dàng thực hiện nhiều kiểu vẽ khác nhau lên cùng một texture.

Dùng nhiều blit trong một texture

DrawableTexture cũng có phương thức blit_rect_multi(), cho phép tối đa 4 đầu vào và đầu ra trong cùng một bước.

texture.blit_rect_multi(
        Rect2(0, 0, 200, 200),
        [preload("res://icon.svg"), preload("res://circle.svg")],
        [other_drawable_texture]
    )

texture.BlitRectMulti(
    new Rect2I(0, 0, 200, 200),
    [GD.Load<Texture2D>("res://icon.svg"),
    GD.Load<Texture2D>("res://circle.svg")],
    [otherDrawableTexture]);

Hành vi mặc định của nó chỉ là ghép từng đầu vào với từng đầu ra theo thứ tự. Ví dụ, điều này hữu ích khi vẽ đồng thời vào texture albedo, normal và height.

Tất nhiên, hành vi này cũng có thể được tùy chỉnh qua texture blit shader. Trong shader, các đầu ra bổ sung được ghi qua COLOR1, COLOR2 và COLOR3 (với COLOR0 là đầu ra chính). Các đầu vào bổ sung có thể được đọc dưới dạng uniform với hint_blit_source1, hint_blit_source2 và hint_blit_source3.

Ví dụ 1: Vẽ đơn giản

Một trong những cách dùng trực quan nhất của DrawableTexture là để... vẽ! Trong ví dụ này, chúng ta sẽ bắt đầu một dự án mới và tạo một scene UI mới với node Control làm gốc.

Tiếp theo, bạn cần tạo một node class_TextureRect, đây sẽ là canvas của người dùng. Đặt kích thước phù hợp với màn hình, rồi gắn một script mới vào nó. Phần đầu script này nên khởi tạo texture của TextureRect thành một DrawableTexture mới.

extends TextureRect

func _ready():
    texture = DrawableTexture2D.new()
    # Be careful; if the dimensions of the node are not equal to the size set here,
    # our draw call later will seem to happen at the wrong spot.
    texture.setup(500, 500, DrawableTexture2D.DRAWABLE_FORMAT_RGBA8, false)

private DrawableTexture2D _texture = new DrawableTexture2D();

public override void _Ready()
{
    // Be careful; if the dimensions of the node are not equal to the size set here,
    // our draw call later will seem to happen at the wrong spot.
    _texture.Setup(500, 500, DrawableTexture2D.DrawableFormat.Rgba8, null, false);
    Texture = _texture;
}

Tiếp theo, chúng ta cần TextureRect phản hồi việc người chơi nhấn và kéo chuột như đang vẽ. Để làm vậy, chúng ta có thể ghi đè phương thức _gui_input() của TextureRect trong script và xử lý các sự kiện InputMouseButton và InputMouseMotion:

var drawing = false

func _gui_input(event):
    if event is InputEventMouseButton:
        # Mouse click/unclick - start/stop drawing.
        drawing = not drawing
    if event is InputEventMouseMotion and drawing:
        # Calculate rect to center our drawn rectangle on mouse position
        # instead of mouse at top left.
        var rect = Rect2(event.position.x - 10, event.position.y - 10, 20, 20)
        texture.blit_rect(rect, null)

public bool drawing = false;

public override void _GuiInput(InputEvent @event)
{
    if (@event is InputEventMouseButton)
    {
        // Mouse click/unclick - start/stop drawing.
        drawing = !drawing;
    }
    if (@event is InputEventMouseMotion eventMouseMotion && drawing)
    {
        // Calculate rect to center our drawn rectangle on mouse position
        // instead of mouse at top left.
        var rect = new Rect2I(
            (int)(eventMouseMotion.Position.X - 10),
            (int)(eventMouseMotion.Position.Y - 10),
            20, 20);
        _texture.BlitRect(rect, null);
    }
}

Giờ thao tác này sẽ vẽ các hình vuông đen khi bạn nhấn và kéo quanh TextureRect. Để vẽ tự nhiên hơn, có lẽ chúng ta muốn vẽ hình tròn và thực sự tô màu cho nó.

Chúng ta có thể điều chỉnh thứ được vẽ bằng cách dùng một Texture để sao chép và tham số modulate. Chúng ta sẽ dùng texture hình tròn trắng trơn này, nạp làm tham số texture trong blit_rect(), và dùng màu đỏ làm tham số modulate.

if event is InputEventMouseMotion and drawing:
    # Calculate rect to center our drawn rectangle on mouse position
    # instead of mouse at top left.
    var rect = Rect2(event.position.x - 10, event.position.y - 10, 20, 20)
    texture.blit_rect(rect, preload("res://circle.svg"), Color.RED)

if (@event is InputEventMouseMotion eventMouseMotion && drawing)
{
    // Calculate rect to center our drawn rectangle on mouse position
    // instead of mouse at top left.
    var rect = new Rect2I(
        (int)(eventMouseMotion.Position.X - 10),
        (int)(eventMouseMotion.Position.Y - 10),
        20, 20);
    _texture.BlitRect(rect, GD.Load<Texture2D>("res://circle.svg"), Colors.Red);
}

Giờ nét vẽ trông tự nhiên và nhiều màu sắc hơn hẳn. Để tùy chỉnh thêm, bạn có thể kết nối một node class_ColorPickerButton với script để lưu lựa chọn màu của người dùng cho tham số modulate của blit_rect(). Bạn cũng có thể lưu một biến kích thước cọ, cho người dùng cách điều chỉnh nó, và đưa nó vào phép tính hình chữ nhật để người dùng có thể vẽ nét lớn hơn hoặc nhỏ hơn.

var drawing = false
var my_color = Color.RED
var my_size = 20.0

func _gui_input(event):
    if event is InputEventMouseButton:
        # Mouse click/unclick - start/stop drawing.
        drawing = not drawing
    if event is InputEventMouseMotion and drawing:
        # Calculate rect to center our drawn rectangle on mouse position
        # instead of mouse at top left.
        var rect = Rect2(event.position.x - my_size / 2, event.position.y - my_size / 2, my_size, my_size)
        texture.blit_rect(rect, preload("res://circle.svg"), my_color)

func _on_color_picker_button_color_changed(color):
    my_color = color

func _on_h_slider_value_changed(value):
    my_size = value

private bool _drawing = false;
private Color _myColor = Colors.Red;
private int _mySize = 20;

public override void _GuiInput(InputEvent @event)
{
    if (@event is InputEventMouseButton)
    {
        // Mouse click/unclick - start/stop drawing.
        _drawing = !_drawing;
    }
    if (@event is InputEventMouseMotion eventMouseMotion && _drawing)
    {
        // Calculate rect to center our drawn rectangle on mouse position
        // instead of mouse at top left.
        var rect = new Rect2I(
            (int)(eventMouseMotion.Position.X - _mySize / 2),
            (int)(eventMouseMotion.Position.Y - _mySize / 2),
            _mySize, _mySize);
        _texture.BlitRect(rect, GD.Load<Texture2D>("res://circle.svg"), _myColor);
    }
}

public void OnColorPickerButtonColorChanged(Color color)
{
    _myColor = color;
}

public void OnHSliderValueChanged(float value)
{
    _mySize = (int)value;
}
