Di chuyển người chơi bằng code

Đến lúc viết code rồi! Chúng ta sẽ dùng các input action đã tạo ở phần trước để di chuyển nhân vật.

Ghi chú

Trong dự án này, chúng ta sẽ tuân theo quy ước đặt tên của Godot.

  • GDScript: Lớp (node) dùng PascalCase, biến và hàm dùng snake_case, hằng số dùng ALL_CAPS (Xem Hướng dẫn phong cách GDScript).

  • C#: Lớp, biến export và phương thức dùng PascalCase, trường private dùng _camelCase, biến cục bộ và tham số dùng camelCase (Xem Hướng dẫn phong cách C#). Hãy cẩn thận gõ chính xác tên phương thức khi kết nối signal.

Nhấp chuột phải vào node Player và chọn Attach Script để thêm một script mới cho nó. Trong cửa sổ bật lên, đặt Template thành Empty trước khi nhấn nút Create. Chúng ta đặt nó thành Empty vì muốn tự viết code cho chuyển động của người chơi.

Hãy bắt đầu với các thuộc tính của lớp. Chúng ta sẽ định nghĩa tốc độ di chuyển, gia tốc rơi đại diện cho trọng lực, và một vận tốc dùng để di chuyển nhân vật.

extends CharacterBody3D

# How fast the player moves in meters per second.
@export var speed = 14
# The downward acceleration when in the air, in meters per second squared.
@export var fall_acceleration = 75

var target_velocity = Vector3.ZERO

using Godot;

public partial class Player : CharacterBody3D
{
    // Don't forget to rebuild the project so the editor knows about the new export variable.

    // How fast the player moves in meters per second.
    [Export]
    public int Speed { get; set; } = 14;
    // The downward acceleration when in the air, in meters per second squared.
    [Export]
    public int FallAcceleration { get; set; } = 75;

    private Vector3 _targetVelocity = Vector3.Zero;
}

Đây là các thuộc tính phổ biến cho một vật thể chuyển động. target_velocity là một vector 3D kết hợp tốc độ với hướng. Ở đây, chúng ta định nghĩa nó là một thuộc tính vì muốn cập nhật và tái sử dụng giá trị của nó qua các frame.

Ghi chú

Các giá trị khá khác so với code 2D vì khoảng cách được tính bằng mét. Trong 2D, một nghìn đơn vị (pixel) có thể chỉ tương ứng với một nửa chiều rộng màn hình, còn trong 3D, đó là một kilômét.

Hãy viết code cho chuyển động. Chúng ta bắt đầu bằng việc tính vector hướng đầu vào bằng đối tượng toàn cục Input, trong _physics_process().

func _physics_process(delta):
    # We create a local variable to store the input direction.
    var direction = Vector3.ZERO

    # We check for each move input and update the direction accordingly.
    if Input.is_action_pressed("move_right"):
        direction.x += 1
    if Input.is_action_pressed("move_left"):
        direction.x -= 1
    if Input.is_action_pressed("move_back"):
        # Notice how we are working with the vector's x and z axes.
        # In 3D, the XZ plane is the ground plane.
        direction.z += 1
    if Input.is_action_pressed("move_forward"):
        direction.z -= 1

public override void _PhysicsProcess(double delta)
{
    // We create a local variable to store the input direction.
    var direction = Vector3.Zero;

    // We check for each move input and update the direction accordingly.
    if (Input.IsActionPressed("move_right"))
    {
        direction.X += 1.0f;
    }
    if (Input.IsActionPressed("move_left"))
    {
        direction.X -= 1.0f;
    }
    if (Input.IsActionPressed("move_back"))
    {
        // Notice how we are working with the vector's X and Z axes.
        // In 3D, the XZ plane is the ground plane.
        direction.Z += 1.0f;
    }
    if (Input.IsActionPressed("move_forward"))
    {
        direction.Z -= 1.0f;
    }
}

Ở đây, thay vì _process(), chúng ta sẽ thực hiện mọi phép tính bằng hàm ảo _physics_process(). Hàm này được thiết kế riêng cho code liên quan đến vật lý, như di chuyển một kinematic body hoặc rigid body. Nó cập nhật node theo các khoảng thời gian cố định.

Xem thêm

Để tìm hiểu thêm về sự khác biệt giữa _process() và _physics_process(), xem Xử lý idle và xử lý vật lý.

Chúng ta bắt đầu bằng việc khởi tạo biến direction với giá trị Vector3.ZERO. Sau đó, chúng ta kiểm tra xem người chơi có đang nhấn một hoặc nhiều input move_* hay không và cập nhật các thành phần x và z của vector tương ứng. Chúng tương ứng với các trục của mặt phẳng mặt đất.

Bốn điều kiện này cho chúng ta tám khả năng và tám hướng có thể.

Trong trường hợp người chơi nhấn đồng thời, chẳng hạn, cả W và D, vector sẽ có độ dài khoảng 1.4. Nhưng nếu họ chỉ nhấn một phím, nó sẽ có độ dài 1. Chúng ta muốn độ dài của vector nhất quán, và nhân vật không di chuyển nhanh hơn theo đường chéo. Để làm vậy, chúng ta có thể gọi phương thức normalized() của nó.

func _physics_process(delta):
    #...

    if direction != Vector3.ZERO:
        direction = direction.normalized()
        # Setting the basis property will affect the rotation of the node.
        $Pivot.basis = Basis.looking_at(direction)

public override void _PhysicsProcess(double delta)
{
    // ...

    if (direction != Vector3.Zero)
    {
        direction = direction.Normalized();
        // Setting the basis property will affect the rotation of the node.
        GetNode<Node3D>("Pivot").Basis = Basis.LookingAt(direction);
    }
}

Ở đây, chúng ta chỉ chuẩn hóa vector nếu hướng có độ dài lớn hơn không, nghĩa là người chơi đang nhấn một phím hướng.

Chúng ta tính hướng mà $Pivot đang nhìn bằng cách tạo một Basis nhìn theo hướng direction.

Sau đó, chúng ta cập nhật vận tốc. Chúng ta phải tính riêng vận tốc trên mặt đất và tốc độ rơi. Hãy nhớ lùi lại một tab để các dòng nằm bên trong hàm _physics_process() nhưng bên ngoài điều kiện vừa viết ở trên.

func _physics_process(delta):
    #...
    if direction != Vector3.ZERO:
        #...

    # Ground Velocity
    target_velocity.x = direction.x * speed
    target_velocity.z = direction.z * speed

    # Vertical Velocity
    if not is_on_floor(): # If in the air, fall towards the floor. Literally gravity
        target_velocity.y = target_velocity.y - (fall_acceleration * delta)

    # Moving the Character
    velocity = target_velocity
    move_and_slide()

public override void _PhysicsProcess(double delta)
{
    // ...
    if (direction != Vector3.Zero)
    {
        // ...
    }

    // Ground velocity
    _targetVelocity.X = direction.X * Speed;
    _targetVelocity.Z = direction.Z * Speed;

    // Vertical velocity
    if (!IsOnFloor()) // If in the air, fall towards the floor. Literally gravity
    {
        _targetVelocity.Y -= FallAcceleration * (float)delta;
    }

    // Moving the character
    Velocity = _targetVelocity;
    MoveAndSlide();
}

Hàm CharacterBody3D.is_on_floor() trả về true nếu body đã va chạm với sàn trong frame này. Đó là lý do chúng ta chỉ áp dụng trọng lực cho Player khi nó đang ở trên không.

Với vận tốc theo phương thẳng đứng, chúng ta trừ đi gia tốc rơi nhân với thời gian delta mỗi frame. Dòng code này sẽ khiến nhân vật rơi xuống ở mọi frame, miễn là nó không đứng trên hoặc va chạm với sàn.

Engine vật lý chỉ có thể phát hiện tương tác với tường, sàn hoặc các body khác trong một frame nhất định nếu có chuyển động và va chạm xảy ra. Chúng ta sẽ dùng thuộc tính này sau để viết code cho cú nhảy.

Ở dòng cuối, chúng ta gọi CharacterBody3D.move_and_slide(), một phương thức mạnh mẽ của lớp CharacterBody3D cho phép bạn di chuyển nhân vật một cách mượt mà. Nếu nhân vật va vào tường giữa chừng một chuyển động, engine sẽ cố gắng làm mượt nó cho bạn. Phương thức này dùng giá trị velocity có sẵn của CharacterBody3D

Và đó là tất cả code bạn cần để di chuyển nhân vật trên sàn.

Đây là toàn bộ code player.gd để bạn tham khảo.

extends CharacterBody3D

# How fast the player moves in meters per second.
@export var speed = 14
# The downward acceleration when in the air, in meters per second squared.
@export var fall_acceleration = 75

var target_velocity = Vector3.ZERO


func _physics_process(delta):
    var direction = Vector3.ZERO

    if Input.is_action_pressed("move_right"):
        direction.x += 1
    if Input.is_action_pressed("move_left"):
        direction.x -= 1
    if Input.is_action_pressed("move_back"):
        direction.z += 1
    if Input.is_action_pressed("move_forward"):
        direction.z -= 1

    if direction != Vector3.ZERO:
        direction = direction.normalized()
        # Setting the basis property will affect the rotation of the node.
        $Pivot.basis = Basis.looking_at(direction)

    # Ground Velocity
    target_velocity.x = direction.x * speed
    target_velocity.z = direction.z * speed

    # Vertical Velocity
    if not is_on_floor(): # If in the air, fall towards the floor. Literally gravity
        target_velocity.y = target_velocity.y - (fall_acceleration * delta)

    # Moving the Character
    velocity = target_velocity
    move_and_slide()

using Godot;

public partial class Player : CharacterBody3D
{
    // How fast the player moves in meters per second.
    [Export]
    public int Speed { get; set; } = 14;
    // The downward acceleration when in the air, in meters per second squared.
    [Export]
    public int FallAcceleration { get; set; } = 75;

    private Vector3 _targetVelocity = Vector3.Zero;

    public override void _PhysicsProcess(double delta)
    {
        var direction = Vector3.Zero;

        if (Input.IsActionPressed("move_right"))
        {
            direction.X += 1.0f;
        }
        if (Input.IsActionPressed("move_left"))
        {
            direction.X -= 1.0f;
        }
        if (Input.IsActionPressed("move_back"))
        {
            direction.Z += 1.0f;
        }
        if (Input.IsActionPressed("move_forward"))
        {
            direction.Z -= 1.0f;
        }

        if (direction != Vector3.Zero)
        {
            direction = direction.Normalized();
            // Setting the basis property will affect the rotation of the node.
            GetNode<Node3D>("Pivot").Basis = Basis.LookingAt(direction);
        }

        // Ground velocity
        _targetVelocity.X = direction.X * Speed;
        _targetVelocity.Z = direction.Z * Speed;

        // Vertical velocity
        if (!IsOnFloor()) // If in the air, fall towards the floor. Literally gravity
        {
            _targetVelocity.Y -= FallAcceleration * (float)delta;
        }

        // Moving the character
        Velocity = _targetVelocity;
        MoveAndSlide();
    }
}

Kiểm thử chuyển động của người chơi

Chúng ta sẽ đặt người chơi vào scene Main để kiểm thử. Để làm vậy, chúng ta cần tạo instance của người chơi rồi thêm một camera. Không giống như trong 2D, trong 3D bạn sẽ không thấy gì nếu viewport không có camera hướng vào thứ gì đó.

Lưu scene Player và mở scene Main. Bạn có thể nhấp vào tab Main ở phía trên trình chỉnh sửa để làm điều này.

Nếu trước đó bạn đã đóng scene, hãy vào dock FileSystem và nhấp đúp vào main.tscn để mở lại.

Để tạo instance của Player, nhấp chuột phải vào node Main và chọn Instantiate Child Scene.

Trong cửa sổ bật lên, nhấp đúp vào player.tscn. Nhân vật sẽ xuất hiện ở giữa viewport.

Thêm camera

Tiếp theo, hãy thêm camera. Giống như đã làm với Pivot của Player, chúng ta sẽ tạo một rig cơ bản. Nhấp chuột phải vào node Main một lần nữa và chọn Add Child Node. Tạo một Marker3D mới và đặt tên là CameraPivot. Chọn CameraPivot và thêm cho nó một node con Camera3D. Cây scene của bạn sẽ trông tương tự như thế này.

Hãy để ý ô đánh dấu Preview xuất hiện ở góc trên bên trái của khung nhìn 3D khi bạn chọn Camera. Bạn có thể nhấp vào nó để xem trước phép chiếu của camera trong game.

Chúng ta sẽ dùng Pivot để xoay camera như thể nó được gắn trên một cần cẩu. Trước tiên, hãy chia khung nhìn 3D để có thể tự do di chuyển trong scene và xem những gì camera nhìn thấy.

Trên thanh công cụ ngay phía trên viewport, nhấp vào View, rồi 2 Viewports. Bạn cũng có thể nhấn Ctrl + 2 (Cmd + 2 trên macOS).

Ở khung nhìn phía dưới, chọn Camera3D và bật Preview của camera bằng cách nhấp vào ô đánh dấu.

Ở khung nhìn phía trên, hãy đảm bảo Camera3D đang được chọn và di chuyển camera khoảng 19 đơn vị trên trục Z (kéo mũi tên màu xanh dương).

Đây là lúc điều kỳ diệu xảy ra. Chọn CameraPivot và xoay nó -45 độ quanh trục X (dùng vòng tròn màu đỏ). Bạn sẽ thấy camera di chuyển như thể nó được gắn vào một cần cẩu.

Bạn có thể chạy scene bằng cách nhấn F6 (Cmd + R trên macOS) và nhấn các phím mũi tên để di chuyển nhân vật.

Chúng ta có thể thấy một khoảng trống quanh nhân vật do phép chiếu phối cảnh. Trong trò chơi này, chúng ta sẽ dùng phép chiếu trực giao để đóng khung khu vực chơi tốt hơn và giúp người chơi dễ ước lượng khoảng cách hơn.

Chọn lại Camera và trong Inspector, đặt Projection thành Orthogonal và Size thành 19. Nhân vật giờ sẽ trông phẳng hơn và mặt đất sẽ lấp đầy nền.

Ghi chú

Khi dùng camera trực giao trong Godot 4, chất lượng bóng đổ của directional light phụ thuộc vào giá trị Far của camera. Giá trị Far càng cao, camera càng nhìn được xa hơn. Tuy nhiên, giá trị Far cao hơn cũng làm giảm chất lượng bóng đổ, vì việc kết xuất bóng phải bao phủ một khoảng cách lớn hơn.

Nếu bóng đổ của directional light trông quá mờ sau khi chuyển sang camera trực giao, hãy giảm thuộc tính Far của camera xuống một giá trị thấp hơn, chẳng hạn 100. Đừng giảm thuộc tính Far này quá nhiều, nếu không các vật thể ở xa sẽ bắt đầu biến mất.

Kiểm thử scene và bạn sẽ có thể di chuyển theo cả 8 hướng mà không bị lọt xuyên qua sàn!

Cuối cùng, chúng ta đã có cả chuyển động của người chơi lẫn khung nhìn. Tiếp theo, chúng ta sẽ làm việc với quái vật.
