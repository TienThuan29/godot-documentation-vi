Lắng nghe input của người chơi

Dựa trên bài học trước, Tạo script đầu tiên, hãy xem xét một tính năng quan trọng khác của bất kỳ game nào: trao quyền điều khiển cho người chơi. Để thêm tính năng này, chúng ta cần sửa code sprite_2d.gd.

Bạn có hai công cụ chính để xử lý input của người chơi trong Godot:

  1. Các callback input tích hợp sẵn, chủ yếu là _unhandled_input(). Giống như _process(), nó là một hàm ảo tích hợp sẵn mà Godot gọi mỗi khi người chơi nhấn một phím. Đây là công cụ bạn nên dùng để phản ứng với các sự kiện không xảy ra mỗi frame, như nhấn Space để nhảy. Để tìm hiểu thêm về callback input, hãy xem Sử dụng InputEvent.

  2. Singleton Input. Singleton là một đối tượng có thể truy cập toàn cục. Godot cung cấp quyền truy cập vào một số singleton trong script. Đây là công cụ phù hợp để kiểm tra input mỗi frame.

Ở đây chúng ta sẽ dùng singleton Input vì cần biết người chơi có muốn xoay hay di chuyển ở mỗi frame hay không.

Để xoay, chúng ta nên dùng một biến mới: direction. Trong hàm _process(), thay dòng rotation += angular_speed * delta bằng đoạn code bên dưới.

var direction = 0
if Input.is_action_pressed("ui_left"):
    direction = -1
if Input.is_action_pressed("ui_right"):
    direction = 1

rotation += angular_speed * direction * delta

var direction = 0;
if (Input.IsActionPressed("ui_left"))
{
    direction = -1;
}
if (Input.IsActionPressed("ui_right"))
{
    direction = 1;
}

Rotation += _angularSpeed * direction * (float)delta;

Biến cục bộ direction là một hệ số nhân biểu thị hướng mà người chơi muốn xoay. Giá trị 0 nghĩa là người chơi không nhấn phím mũi tên trái hay phải. Giá trị 1 nghĩa là người chơi muốn xoay sang phải, và -1 nghĩa là họ muốn xoay sang trái.

Để tạo ra các giá trị này, chúng ta giới thiệu câu lệnh điều kiện và cách dùng Input. Trong GDScript, một câu lệnh điều kiện bắt đầu bằng từ khóa if và kết thúc bằng dấu hai chấm. Điều kiện chính là biểu thức nằm giữa từ khóa và dấu hai chấm ở cuối dòng.

Để kiểm tra một phím có được nhấn trong frame này hay không, chúng ta gọi Input.is_action_pressed(). Phương thức này nhận một chuỗi văn bản biểu thị một input action và trả về true nếu action được nhấn, ngược lại trả về false.

Hai action chúng ta dùng ở trên, "ui_left" và "ui_right", được định nghĩa sẵn trong mọi dự án Godot. Chúng lần lượt được kích hoạt khi người chơi nhấn phím mũi tên trái và phải trên bàn phím hoặc nút trái và phải trên D-pad của gamepad.

Ghi chú

Bạn có thể xem và chỉnh sửa các input action trong dự án bằng cách vào Project > Project Settings và nhấp vào tab Input Map.

Cuối cùng, chúng ta dùng direction làm hệ số nhân khi cập nhật rotation của node: rotation += angular_speed * direction * delta.

Hãy comment các dòng var velocity = Vector2.UP.rotated(rotation) * speed và position += velocity * delta như sau:

#var velocity = Vector2.UP.rotated(rotation) * speed

#position += velocity * delta

//var velocity = Vector2.Up.Rotated(Rotation) * _speed;

//Position += velocity * (float)delta;

Việc này sẽ bỏ qua đoạn code ở bài tập trước, vốn di chuyển vị trí của biểu tượng theo vòng tròn mà không cần đầu vào từ người dùng.

Nếu bạn chạy scene với code này, biểu tượng sẽ xoay khi bạn nhấn Left và Right.

Di chuyển khi nhấn "up"

Để chỉ di chuyển khi nhấn phím, chúng ta cần sửa đoạn code tính vận tốc. Hãy bỏ comment đoạn code và thay dòng bắt đầu bằng var velocity bằng đoạn code dưới đây.

var velocity = Vector2.ZERO
if Input.is_action_pressed("ui_up"):
    velocity = Vector2.UP.rotated(rotation) * speed

var velocity = Vector2.Zero;
if (Input.IsActionPressed("ui_up"))
{
    velocity = Vector2.Up.Rotated(Rotation) * _speed;
}

Chúng ta khởi tạo velocity với giá trị Vector2.ZERO, một hằng số khác của kiểu Vector có sẵn, biểu diễn một vector 2D có độ dài 0.

Nếu người chơi nhấn action "ui_up", chúng ta sẽ cập nhật giá trị vận tốc, khiến sprite di chuyển về phía trước.

Script hoàn chỉnh

Đây là file sprite_2d.gd hoàn chỉnh để bạn tham khảo.

extends Sprite2D

var speed = 400
var angular_speed = PI


func _process(delta):
    var direction = 0
    if Input.is_action_pressed("ui_left"):
        direction = -1
    if Input.is_action_pressed("ui_right"):
        direction = 1

    rotation += angular_speed * direction * delta

    var velocity = Vector2.ZERO
    if Input.is_action_pressed("ui_up"):
        velocity = Vector2.UP.rotated(rotation) * speed

    position += velocity * delta

using Godot;

public partial class MySprite2D : Sprite2D
{
    private float _speed = 400;
    private float _angularSpeed = Mathf.Pi;

    public override void _Process(double delta)
    {
        var direction = 0;
        if (Input.IsActionPressed("ui_left"))
        {
            direction = -1;
        }
        if (Input.IsActionPressed("ui_right"))
        {
            direction = 1;
        }

        Rotation += _angularSpeed * direction * (float)delta;

        var velocity = Vector2.Zero;
        if (Input.IsActionPressed("ui_up"))
        {
            velocity = Vector2.Up.Rotated(Rotation) * _speed;
        }

        Position += velocity * (float)delta;
    }
}

Nếu chạy scene, giờ bạn sẽ có thể xoay bằng phím mũi tên trái và phải, và di chuyển về phía trước bằng cách nhấn Up.

Tóm tắt

Tóm lại, mọi script trong Godot đều đại diện cho một lớp và mở rộng một trong các lớp có sẵn của engine. Các loại node mà lớp của bạn kế thừa cho phép bạn truy cập các thuộc tính, chẳng hạn rotation và position trong trường hợp sprite của chúng ta. Bạn cũng kế thừa nhiều hàm mà chúng ta chưa dùng đến trong ví dụ này.

Trong GDScript, các biến bạn đặt ở đầu file là thuộc tính của lớp, còn gọi là biến thành viên. Ngoài biến, bạn có thể định nghĩa hàm, phần lớn sẽ là các phương thức của lớp.

Godot cung cấp một số hàm ảo mà bạn có thể định nghĩa để kết nối lớp của mình với engine. Trong đó có _process() để áp dụng thay đổi lên node mỗi frame, và _unhandled_input() để nhận các sự kiện input như nhấn phím và nút từ người dùng. Còn khá nhiều hàm khác nữa.

Singleton Input cho phép bạn phản hồi đầu vào của người chơi ở bất kỳ đâu trong code. Đặc biệt, bạn sẽ dùng nó trong vòng lặp _process().

Trong bài tiếp theo, Sử dụng signal, chúng ta sẽ phát triển thêm mối quan hệ giữa script và node bằng cách để các node kích hoạt code trong script.
